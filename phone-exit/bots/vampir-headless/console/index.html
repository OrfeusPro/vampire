Регистрация Netmarble

Для почты @vampir.top код читается из новых писем через mail.vampir.top:143 с STARTTLS. Почтовый пароль хранится отдельно от игрового, зашифрован Windows. Создание почтового ящика сюда не входит.

Оба способа сначала открывают одну и ту же форму входа Netmarble. Затем «Через лаунчер» выполняет launcher/token → launcher/sign-in, а «Прямой SDK SignIn» — v1/sign-in. При ошибке способ сам не меняется; регистрация не запускается.

Для одной следующей операции входа. Автозаполнение отключено; после авторизации продолжается выбранное действие. К регистрации этот режим не применяется.

Первый вход игрового SDK

Для уже зарегистрированного Netmarble без подтверждённого игрового профиля. Проверяет профиль; только при точном ответе об отсутствии и отсутствии условий создаёт профиль SDK. Если условия доступны, останавливается. Персонажа не создаёт и в игру не входит. Обычный вход эту операцию не запускает.

По умолчанию Carnage. Класс выбирается вручную и сохраняется. При подтверждении «ник занят» меняется только ник, до 5 вариантов; неизвестный ответ не вызывает повтор.

Если на выбранном сервере уже есть персонаж, новый не создаётся. Эти настройки применяются только к подтверждённому пустому списку. Создание запускается отдельной кнопкой ниже. Кнопка случайного ника меняет форму до сохранения.

Для выбранного сервера сразу нажмите «Войти и прочитать персонажей»: каталог серверов и персонажи загружаются за один вход. Предварительно нажимать «Загрузить серверы» не нужно. Эта проверка не входит в мир.

Создание использует сохранённые настройки и свежий список. После неподтверждённой попытки сначала отдельно прочитайте персонажей.
