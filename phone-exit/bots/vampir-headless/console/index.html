Регистрация Netmarble

Для почты @vampir.top код читается из новых писем через mail.vampir.top:993. Почтовый пароль хранится отдельно от игрового, зашифрован Windows. Создание почтового ящика сюда не входит.

Ник сохраняется как задание. Автоматическое создание пока не подключено; отказ входа не считается пустым списком.
