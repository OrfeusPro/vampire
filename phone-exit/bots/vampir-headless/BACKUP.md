# Локальные данные и резервная копия

Пользователи, пароли, назначения и каталоги находятся в `.local/console.sqlite3`.
Привязки устройств — в `.local/accounts.sqlite3`. Эти файлы не попадают в Git.
Пароли защищены Windows DPAPI CurrentUser: копия базы сама по себе не переносит
доступ к паролям на другой ПК или к другому пользователю Windows.

Из корня репозитория:

```powershell
python -X utf8 phone-exit/bots/vampir-headless/backup-local-data.py create --destination 'F:/PhoneExit Backups/Vampir/accounts'
python -X utf8 phone-exit/bots/vampir-headless/backup-local-data.py verify --backup '<каталог созданной копии>'
```

Используется SQLite backup API, включая подтверждённые записи WAL. Каждая база
проверяется через integrity_check, размер и SHA256. Сначала создаётся временный
каталог; готовая копия публикуется только после проверок. Прежние копии и рабочие
базы не заменяются. Ошибка создания не оставляет готовый manifest.

Для общего согласованного момента остановите workers и редактирование настроек:
между двумя базами нет общей транзакции. Отдельная база согласованна и при работе
панели. Проверка не расшифровывает пароли, не авторизуется и не отправляет команды.
Manifest показывает отсутствующие базы; если console.sqlite3 нет, создание запрещено.

Восстановление пока ручное: остановить панель и workers, проверить копию, сохранить
текущую `.local`, затем вернуть базы под исходным пользователем Windows. Сохранить
старые WAL/SHM отдельно вместе с прежними базами; не смешивать их с восстановленными.
Автоматического восстановления поверх действующей базы нет.

Это копия двух баз, а не всей библиотеки. EXE, PAK, Ghidra и машинные результаты
в `F:/PhoneExit Resources/Vampir` требуют отдельной копии на другой носитель.
Хранение копии на том же диске не защищает от его отказа. Перенос паролей и
облегчённый Android runtime остаются отдельными незавершёнными задачами.
