## Текущее продолжение

Следом H02: `headless-network-index.json` содержит root/инструкции для каждого
выбранного имени. Искать подтверждённые функции возврата имени и pointers на них,
затем связать vtable slots/конструкторы/регистрацию; полные primitive readers
остаются отдельной H03. Сначала PktLogin/Result, LobbyLogin/Result,
CharacterSelect/Result и Ping/Result. Не декодировать большие factory/data spans
линейно без проверки границ. U01 делать до приёма следующего обновления игры.

Критерий продукта: Windows без процесса игры, 10–20 аккаунтов, управление через живую 2D-карту,
проверенный фарм, замеренная нагрузка и воспроизводимое обновление данных.
H01, статическая карта и synthetic replay сами по себе этот критерий не закрывают.
