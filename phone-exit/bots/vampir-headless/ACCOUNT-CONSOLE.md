# Аккаунты ботов на Windows

Панель запускается отдельно от игры и инструментов исследования:

```powershell
python -X utf8 phone-exit/bots/vampir-headless/account-manager.py
```

Открыть `http://127.0.0.1:17949/`. Сервер принимает соединения только через
loopback. Остановка процесса панели закрывает принадлежащие ему рабочие процессы.
Кнопка «Остановить» закрывает процесс только выбранного аккаунта.

## Настройки и регистрация

1. Добавить почту Netmarble и игровой пароль. Для автоматического получения кода
   регистрации отдельно указать пароль этого почтового ящика. Пустое поле при
   следующем сохранении оставляет прежний пароль; браузер его не получает.
2. Сохранить настройки. Для регистрации сервер и персонаж пока не обязательны.
3. Для одной явной регистрации отметить принятие обязательных условий Netmarble
   и нажать «Зарегистрировать аккаунт». Необязательная рекламная подписка выключена.
4. Откроется официальная форма в отдельном WebView. Код читается только из новых
   писем выбранного ящика через проверенный TLS IMAP `mail.vampir.top:993`.
   Поддержаны только ящики `@vampir.top`. Создание самого почтового ящика выполняется
   отдельно. Капча и изменившаяся форма требуют вмешательства пользователя.
5. Завершение регистрации подтверждается экраном завершения и проверенным NID
   callback. Только после обоих сигналов панель сохраняет статус «подтверждена».
   Неизвестный результат не считается успехом и не повторяется автоматически.

Пароли хранятся раздельно в `.local/console.sqlite3`, зашифрованы Windows DPAPI
для текущего пользователя ОС. База и каталоги WebView исключены из Git.
Пароли и коды не передаются аргументами процессов и не выводятся в состояние API.
Флаг принятия условий не сохраняется для будущих регистраций.

Регистрация Netmarble отличается от создания SDK-игрока и создания персонажа.
Эти действия не выполняются скрытно при ошибке обычного входа.

## Серверы, персонажи и параллельный запуск

«Загрузить серверы» получает свежий каталог через SDK и лобби выбранного региона.
Названия берутся из ответа: подпись группы и числовой суффикс записи сервера.
Например, EU возвращает группу `Prelude` и запись `프렐류드2`; панель показывает
`Prelude 2`, сохраняя исходную подпись. Если суффикс неизвестен, остаётся исходное
название без придуманного номера. Адреса соединений в каталог панели не включаются.
Каталог региона общий для аккаунтов и сохраняется после перезапуска панели;
после обновления меняются и выпадающий список, и подписи карточек.
Отказ лобби, неоднозначные ID или пустой регион не заменяют прежний каталог.
После выбора сервера сохранить настройки и нажать «Прочитать персонажей».
Назначение персонажа сохраняет его ключ как десятичную строку: после изменения
порядка списка выбирается прежний ключ. Отсутствующий или неоднозначный ключ
останавливает выбор. Смена региона или сервера очищает выбор в форме.

«Запустить два аккаунта» запускает первые два включённых аккаунта отдельными
процессами. Одновременно допускаются не более двух операций; повторный запуск
одного аккаунта отклоняется. Отключённые аккаунты сохраняются, но не запускаются.
Настройки работающего бота нельзя редактировать.

На первом этапе доступен общий профиль «Текущий ПК». Он использует наблюдённые
данные устройства и сохраняет существующие привязки. Cookies WebView изолированы
по аккаунтам. Произвольные идентификаторы и другие профили устройств пока не
подключены. Все операции используют прямой маршрут без изменения VPN и маршрутов ОС.

Статус «В мире» возникает после получения серверной позиции. Без назначенного
персонажа запуск читает список; пустой список показывается отдельно от отказа
Login. Ник для создания сохраняется, но сетевое создание персонажа ещё не подключено.
Сессия ограничена 300 секундами наблюдения после входа в мир; автоматических
повторов, квестовых действий и reconnect здесь пока нет.

## Проверки и границы

78 локальных тестов: DPAPI, отсутствие паролей в API, сохранение настроек,
отдельный почтовый пароль, обязательное подтверждение регистрации, прямой маршрут
и освобождение IMAP, две отдельные тестовые службы и независимая остановка,
запрет третьего процесса, проверка HTTP Host / Origin / token, выбор по свежему
ключу персонажа, формы регистрации, получение кода и существующий вход.
Дополнительно проверены названия и фильтрация региона, неизвестные подписи,
дубли ID и сохранение прежнего каталога при отклонённом обновлении.
Эти тесты используют fixtures и не выполняют реальную регистрацию или игровой вход.
Панель открыта и проверена в браузере с двумя локальными аккаунтами.
22 октября через панель выполнена живая загрузка EU-каталога без VPN:
12 серверов Aria / Prelude / Opus / Canon / Requiem / Waltz, по два в группе.
У обоих аккаунтов в интерфейсе подтверждено имя Prelude 2 для server ID 384.
Проверка закончилась в лобби, без игрового соединения и создания персонажа.
Живая регистрация через новую панель и одновременный вход двух аккаунтов в мир
ещё не подтверждены. Хранилище DPAPI и WebView относятся к Windows;
перенос в лёгкий Android runtime не выполнен.
