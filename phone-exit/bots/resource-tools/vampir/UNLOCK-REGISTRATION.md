# Vampir: регистрация обработчиков и события готовности

16 октября 2026. Продолжение [UNLOCK-RESULTS.md](UNLOCK-RESULTS.md) и
[CONDITION-GATE.md](CONDITION-GATE.md). Статическое чтение Windows-файлов.

## Как повторить

`python phone-exit/bots/resource-tools/vampir/build-lock-registration-events.py`
создаёт `F:/PhoneExit Resources/Vampir/code-clues/lock-registration-events.json`.
EXE SHA256:
`c7552efd2125e7981945d3443cc1d70a41ac0a8a4cb42e7c77e0d40b4713dfc8`.

Проверяются 29 опорных инструкций, семь прямых вызовов setter, три точные
диагностические строки, таблицы методов, конструкторы пакетов и getters ID.
Отчёт содержит 13 unwind-фрагментов, блок фабрики и четыре leaf-диапазона.
Фабрика сначала декодируется от unwind-границы, затем сохраняется её нужный блок;
совпадение адреса в произвольных байтах не считается началом инструкции.

## Регистрация двух результатов

| Назначение | Таблица обработчика | OnHandler в слоте+0x10 | Конструктор пакета | ID |
|---|---|---|---|---:|
| ContentsUnlockListReadResult | 0x149d81a40 | 0x146763cd0 | 0x1456e99f0 | 1007 (0x3ef) |
| ContentsUnlockRequestResult | 0x149d81a58 | 0x146763da0 | 0x1456e9ab0 | 1009 (0x3f1) |

LEA на сами OnHandler не найден, зато адреса есть в таблицах методов.
Общая фабрика с корнем 0x14678ec40 создаёт 8-байтный объект обработчика,
устанавливает таблицу в 0x146792b34/0x146792b7f и отдельно создаёт объект пакета.
Пара передаётся в 0x1467a7250 вызовами 0x146792b61/0x146792bac.

Функция 0x1467a7250 содержит точную ASCII-строку
`PacketDispatcher::_AddPacketHandler`, файловое смещение 165165232.
Она вызывает packet-vtable+0x28, сохраняет AX как word-ключ и передаёт ключ
с парой packet/handler в 0x14678e3e0. Packet-vtable0x1498dca80/0x1498dcb88
установлены конструкторами; слот+0x28 ведёт в 0x1456f8560/0x1456f8580,
которые возвращают 1007/1009. Байты getter и таблиц проверяются отдельно.

Это доказывает регистрацию пары с ключом пакета, но ещё не весь путь
«получить байты → десериализовать → найти запись → вызвать handler+0x10».
Числа ID — доказательства внутреннего устройства клиента, не сетевой API бота.

## События готовности

Прямой E8-поиск к setter0x145ced600 нашёл семь вызовов; во всех R8B=1.
Типы подтверждены подготовкой аргументов, имена типов — предыдущим конвертером.
Окружающие ветвления функций остаются значимыми.

| Вызов | Тип | Корень / подтверждённое имя |
|---|---|---|
| 0x145d05a12 | 3, GuildLevel | 0x145d05850, имя неизвестно |
| 0x145d05a24 | 8, GuildJoined | тот же корень |
| 0x145d73f2c | 1, CompletedQuest | 0x145d73e10, имя неизвестно |
| 0x145d7dc91 | 0, CharacterLevel | 0x145d7db30, имя неизвестно; под условием BPL |
| 0x14675ec03 | 3, GuildLevel | PktCharacterSelectResultHandler::OnHandler() |
| 0x14675ec15 | 7, EngravingAdditionalRarity | тот же обработчик |
| 0x14676d787 | 7, EngravingAdditionalRarity | PktEngravingResultHandler::OnHandler() |

Два имени подтверждены UTF-16 литералами в 0x14675e9d3 (файловое смещение 165059712)
и 0x14676d684 (165076912). В ветви выбора персонажа перед setter вызывается
 0x145ceb7e0, ранее связанный с подготовкой/сбросом+0x221.
Выбор персонажа не объявляется достаточным для готовности всех типов: здесь 3/7,
остальные обновляются в других путях.

Список содержит только прямые вызовы. Tail-jump/виртуальные/callback пути
не исключены; отсутствие типа в этой таблице не означает отсутствия события.
У EnterArea=4 ранее найден отдельный writer0x145cf5b10.
