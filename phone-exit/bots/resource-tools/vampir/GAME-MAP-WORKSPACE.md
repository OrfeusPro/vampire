# Отдельный прототип карты с панелями игры

Сохранён экспериментальный вариант `maps/atlas/workspace.html`. Это адаптация
панелей поверх существующего атласа, а не восстановленный игровой HUD.
Дальнейшее восстановление внешнего вида проходит через общий аудит,
описанный в [README Vampir](../../vampir/README.md).

Сборка из корня репозитория:

```powershell
python phone-exit/bots/resource-tools/vampir/build-game-map-workspace.py
```

Входы и результат находятся вне Git в `F:/PhoneExit Resources/Vampir`.
Сборщик проверяет SHA архива и снимка каталога, сопоставляет текущие экспорты
по имени и типу, сохраняет происхождение в `game-ui-resources.json`.
Снимок каталога: `b8ee52f76aecb1ecb7544de13a59e2355b7a32b44d1da1fb6426e650f17f9a04`.
PAK: `88cf9a8a87e3bbcbe2d817ac5c2b5254a133112f6bfa7f89230335dd3417808b`.

Использованы каталоги `WBP_GameUI`, `WBP_MainMenuUI_GL`, `WBP_PCStatusUI`,
`WBP_SideMenuUI`, `WBP_QuickSlotUI` и `WBP_MinimapUI`.
Исторические цепочки родителей отмечены отдельно; изменённые байты слотов
не переиспользуются. Соответствие иконки кнопке — явное назначение прототипа:
зависимость ресурса не подтверждает исходный brush binding.

Ограничения: расположение и CSS временные, активный вариант, DPI, состояния,
анимации и итоговая геометрия игры не подтверждены. Карта использует прежние
данные атласа. Кнопки открывают местные справочники и инструменты карты;
игровые команды не отправляются. Проверка синтаксиса Python и JavaScript
выполнена; визуальная проверка этого варианта в браузере ещё не завершена.
