## Переходы и порядок реализации

Общее меню, отдельные URL каталогов и карточек; состояние поиска/фильтров/
прокрутки сохраняется при возврате. Один объект имеет одну основную карточку.
Книги — вкладка предметов плюс быстрый переход из навыков, без копии карточки.
Монстр → добыча → предмет → навык; предмет → коробки/рецепты/карта источников.
Краткие карточки карты открывают полную страницу через «Подробнее».

Сначала вынести существующие карточки/каталоги и объединить меню; затем
добавлять «Развитие» по готовности подтверждённых связей. Серверный календарь,
рыбалка, сбор ресурсов и торговые маршруты сейчас не обещаются: в этом
исследовании достаточные связи для них не установлены.
