# Русский язык атласа

22 октября 2026: русский включён для отображения названий и описаний во всех
разделах атласа: карта, монстры, предметы, книги, навыки, коллекции, характеристики.
При отсутствии перевода либо конфликте исходный текст сохраняется. Это перевод
представления; игровые ID, координаты, исходные JSON, SHA и серверное состояние
не меняются. Старые данные атласа не объявляются обновлёнными до нового релиза.

## Источники

Русский и английский CSV берутся из одного актуального PAK с SHA256
`365ceb7fc006633f4c2be9a38d33c2b8c8a527e4f1250f8b1579af170f16cdb6`.
Имена таблиц установлены через проверенный полный каталог архива, не по номеру
записи или похожей схеме. Его отдельный снимок:
`F:/PhoneExit Resources/Vampir/resource-config-snapshots/4760d94dc28b0156176d0cace6295da3ce130ea7e2f91798ff7b9a5b6976ae1c/manifest.json`.
Каталог получен существующим recovery reader без извлечения INI, с теми же
SHA1-проверками main/directory indexes; key в файлах и логах не сохранялся.

`build-atlas-russian.py` повторно проверяет SHA архива, каталога, immutable
CSV manifest и каждого CSV. Через encoded entry position связывает именованный
путь `CSV/L10N/en/<table>.csv` с соответствующим `ru` и извлечённым CSV offset.
Текст сопоставляется только при совпадении таблицы, уникального ключа записи
и колонки. Одинаковый английский текст с разными русскими значениями исключается.
Непереведённые и пустые строки не затирают оригинал.

Результат: 34 043 однозначных текста; 398 неоднозначных английских текстов
исключены. Словарь `maps/locale-ru.json` SHA256
`f26f83dbb7c9d240a3791549e2bcca61d0e08ec905a665efec640cf3b44a9f76`.
`maps/locale-ru-manifest.json` хранит все пути, offsets, SHA, число строк и SHA
инструмента. Большие данные остаются в библиотеке ресурсов вне Git.

## Подключение и проверки

`atlas-locale.js` загружается перед общим меню. Каждый загрузчик сначала проверяет
SHA исходного JSON, затем строит отображаемую копию с переводом текстовых полей.
Сырые `data`, `record`, `row`, `provenance`, `source` и поля `*_source` сохраняются.
Имена файлов, ссылки, хеши, числовые значения и ID не переводятся. Поля `names_en`
сохраняют прежнее техническое имя ради совместимости, но отображаемый `Name`
получает русский текст. Форматированные ReplaceString1/2 и составные подписи
обрабатываются без подстановки новых игровых значений.

При ошибке словаря показывается сообщение и исходные подписи. Словарь проверяется
по SHA. Учётные записи и язык клиента игры не меняются.

```powershell
python -X utf8 phone-exit/bots/resource-tools/vampir/build-atlas-russian.py
node phone-exit/bots/test_atlas_locale.cjs
```

UI-файлы копируются обычными builders разделов; словарь строится отдельно.
Для существующего локального атласа UI обновлён без пересборки и подмены исходных
данных. Проверены реальные переводы нескольких предметов, монстра, области и
коллекции. JS-проверка подтверждает fallback, шаблоны, неизменность ID/сырых полей
и отсутствие изменения исходного объекта. Визуальный осмотр браузера не выполнен.
