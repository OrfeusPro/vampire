# Vampir — где искать ресурсы и доказательства

Текущее знание: [сводка по темам](knowledge/TOPICS.md).
Подробные документы находятся в `knowledge/evidence/<тема>/`;
в каждой тематической странице есть список разборов.

| Данные | Каталог относительно F:/PhoneExit Resources/Vampir |
| --- | --- |
| Версии и исходные снимки | release-snapshots / patch-state-snapshots |
| Config / CDN / GMC2 | resource-config-snapshots / public-cdn-snapshots / public-gmc2-snapshots |
| Таблицы и происхождение | table-study |
| Функции и инструкции | ghidra / code-clues |
| Квесты и условия | quest-graph / quest-script-study |
| Виджеты и размеры | ui-catalog / ui-geometry / ui-layout-study |
| Карта, геометрия, каталоги | maps |
| Инструменты | tools |
| Реестр функций | knowledge/function-registry.json / knowledge/INDEX.md |

Путь, SHA, PAK entry и смещения конкретного результата хранить в подробном
доказательстве, а не подменять этим общим списком. Native / static / live
доказательства различаются. Версия данных Windows не доказывает Android parity.

[RESOURCE-HISTORY.md](RESOURCE-HISTORY.md) сохраняет прежний полный указатель
ресурсов, таблиц, provenance и последовательностей сборки. Его исторические
«следующие шаги» читать с учётом актуальных [вопросов](knowledge/questions.json).
