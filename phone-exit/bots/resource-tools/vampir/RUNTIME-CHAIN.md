# Полная цепочка данных и исполнение Vampir

15 октября 2026, модуль 1.0.7. Runtime-каталог `bots/vampir/quest-runtime.json`
собирается build-runtime-chain.py из проверенного quest-graph/index.json.
Это локальные данные телефона: ПК не требуется для каждого шага.

Каталог содержит все найденные 1353 квеста, 5944 задачи, 3892 записи действий
игры, 26 обучений, 139 учебных шагов и 94 UI-ключа. Сохранены предшественники,
параметры, условия, последовательность записей, координаты, флаги и происхождение.
Серверные действия из таблиц не исполняются ботом; ими управляет сама игра.
Порядок записей не подменяет ещё не восстановленную семантику ветвлений.

## Что сейчас исполняется

18 пар визуальная подсказка/цель связаны с точными TutorialStep:
1001 — панель квеста, 4002 — Drain, 4003 — первая экипировка,
4009 — Bloodshape. Привязки воспроизводимо создаёт build-tutorial-bindings.py,
проверяя хеши CSV и UI-ключи. Ссылка из каталога сама по себе не разрешает клик:
нужны свежие совпадения подсказки и цели на одном кадре.

При подтверждённом нажатии движок определяет TutorialId/Step и кандидатов
QuestTask. Если кандидат единственный, status.activePoint содержит
`quest:<id>/task:<id>/tutorial:<id>/step:<n>`. Это последняя визуально наблюдавшаяся
стадия, а не прочитанное серверное состояние. При возврате к HUD поле очищается.
Ожидаемый следующий шаг берётся из каталога и показывается в reason во время
ожидания; исполнение всё равно требует его визуального подтверждения.

Данные полной цепочки включены, но распознавание всех 139 учебных шагов и
автономное прохождение всех 1353 квестов не реализованы и не заявляются.
Неподдерживаемая стадия останавливает ввод; чужой контрол не выбирается наугад.

## Задержки, зависания и безопасная вариация

- Минимум после действия — 2 с либо больший параметр ожидания из исходной
  таблицы. Для Drain это 4.5 с. Сверху добавляются случайные 0.15–0.65 с.
  Субсекундная точность не обещается: цикл распознавания может длиться дольше.
- Смещение клика до 3 px на базовом 1280×720, с учётом масштаба кадра.
  Ограничивается безопасной внутренней частью найденного rect, с полями 2 px.
  Без известной области вариация не применяется. Для клика от угла подсветки
  используется малая область вокруг проверенного центра, а не весь экран.
- Если цель временно не найдена при известной подсказке, ожидание до 20 с.
  Никакого клика по прошлым координатам в это время нет.
- Повтор по той же подсказке — не ранее 8 с, по новому кадру; максимум 2 попытки,
  затем понятная ошибка. Неизвестный экран ограничен 120 с.
- Закрытие World Map и завершённого Bloodshape — по двум якорям заголовок/выход,
  после ожидания 8 с, одна попытка и проверка исчезновения в пределах 20 с.
  Распознанное обучение имеет приоритет перед закрытием окна.
