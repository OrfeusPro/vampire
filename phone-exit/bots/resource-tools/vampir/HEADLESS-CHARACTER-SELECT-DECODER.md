## Оставшаяся необязательная таблица

В основном блоке персонажа поле `+0x98` содержит необязательную таблицу.
В памяти клиента запись занимает `0xf0` байт: ключ находится по смещению `0`,
значение — по смещению `+8`. Размер записи в памяти не равен её размеру в пакете.

| Участок | Адрес | Подтверждённое действие |
| --- | --- | --- |
| Чтение заголовка | `0x1456d7ae0` | Читает признак присутствия, затем количество записей |
| Чтение записи | `0x1456da4b0` | Читает байтовый ключ, находит значение и вызывает его reader |
| Поиск / вставка | `0x1456d37a0` / `0x1456d33f0` | Повторный ключ использует существующую запись |
| Чтение значения | `0x145796480` | Читает скаляры, поля времени и вложенные массивы |
| Вложенный блок | `0x145796df0` | Читает время, число, массив u32 и логическое поле |
| Элемент массива | `0x145796d60` | Читает два байта и два u32; второй байт ограничивает значением 2 |

Без элементов вложенных массивов значение занимает 108 байт в пакете.
Первый массив хранится в значении по смещению `+0x50`, второй — по `+0x88`.
Первый элемент кодируется как `<BBII`, второй — как `<I`. Количество элементов
каждого массива передаётся отдельным u16. Значение перечисления в поле `+0x28`
ограничивается числом 3. Ненулевые логические поля нормализуются в 1.
Поля времени сохраняются как необработанные u64; единицы измерения не установлены.

Проверены отсутствие и пустое содержимое таблиц, ключи 0 и 255, вложенные массивы
с 1, 2 и 8 элементами, коллизии хеш-таблицы и повторные ключи. Обе таблицы
прочитаны вместе со всеми 11 основными массивами ответа. Повторный ключ заменяет
значение; прежние вложенные массивы при этом очищаются. Счётчик лимита учитывает
все переданные записи, включая впоследствии заменённые.

## Общий декодер

Модуль: [character_select_result.py](../../vampir-shared/vampir_core/character_select_result.py).

```python
from vampir_core.character_select_result import decode_character_select_result

body = decode_character_select_result(
    payload,
    max_payload_size=4096,
    max_collection_items=256,
)
wire_vector = body.player.at(0x188)
wire_heading = body.player.at(0x1a0).raw_byte
```

Лимиты в примере — локальная политика вызывающего кода, а не ограничения сервера.
Декодер требует оба лимита явно. Он проверяет полноту тела, отсутствие лишних
байтов и корректность текста. Лимит коллекций общий для всех массивов и таблиц,
включая вложенные записи и повторные ключи.

`SelectionRecord.at(offset)` возвращает поле по подтверждённому смещению данных
в объекте клиента. Указатели vtable и служебная память не переносятся. Поля времени
представлены по смещению их u64-данных. Записи и вложенные коллекции неизменяемы;
их содержимое скрыто из стандартного `repr`.

Необязательные таблицы представлены как `None` при отсутствии и как кортеж пар
`(key, record)` при наличии; пустая таблица — пустой кортеж. Пары отсортированы
по ключу. Поля с неизвестным назначением не получили предположительных имён.

`WireVector3.bits` сохраняет исходные биты трёх float32. Метод `finite_values()`
возвращает конечные числовые значения либо отклоняет NaN/Infinity.
`WireHeading.raw_byte` хранит исходный байт направления: это значение до
нормализации математикой клиента, описанной в [предыдущем отчёте](HEADLESS-CHARACTER-SELECT-RESULT.md).
Декодер не назначает вектору систему координат и не выдаёт его за мировую позицию.

## Проверки и границы

Сценарии `replay-character-select-maps.py` исполняют целое тело ответа, функции
чтения, поиска, вставки и обновления значений клиента. Хранилище таблицы,
выделение памяти, очистка массивов и перестроение корзин ограничены тестовыми
реализациями. Поиск повторного ключа проходит по настоящим цепочкам клиента;
распределитель памяти и время жизни объектов этим не проверены.

Сценарии `replay-character-select-fields.py` дополнительно проверяют ненулевые
скаляры и строки: пустую, ASCII, кириллицу, CJK и emoji. Общий декодер сверяется
с результатами чтения векторов, массивов, обеих таблиц, скаляров и текста.
Короткие тела, лишние байты, неверный UTF-8 и превышение общих лимитов отклоняются.
Пройдено 36 проверок цепочки персонажей и 3 проверки целостности экспорта Ghidra.
