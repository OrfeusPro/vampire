## Что проверено

Целый packet writer `0x1456bb7d0` вызывает CreateData writer `0x14578e120`,
затем appearance writer `0x14578ddd0`. Таблицы packet / data / appearance и
элемента массива сверены с текущим EXE. Элементы создаются native constructor
`0x145783f30`, их table `0x149921f68` содержит writer `0x14578c800`.
Настоящие scalar aliases и преобразование UTF-16 → UTF-8 выполняются native;
raw output append, allocation / copy / free / cookie — ограниченные fixtures.

`replay-release-character-create-writer.py` проверил 42 тела. Включены
пустые строки, Unicode, ASCII длиной 15 / 16 / 127 / 128 / 129 символов,
80 иероглифов, пустой / непустой массив внешности. Полные байты совпали с
независимым описанием формата и переносимым encoder. Исходный объект не меняется.
Тридцать шесть базовых комбинаций соответствуют входам прежней проверки reader.
Длинные строки дополнительно проверяют ветви временного буфера и allocation.

Writer сохраняет сырые байты enum / bool; clamp 2 / 45 и нормализация bool
происходят в reader. Поэтому запись и последующее чтение значения 255 не
обязаны сохранять значение поля. Допустимость такого значения в игре не доказана.

В 24 отдельных случаях искусственный raw output fixture возвращал отказ.
На четырёх позициях, относящихся к длине / содержимому двух строк, native writer
продолжил запись и вернул успех с отсутствующим фрагментом. На остальных
позициях остановился с отказом. Это поведение при заданном контракте fixture;
оно не доказывает поведение реального архива при нехватке памяти или сокета.
Проверка сохраняет точную последовательность записей и пропущенный фрагмент.

## Код и границы

Переносимый `vampir_core.character_create` принимает `CharacterCreatePayload`
и полный SHA источника. Сначала проверяет все поля, затем возвращает целое
immutable тело без transport header. Embedded NUL и некорректный Unicode
отклоняются; локальные бюджеты — 4096 UTF-8 байт на строку и 256 элементов.
Это ограничения памяти нашего кода, а не найденная политика имён сервера.
Неверный SHA отклоняется. Код не открывает сеть и пока не подключён к worker.

Команда из `phone-exit/bots`:

```powershell
python -X utf8 -m unittest test_vampir_character_create_writer
```

Проверка `release-character-create-writer` зарегистрирована вместе с входными
зависимостями. Авторизация, игра и создание персонажей не выполняются.
Native report:
`F:/PhoneExit Resources/Vampir/code-clues/release-character-create-writer/ebb9ce5badc95e22c550f3983ecf962c291e1390b3b8edc5a009c82ec50d4e3e/manifest.json`.
SHA256 совпадает с именем каталога. Ghidra artifact dependencies перечислены
в `research-checks.json`; точные инструкции UTF-8 leaf сохранены в report.

Полный producer, допустимый ID Carnage из UI, генерация JSON внешности,
выбор допустимых байтов / элементов, политика имени и ответ ID 104 ещё не
проверены. Encoder намеренно не подставляет класс или внешность по умолчанию.
Следом проверить источник игровых значений и reader / handler ответа создания;
отправлять запрос можно только после принятого пустого списка нужного сервера.
