## Сервер карты

`serve-ui-prototype.py --detached` также использует одноразовую задачу Windows.
Он слушает только 127.0.0.1, сообщает собственный PID / порт / root, срок по
умолчанию 24 часа. `--lifetime-seconds 1..86400` ограничивает отдельный запуск;
обычный foreground сохраняет прежнее управление Ctrl+C. Определение задачи
удаляется после readiness, триггеров автозапуска и повышения прав нет.
Для явной остановки отдельного UI-сервера используется собственный PID из
readiness (`Stop-Process -Id <PID>` после сверки процесса); игра этим не закрывается.

`test_vampir_ui_server_owner.py` проверяет настоящий отдельный сервер после
выхода launcher: HTTP bytes, immutable cache / nosniff и закрытие listener по
собственному timer. При закрытии Windows может сначала дать reset / timeout;
тест требует окончательного ConnectionRefused, а не считает timeout успехом.
Тест прошёл; 24-часовой реальный срок ожиданием не проверялся.
Существующий foreground UI-сервер заменён отдельным; game owner не трогался.
