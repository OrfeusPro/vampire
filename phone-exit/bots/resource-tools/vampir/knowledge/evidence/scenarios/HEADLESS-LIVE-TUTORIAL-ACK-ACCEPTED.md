# Сервер принял начальное подтверждение обучения

22 октября 2026. После добавления трёх новых телефонов выполнена одна игровая
попытка через Redmi M2006C3LG / JP. Самостоятельный клиент работал без процесса
игры. Runtime подтверждения добавлен коммитом `eacf4c8`; в момент проверки
HEAD — `9d636e3`, последующие изменения касались записей исследования.
EXE SHA256:
`98802d550890354da73cfef101bc49c1691f104beccb8b6d878594ba8952807e`.

## Вход и результат команды

Прямой WebRTC-канал прошёл `connecting → connected`, SOCKS достиг готовности.
Аккаунт `bot-hk-test@vampir.top`, JP / server ID 256, Franz 2, character index 0.
Использован свежий SDK / лобби контекст. Получено:

| Этап | Результат |
| --- | --- |
| Game Version / Game Login | code 0 / 0 |
| Список персонажей | code 0, одна запись |
| Выбор персонажа | code 0, полностью разобранное тело 4724 байта |
| Вход в мир | ID 204 и ID 206 code 0, серверная целевая позиция получена |
| Состояние обучения | один ID 9905: flag false, 16 записей |
| Явная команда | одна ID 9903: key 1001, selector 2, raw18 0 |
| Ответ | один ID 9904, code 0, `accepted`, unmatched results 0 |

В ID 9905 запись 1001 имела raw0c 0, raw10 0, state 1. Остальные 15 записей
имели raw0c / raw10 / state 0. Отправку разрешили свежий снимок этого же
соединения и успешный ID 206. Ответ принят только после полной передачи
кадра сокету и совпадения key 1001 / selector 2 в ID 9904.

Получен один ID 17; ошибок соединения и обработки не зарегистрировано.
Запрошенный предел наблюдения — 20 секунд, но проверка завершилась раньше
при получении результата команды. Это не новая проверка длительной сессии.

Сокет закрыт владельцем проверки. Временный маршрут завершился с code 0;
автоматического повторного входа / отправки нет. Самостоятельная карта в этой
попытке не подключалась; игровые окна и кнопки не воспроизводились.

## Что доказано и что остаётся

Игровой сервер принял конкретное подтверждение обучения 1001 / 2 после
успешного headless-входа. Это первая живая проверка
[подключённой команды](../../../../../vampir-headless/README.md#текущее-состояние).
Прежние [два BlockedIp](HEADLESS-LIVE-INITIAL-TUTORIAL-ACK.md) относятся к другим
выходам; [Pixel](../network/HEADLESS-LIVE-PIXEL-CHANNEL.md) не установил прямой канал.

ID 1836 / выбор квеста не отправлялся. Автоматическое перемещение, выполнение
задания и фактическое нажатие QuestPanel_PanelTouch не доказаны. Сводка сохраняет
результат корреляции и code 0, но не поля записи / флаги из самого ID 9904.
Поэтому новое устойчивое состояние обучения после подтверждения ещё неизвестно.
Нельзя из одного `accepted` заключить завершение квеста или запуск движения.

В счётчике также есть по одному ID 1827, 1840 и 1854; содержимое этих тел
не сохранялось. Это кандидаты для привязки к квестовым данным, не доказанные
события прогресса. Следующий этап — добавить ограниченное чтение нужного
состояния квестов / обучения и связать действие панели с серверной записью.
