`d00a197796b7cee30f46854b2a8579049726c2bfba542d359f41b3817ec8b960`.
Продолжение [привязки входящего ID 1854](HEADLESS-QUEST-SYNC-ENTRY-11316.md).

## Формат и настоящие типы

Constructor 145828a10 и вложенный leaf 1457a2a70 исполняются целиком.
Проверяются packet vptr 1499654c0, nested vptr 149948c10 и getter ID 1854.
Reader 1456b70d0 передаёт packet+0x10 в настоящий nested reader 1457a66b0.
Тип не подставляется вручную, как в отозванном прежнем suffix ID 1802.

Все числа little-endian. Count — uint16. Минимальное тело — 10 байт:

1. Count групп.
2. Для каждой группы: byte raw08 с clamp до 12, count квестов, записи Quest.
3. После всех групп: uint64 raw18, сохраняемый без потери точности.

Quest занимает 39 байт: uint64 raw08, byte raw10 с clamp до 6,
Progress (byte raw08 без clamp и два uint64), bool raw38 и три uint32
raw3c / raw40 / raw44. Ненулевой bool нормализуется в true.
Группы не объединяются и не фильтруются по неизвестному игровому смыслу enum.
Названия, текущая задача, завершённость и разрешение следования не выводятся
только из этих wire-полей.

## Целая native проверка

replay-quest-sync-11316.py использует закреплённые Capstone 5.0.6 / Unicorn 2.1.4,
18 явных unwind roots, source-bound leaf bytes и 7 Ghidra exports. Контекст:
knowledge/native-contexts/quest-sync-11316.json. Общий harness допускает до 24
явных roots вместо 16, чтобы вместить readers / callbacks и общий archive;
автоматического обхода callees нет, неизвестный переход останавливает проверку.

Исполняются outer / nested / group / Quest / Progress readers, archive input
loop, оба callbacks, reserve wrappers и leaf typed copy 145781e90.
Leaf имеет явный call entry и заканчивается RET на 145781f05; обе внутренние
ветви находятся в закреплённых 118 байтах. Отсутствие unwind не обходится
подстановкой угаданного начала функции в Ghidra.

96 целых тел покрывают 0 / 1 / 2 / 8 групп, столько же квестов в каждой,
raw 0 / 1 / 6 / 7 / 12 / 255, крайние uint64 и независимые поля прогресса.
Все final records сравниваются с portable decoder после native typed copies
и cleanup временных объектов. Освобождённые temporary buffers заполняются DD;
доступ к ним вместо итоговой копии не может дать правильные поля. Проверены
vptr, counts / capacities и guards входного тела, packet и всех allocations.
Все 172 коротких префикса составного тела отклонены; cursor не выходит за тело.
Это все префиксы тела с двумя группами по два Quest, не всех крупных вариантов.

Allocation, cleanup / free и raw archive memcpy — ограниченные fixtures.
Нативный allocator / destructor, повторное использование непустых arrays,
growth и application handler не проверены. Fixtures допускают максимум восемь
элементов коллекции; это граница эксперимента, не лимит игрового сервера.
Сохранение всех scalar-полей не доказывает активный список квестов.

## Portable ограничения и совместимость

Decoder требует явные max_collection_items / max_total_items / max_payload_size.
Общий бюджет считает группы и вложенные Quest; превышение отклоняется до
чтения элементов. Неверный SHA, mutable body, короткий / лишний ввод и неявные
лимиты отклоняются. Частичный результат наружу не возвращается. Tuple records
и frozen dataclasses не допускают общую изменяемую коллекцию между владельцами.
Raw ключи / suffix скрыты из repr.

Существующий decode_quest_record повторно использован с явным текущим SHA;
старый SHA сохранён. Его прежние 3 теста прошли. Общий harness после изменения
проверен текущим ID 9905: 73 тела / 835 коротких префиксов прошли.
Новый test_vampir_quest_sync_11316.py: 4 теста, включая всю native матрицу,
проверку источника, бюджетов, точности, clamps и trailing bytes, прошли.
Проверка зарегистрирована как native-quest-sync-11316.

Отчёт в библиотеке ресурсов, SHA равен имени каталога:
`code-clues/quest-sync-11316/d8cbe5f6c8e2e751d7467bca803108868421899d38cd0e3598aaf350111e514f/manifest.json`.
Контекст закрепляет SHA exports, точные leaf bytes и virtual / descriptor bindings.

Действующий Itel owner не перезапускался и пока не загружал новый decoder.
Начальное тело ID 1854 не сохранялось. Следующий шаг — изолированная модель
полученного сообщения, ограниченная выдача API и правая панель через адаптер.
Старые данные / fixture не выдавать за текущий список этого персонажа.
Существующий журнал этой сессии сохранил только metadata: ID 1854 — 64 байта
(seq 43), ID 1827 — 8 байт, ID 1840 — 36 байт. Длину нельзя подменять
реконструированным по предположению содержимым списка.
