22 октября 2026. EXE SHA256:
`98802d550890354da73cfef101bc49c1691f104beccb8b6d878594ba8952807e`.
Продолжение [повторной проверки](HEADLESS-QUEST-REFUSAL-RECHECK.md).

## Статические пары имён и значений

В явной функции `0x1457da4e0` найдены пары указателей на строковый объект
и целочисленное значение. Для трёх записей проверены инструкции построения
строки, её локальный адрес, запись int и два соседних указателя пары:

| Значение | Имя | Инструкция записи значения |
| --- | --- | --- |
| 0 | Success | `0x1457edce4` |
| 58 | BlockedIp | `0x1457df7c7` |
| 100 | CharacterNotSelected | `0x1457e140e` |

Для 100: строка CharacterNotSelected передаётся в `0x141426a30` по
`0x1457e13e6`; объект находится в `[rbp+0x52e0]`. Его адрес сохраняется
в `[rbp+0x75f0]`; int 100 — в `[rbp+0x380]`, адрес этого int — в
следующем `[rbp+0x75f8]`. Следующая строка CharacterTitleAlreadyAcquired
относится к следующей записи: считать ближайшую строку после MOV именем
текущего значения было бы ошибкой. Аналогично проверены 0 и 58.

`inspect-release-result-names.py` сверяет полный SHA EXE, закреплённый
Capstone 5.0.6, chained unwind root, полное декодирование его диапазонов
и точные инструкции выбранных пар. При несовпадении строки, адресов слотов,
соседства пары или неоднозначности инструмент завершается ошибкой.
Он не исполняет native string constructor / map insertion / lookup.

Вход функции статически получает строку, ищет её в локальном словаре
и возвращает int; при отсутствии записи возвращает `0x15fb1`.
Общий dispatch ID 1802 и применение этого lookup конкретным handler
не восстановлены. Соответствие общего словаря фактическому серверному
code 100 обосновано именем пары и известными 0 / 58, но серверный код
и причина формирования отказа недоступны.

## Что это меняет

В новой сессии Login / список / выбор / ID 206 приняты с кодом 0, но запрос
квестов с 0 / 0 получил 100. Имя в клиенте — CharacterNotSelected,
то есть «персонаж не выбран». Это отдельное значение от BlockedIp / 58.
Не установлено, какой именно выбор / контекст проверяет сервер.
Qword запроса ещё нельзя объявлять идентификатором персонажа только по имени
ошибки. Требуется найти штатное заполнение поля или точный lifecycle запроса.
Новый вход или подбор параметров в этом исследовании не выполнялись.
