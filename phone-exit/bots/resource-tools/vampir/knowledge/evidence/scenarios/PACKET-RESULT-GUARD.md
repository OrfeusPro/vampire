# Vampir: разрешение обработки результата пакета

Продолжение [UNLOCK-RESULTS.md](UNLOCK-RESULTS.md), 16 октября 2026.
Изучена функция 0x1467a8e10, которую оба unlock-handler вызывают перед передачей
списка в контекст. Это логика клиента, не сетевые запросы и не новый retry бота.

## Источник и повторение

`python phone-exit/bots/resource-tools/vampir/build-packet-result-guard.py`
создаёт `F:/PhoneExit Resources/Vampir/code-clues/packet-result-guard.json`.
EXE SHA256:
`c7552efd2125e7981945d3443cc1d70a41ac0a8a4cb42e7c77e0d40b4713dfc8`.

Проверяются 25 опорных инструкций, границы guard, таблицы переходов, SHA локализации
CSV405 и пять связей ключ→строка. Отчёт содержит 252 инструкции guard, восемь
фрагментов вспомогательных функций, 227 записей dispatch и исходные строки CSV
с логическим csv_record. Широкая таблица результатов не подписывается guessed enum.

## Что пропускается дальше

ECX сохраняется как результат в EBX. По полю объекта от 0x14558edf0 проверяется
byte+8==1; символическое имя этого режима неизвестно.

| Путь | Результат | Наблюдаемое поведение |
|---|---:|---|
| Режим byte+8==1 | 0 | Очистка временного значения, AL=true |
| Режим byte+8==1 | ненулевой | Очистка, AL=false; обычный switch пропускается |
| Обычный режим | 0 | Ветка 0x1467a91d6, затем AL=true |
| Обычный режим | 4503 (0x1197) | Вызов 0x145f8a7a0 в 0x1467a91d1, затем AL=true |

Имя результата 4503 не найдено в извлечённых native enum и не придумано.
Общий вызов обработки ошибки для этого кода не означает запрет продолжения.
При false оба unlock-handler выходят, не обновляя список; при true идут
в ранее связанный update. Нельзя заменить guard универсальным result==0.

Остальные ветви содержат специальные действия и общий путь false, но их имена
и все побочные эффекты ещё не восстановлены полностью. В частности, вызов
callee с кодом не доказывает, что окно показалось или пользователь его подтвердил.

## Компактная таблица и границы кода

Код заканчивается перед 0x1467a9228. Внутри unwind-диапазона дальше идут данные:
четыре RVA по 0x1467a9228 и 227 байтов-селекторов по 0x1467a9238.
Код нормализует result-0x519, ограничивает индекс значением 0xe2,
читает selector, затем RVA цели. Это два этапа, а не 227 адресов функций.

Генератор проверяет размеры, границы инструкций всех целей и selector<4.
Selector1 используется для 0x523/0x524 и ведёт в 0x1467a902f;
selector 2 — для 0x5f1/0x5fb и ведёт в 0x1467a9137. Остальные селекторы
ведут в общий путь 0x1467a91f5. Данные не дизассемблируются как код.
Четыре теста защищают размеры, индекс selector, границы целей и сохранение ID.

## Сообщения связаны с ресурсами

| Инструкция ключа | Ключ | English CSV405, csv_record | Текст |
|---|---|---:|---|
| 0x1467a8eb2 | NAME_SLANDER | 77 | Contains forbidden terms. |
| 0x1467a8fb6 | GUILDINVENTORY_SLOT_FULL | 5541 | Insufficient Clan Storage space. |
| 0x1467a9093 | ASSET_MAXVALUE_ERROR_MAIL | 948 | Exceeds the max obtainable [AssetName], cannot be claimed. |
| 0x1467a9137 | GUILD_INVITE_NOTUSER_MESSAGE | 2885 | Character not found. |
| 0x1467a916d | CHAT_SPAM_MSG | 2647 | Due to frequent chat usage, please wait a moment before using chat again. |

NAME_SLANDER хранится в EXE как ASCII; остальные четыре ключа — UTF-16LE.
Кодировки проверяются отдельно. Для [AssetName] здесь виден путь подстановки,
но конкретный ресурс, лимит и актуальный запас персонажа по нему не вычисляются.

## Общий путь сообщения и ограничения UI

Default helper 0x145f8a7a0 сначала пропускает коды 0 и 42 без общего сообщения.
В других ветвях получает данные/текст через 0x145bdd0d0/0x145be6830,
при отсутствии записи — через 0x1458091b0, затем вызывает UI-manager0x144a279d0.
Полная привязка этих getter к таблице ошибок ещё не восстановлена.

UI-manager не продолжает этот путь при длине текста<=1 или byte+0x2c4==1.
Иначе передаёт текст/аргументы в 0x144a1c510 через tail-jump с подобъектом+0x770.
Конкретный WBP, его размеры и видимость пока не связаны. Поэтому наличие вызова
обработчика ошибки не является доказательством показанного попапа.

Следующий шаг — принимающая диспетчеризация до OnHandler и привязка общего
сообщения к WBP/макету. Автоматические клики, повторы запросов и player evaluator
по этому отчёту не включались; Android не проверен.
