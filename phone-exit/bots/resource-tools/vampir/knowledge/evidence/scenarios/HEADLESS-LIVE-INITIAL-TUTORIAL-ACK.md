## Доступность телефонов и TLS

Первый отдельный Node-скрипт показывал пустой каталог. Причина установлена
по запросам: `UNABLE_TO_VERIFY_LEAF_SIGNATURE`. Directory сохраняет прежний
список при сетевой ошибке; в новом экземпляре сохранённого списка не было.
Пустой результат этого скрипта не доказывал отсутствие телефонов.

Локальный API в это же время показывал доступные HONOR CLK-LX3 / JP,
Redmi M2101K6G / JP, OnePlus IN2010 / HK и ROG ASUS AI2201_B / NL.
Повтор отдельного Node-запроса с `--use-system-ca` дал HTTP 200 для всех
трёх запросов и тот же набор свежих устройств. Для дочернего Node маршрута
использован `NODE_USE_SYSTEM_CA=1`. Проверка TLS оставалась включённой;
профиль аккаунта не заменялся.

При повторении диагностики не объявлять телефоны недоступными по одному
пустому результату: сверить локальный API, успешность запроса каталога и TLS.
Не выводить account / feed tokens, pairing data и тела запросов авторизации.
