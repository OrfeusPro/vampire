## Формат

Целый ID 9905 состоит из флага bool, количества uint16 и массива записей.
Запись содержит три uint32 little-endian и байт состояния, ограничиваемый
native reader значением 3. Размер тела — `3 + 13 * count` байт.

| Поле объекта | Wire | Текущая интерпретация |
| --- | --- | --- |
| Вложенный объект +8 | bool | Смысл флага ещё неизвестен |
| Элемент +8 | uint32 | Ключ записи в receiver; точный тип ID ещё не установлен |
| Элемент +0xc | uint32 | Сохранено как raw0c |
| Элемент +0x10 | uint32 | Сохранено как raw10 |
| Элемент +0x14 | uint8 | `min(wire, 3)`, имена состояний ещё не установлены |

Связи текущего кода: constructor `0x14584d070`, getter `0x145857190` → 9905,
notify reader `0x1456b83a0`, вложенный constructor leaf `0x1457fee70`,
reader `0x1457ff1e0`, descriptor `0x149961ef0`, callback `0x1457ff270`,
таблица элемента `0x14992afc0`, reader элемента `0x1457ff150`.
Callback создаёт запись размером 0x18 и переносит прочитанные поля в массив.

Лёгкий `tutorial_update.py` требует current SHA, явные лимиты байт / записей
и точный размер тела. Неканонический ненулевой bool принимает как true,
state ограничивает как native. Поля пока не названы tutorial_id / step_id:
такие имена без consumer / таблиц были бы догадкой. Decoder не отправляет
игровые запросы и пока не подключён к обработчику сессии.

`0x1467c229b`, регистрация `0x1467c22ae`, handler table `0x149dc72b8`,

В псевдокоде receiver раннее состояние клиента `<6` откладывает копию пакета
в очередь. Позже записи обрабатываются по первому uint32 ключу; отдельно
проверяется переход state 1 → 2. Reader может быть верным, а применение
пакета — ещё преждевременным: в runtime нужно сохранить это различие.

Ghidra показывает shared branches за пределами короткого начального диапазона
receiver. Эти ветви пока изучены по псевдокоду, не проверены native replay.
