# Прогресс входящего задания: текущая native-проекция

Источник 1.13.16: SHA256
`d00a197796b7cee30f46854b2a8579049726c2bfba542d359f41b3817ec8b960`.
Явный root `145de4610` получен отдельно от неполного chained constructor:
`ghidra/request-exports/<SHA>/run-b865a737d979/details.json`, полный SHA
`e62dea7abd45aa48ce27bcf3ee8c1290fe9ca8991bf5e95792049c8da4c62452`.
Все 259 байт / блоки функции разобраны. Псевдокод сверяется с инструкциями.

`145de4610(output, questKey, progress)` вызывает lookup `145b4be70` с адресом
ключа. Pointer getter `141500410` читает первый qword wrapper.
Если результат ненулевой, байт `progress+8` читается **со знаком** и
сравнивается с int count `array+8`. При `index < count` функция читает
pointer из `array.data[index]`. Отдельной проверки `index >= 0` здесь нет.
Отсутствие такой проверки не разрешает runtime принимать отрицательные индексы.

При ненулевой записи задачи результат получает:

| Offset результата | Источник |
| --- | --- |
| +0 | qword `task+0x40` |
| +8 | byte результата virtual `task.vtable+0x30` |
| +9 | исходный byte индекса |
| +0x0c | low32 `progress+0x10` |
| +0x10 | low32 `progress+0x18` |
| +0x18 | ноль |

При отсутствии массива / неподходящей верхней границе / null task вызывается
диагностика, затем записываются нулевой ключ, kind `1F`, index `FF`, нулевые
счётчики и хвост. Padding +0x0a..0x0b / +0x14..0x17 не инициализируется здесь.
`FF` не считать разрешённым индексом команды.

`replay-quest-progress-11316.py` исполняет всю функцию и настоящий getter
в закреплённом Unicorn. Проверены 324 сценария: ключи 0 / 110120 / UINT64_MAX,
индексы 0 / 1 / 2 / 127 / 128 / 255, count 0 / 2 / 128, отсутствие lookup,
null task / найденная запись, обе ветки освобождения диагностических объектов.
Проверяются точный результат, возвращаемый pointer, неизменность входных данных,
guards и порядок вызовов. Старшие 32 бита счётчиков специально ненулевые.
Для отрицательных индексов явно выделены синтетические слоты, чтобы показать
фактическую адресацию, не обращаясь к произвольной памяти.

Lookup, virtual kind задачи и форматирование / вывод / освобождение диагностики —
явные fixtures. Это не whole application ID 1854 и не источник реального массива.
