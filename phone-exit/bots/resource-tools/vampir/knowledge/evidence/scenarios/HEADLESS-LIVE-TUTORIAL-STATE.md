## Что подключено

В `exchange_game_login` добавлен явный callback `tutorial_observer`.
Он разрешён только вместе с завершением входа в мир; без него прежняя
обработка сопутствующих пакетов сохраняется. ID 9905 читается с лимитами
65536 байт / 4096 записей. Очередь не превышает 64 уведомлений.
Уведомления сохраняют исходный порядок и передаются callback после ID 206.
При закрытии очередь очищается, callback получает None. В публичной сводке
появляется только счётчик `tutorial_notifications_decoded`, без записей.

Это наблюдение прочитанных серверных данных после headless-перехода,
а не полная эмуляция native lifecycle. Уведомления не объединяются в
«активное обучение», не запускают сценарий и не нажимают панель автоматически.
Смысл флага пакета и двух полей прогресса ещё неизвестен.

Сквозная передача callback добавлена в `probe-selected-game-login.py` и
`run-map-session.py`. Карта пока показывает позицию; панель обучения ещё
не подключена к feed.
