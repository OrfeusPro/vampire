# Повторное использование проверок публикаций v3

Обычный update выбирает `update-native-drivers-v3` по машинному
`knowledge/native-publication-engine.json`. Обёртка использует прежний native
driver и те же stage keys; заменён только publication recipe.
[Точные входы, guards и отчёты](AUTO-NATIVE-PUBLICATION-V3-11322.json).

Замер неизменного v2 обнаружил 376 вызовов `_row`, 820 `_tools` и 68 `_snapshot`.
Их совокупное время без двойного учёта вложенности — около 90,7 из 180,8 с.
Новый слой запоминает проверенные rows, tools и SHA только в одном invocation.
Row memo связан с SHA всего mutable index; собственная запись сбрасывает его.
Разные model instances сравниваются, dependency maps заново вычисляются перед
итогом. Полные SHA файлов, реестров, runtime и sources проверяются в финале.
Aliases проверяются до и после барьера. Подмена при прежних size/mtime не
проходит; возвращаемые копии не позволяют испортить memo.

Снимок v2 сохраняется целиком и совпадает с прежним проверенным снимком.
Новый guard кода v3 хранится отдельно и входит в собственный ключ v3.
Первый переход допускается только через точную завершённую квитанцию v2 либо
полную frozen adapter validation. Новые квитанции сохраняются исключительно
в `native-publication-v3`, pointers — в `native-publication-cache-v3`.
Старый namespace не переписывается. Изменившийся рецепт получает другой ключ;
его нельзя скрыть под прежним guard. Повреждённая квитанция даёт конкретный
блокер, не молчаливый fallback. Записи появляются только после финального барьера.

Реальный первый проход 34 семейств занял 106.622635 с:
102 этапа из кэша, 34 проверенные v2-привязки и 34 новые квитанции v3.
Второй проход занял 104.879736 с: 102 этапа и 34 квитанции v3 из кэша,
новых записей нет. Прежний инструментированный v2 проход — 180,813571 с,
неинструментированный owner-v3 — 184,722085 с. Это измерение выбранных 34 семейств,
не полного обновления с SHA-аудитом установки и обработкой ресурсов.
Native / JVM / native PE rebuild в обоих новых проходах — 0.
Прежние v2 pointers, generated indexes и facts сохранили SHA.

Прошли 1240 инфраструктурных тестов, 22 из них новые: 20 publication и две
проверки выбора recipe / маршрутизации. Три прежних symlink-теста пропущены
из-за прав Windows; новые проверки выполнены полностью. Проверены bridge,
первый полный publish, повтор memo, смена guard, tools / runtime / index,
порча данных после попадания в memo, alias retarget, сохранение unrelated rows
и запрет повторного использования закрытой сессии.
Независимое read-only review новых admission-дефектов не выявило.

59 прежних frozen native inputs, publication v2 и самостоятельный scoped research
сохранены. Текущая сессия / профиль не переключались. Целый ordinary CLI update,
новые client contracts и онлайн-допуск ещё требуют своей проверки.
