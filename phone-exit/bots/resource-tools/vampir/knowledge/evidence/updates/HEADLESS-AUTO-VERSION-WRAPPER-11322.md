# Привязка обёртки Version 1.13.20 → 1.13.22

Из RIP-ссылок на нужную таблицу автомат выбирает единственную пару
загрузки и записи указателя в объект. Он проверяет границы инструкций
и функции по PE unwind. Слот таблицы `+0x48` указывает на опубликованный Version prepare.
Для исходного клиента проверяется зарегистрированный конструктор. Смещение
записи относительно начала конструктора совпадает на обоих клиентах.

На целевом SHA функция `0x1467cf880` загружает таблицу
`0x149dcc128` инструкцией `0x1467cf964`. Слот указывает
на `0x1467d1ba0`. Неоднозначность, другая инструкция записи и неверный
слот оставляют проверку открытой.

Все четыре проекции прошли. Статически перенесены 160 сценариев записи
и восемь сценариев tag. Первый проход занял 10.856 с.
Повтор занял 5.741 с и использовал четыре записи из кэша.
Новых JVM и native-сценариев было ноль. Общий набор завершил 1476 тестов
с тремя прежними пропусками.

Проверена связь записи таблицы со слотом Version. Полный конструктор,
установленный клиент и игровой вход в эту приёмку не входят. Статус допуска
остаётся partial.
