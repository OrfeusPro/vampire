# Полный update и окончательный SHA установленной игры

Обычный `knowledge-index.py update --auto` на коммите `ecdae00d` завершился
состоянием `needs_review` за 1181,524819 секунды. Проверены 165 архивов и EXE;
объём архивов — 22 717 689 618 байт. 215 этапов использованы из кэша, включая
108 resource stages и 34 portable native семейства. Все 35 native checks
вернули passed; новых native-прогонов и JVM — 0. Каталог / привязки и результаты
контрактов пересобраны для изменённых входов. Четыре context projections
остались requires_review по недостающим полям constructor / writer.
[Машинные отчёты и точные границы](AUTO-FULL-UPDATE-INSTALLED-BARRIER-11322.json).

Новый next-profile не назначен, bundles отсутствуют. Launcher, world-session,
map, quests и game-ui сохраняют incomplete: готовые bounded проверки отдельных
семейств не заменяют целые контракты. Журнал содержит 304 наблюдения очереди
и 1176 позиций сгруппированной модели разных уровней. Это не число независимых
ручных действий; общие data / helper / schema blockers нужно разбирать пакетами.
Вход и игровые команды не выполнялись.

Заключительная проверка контроллера обнаружила отдельный пробел: mutable файлы
установки после исходного полного аудита сверялись лишь по inventory, size и
mtime. Теперь общий `installation_barrier` заново читает полные SHA через
исходный digest перед сохранением plan-only и перед публикацией next-use pointers.
Смена bytes с прежними size/mtime отклоняется. Длительность барьера сохраняется
в `installation_full_sha_barrier_seconds`.

Прошли 1243 инфраструктурных теста и шесть штатных compatibility checks.
Три новых теста проверяют EXE / PAK mutation после bundle preparation,
порядок полного SHA до publication с исходным digest и mutation при plan-only.
Три прежних symlink-теста пропущены из-за прав Windows.

Новый барьер отдельно проверен на реальных 166 установленных файлах за
20,089627 секунды против полного audit того же завершённого прохода.
AST-проверка подтверждает: кроме нового helper, двух его вызовов и метрик,
контроллер совпадает с исполненным `ecdae00d`. Поэтому прежняя полная цепочка
использована как доказательство неизменной части; resource / native проверки
заново не запускались. Это составное доказательство, а не заявление о новом
монолитном запуске всего изменённого CLI. 59 прежних native inputs сохранены.

Native publication v3 в полном проходе занял 101,886871 секунды и использовал
34 квитанции без новых записей. Общая стоимость всё ещё велика: использованы
85 068 файлов исторических ресурсов, их финальный SHA / alias barrier занял
46,702194 секунды. Следующий пакет скорости — разделение extraction / comparison /
readiness зависимостей и устранение лишних проверок неизменного отказа.
Не заменять фактические использованные SHA доверием к stamps.
