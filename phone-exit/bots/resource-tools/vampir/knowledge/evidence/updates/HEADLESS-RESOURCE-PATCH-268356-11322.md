# Ресурсный патч Revision268356 при прежнем EXE

Полная SHA-опись сверила 165 архивов и EXE установленной игры. Изменились
ровно девять PAK, добавленных и удалённых архивов нет. Полный SHA EXE
остаётся 03edad26033c85835ad8fdc1825df7aeb635e2c199055598ad926bf84b43739f; прежний source-bound код этим патчем не заменён.
Patch manifest содержит Revision268356. Номер версии интерфейса не используется
как доказательство отсутствия изменений; бинарник лаунчера отдельно не проверялся.

Применён существующий resource-pipeline-v3 с общим SHA owner v4. Обработаны
только девять изменившихся архивов. Сохранены новые record indexes, CSV,
сравнения и заключительные source / alias / full-installation barriers.
Аудит занял 60.933305 с, ресурсная обработка вместе с финальными
проверками — 391.548314 с. Native suites и Ghidra не запускались.
Текущая сессия и профиль следующего входа не переключались; watcher не включался.

Это сравнение bytes, а не логическая идентичность таблиц.

У 61 пар-кандидатов с уникальной одинаковой
схемой построены текстовые различия строк. Полный результат содержит заголовки,
число added / removed / changed rows и затронутые поля. Схема и уникальный
первый столбец не доказывают назначение таблицы или смысл игрового ID.
Изображения отдельно не декодировались; UAsset magic подтверждает формат,
а не то, что объект является картинкой.

Directory index и authoritative internal paths остаются открытыми. Поэтому
штатный план консервативно затрагивает зарегистрированных потребителей архивов:
game-ui, map-data, quests.
Обратные зависимости учитываются. Существующие missing table-baseline и
resource identity blockers не превращаются в подтверждённую совместимость.

Около 70 МБ загрузки — наблюдение пользователя, не измерение этого прохода.
Объём изменившихся архивов не равен объёму скачанных изменений. Содержимое
проверено существующими адаптерами без новой адресной привязки для данного патча.
