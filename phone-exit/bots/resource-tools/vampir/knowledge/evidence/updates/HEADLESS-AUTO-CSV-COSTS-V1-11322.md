# Повторные SHA при проверке текущих CSV

Тёплый extract использует уже подготовленные входы вместо второго полного
_prepare. Публичный load_checked самостоятельно готовит входы и завершает
свежую проверку SHA. Число полных чтений PAK внутри CSV сократилось с трёх
до двух. Итоговый SHA-барьер сохранён.

[Машинное правило](../../resource-csv-reuse.json) задаёт точный SHA прежнего
проверяющего кода. Перенос разрешён, когда все inputs совпадают, кроме этого
SHA. Проверяются текущие PAK, record index, decoder, parser, runtime, бюджеты,
содержимое CSV и accounting. Затем новый cache назначается после свежего
барьера, включающего registry, прежний cache pointer и прежний manifest.
Legacy bridge и его счётчики сохраняются. Новая provenance записывается
отдельно. Непривязанный immutable manifest после обрыва допуска не даёт.

На четырёх реальных PAK проверены 0, 1, 249 и 3094 табличные записи — все 3344
прежние записи, 2941 уникальный CSV. Полных чтений стало 8 вместо 12, что
сокращает чтение на 1006045815 байт за выбранный проход.
Результаты CSV совпали, повторного декодирования было ноль.

Медиана двух прежних вызовов составила 21.947 с, двух новых — 20.008 с. Время отдельных вызовов зависит от фоновой нагрузки.
Замеры выполнены в порядке прежний / новый / новый / прежний после завершения
общего tooling worker. Предыдущий парный замер при параллельной проверке
также сохранён в машинных доказательствах. По четырём PAK нельзя судить
о времени полного обновления 109 архивов.

Общий набор завершил 1482 теста с тремя прежними пропусками. В 28 тестах CSV
есть шесть новых случаев. Проверены точное повторное использование producer,
сохранение legacy accounting, отказ при изменённых inputs / record pointer,
поздняя подмена PAK с сохранением size/mtime, registry/cache/output corruption,
неверные JSON-структуры и размер cache. Шесть дополнительных checks прошли.

Далее остаются общий owner для промежуточных SHA и сужение консервативных
ключей кэша. Новая схема owner потребует отложенного назначения результатов
до общего финального барьера. Игровой вход этим пакетом не подтверждается.
