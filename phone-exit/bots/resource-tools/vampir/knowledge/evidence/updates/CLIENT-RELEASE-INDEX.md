# Новые индексы и CSV после обновления, 19 октября 2026

Продолжение [аудита выпуска](CLIENT-RELEASE-AUDIT.md). Все 35 новых/изменённых
архивов прочитаны с проверкой полного SHA256 из манифеста. Старые offsets
не использовались; прежняя библиотека и её индексы сохранены.

## Объём проверки

[index-release-archives.py](../../../index-release-archives.py) строит новые записи по
локальным заголовкам, сохраняя offsets, размеры, хеш каждой сохранённой записи,
хеш декодированного содержимого и наблюдаемые строки путей. Для каждого архива
сохранены SHA256 источника, инструмента, существующего scan-pak.py и Oodle DLL.
Индекс каталога PAK не расшифровывается. Строка `/Game/...` сама по себе
не доказывает имя записи в архиве или связь с игровым объектом.

Найдено 127 375 записей: 125 122 декодированы, 75 зашифрованных пропущены,
2178 пропущены по лимиту 2 МиБ; ошибок декодирования нет. Все 35 проходов
достигли начала каталога. Зафиксированы 62 167 промежутков между записями;
их содержимое не разобрано, поэтому полный охват ресурсов не заявляется.
Хеш сохранённой записи охватывает её заголовок и данные до end, не промежуток.

Сравнение наблюдаемых путей даёт 7145 новых наблюдений и 7065 отсутствующих
в отдельных архивах. Это не число добавленных/удалённых ресурсов: прежний
декодер имел лимит 32 МиБ, новый — 2 МиБ; возможны перемещения между архивами.
Четыре искомых маркера SDK проверены в ASCII/UTF-16LE; совпадений нет в
декодированной части. Это не доказывает отсутствие настроек во всём клиенте.

Корень снимка: `F:/PhoneExit Resources/Vampir/release-snapshots/` плюс SHA256
`0f179fdafc09adab377e40314fd7409428b5961dc846ac300f8f1bb6b3111114`.
Сводка: `index-summaries/0880bdc08270fdea077372c8985b6597882c7646cb4369ba6f568adee8679463/manifest.json`.
Она перечисляет все 35 отчётов и их SHA256. Имена каталогов снимков равны хешу
manifest.json; повторный запуск сверяет источник и использует проверенный кеш.

## Таблицы pakchunk1

[extract-release-tables.py](../../../extract-release-tables.py) использует новый индекс,
повторно сверяет SHA256 архива и зависимости декодера. Лимит CSV — 16 МиБ,
UTF-8 BOM; старые номера записей не используются для идентификации таблиц.
CSV сохранены отдельными файлами с именем по SHA256, прежние не заменяются.

Извлечены 1565 CSV, ошибок и пропусков по лимиту нет. 1267 совпали побайтно
с хотя бы одним старым CSV; 298 точных совпадений не имеют. Это сравнение
содержимого, не подтверждение выбора сервером конкретной версии таблицы.
Уникальная схема даёт 389 кандидатов соответствия, включая неизменённые.
Для 73 изменённых кандидатов проверены строки: 62 сравнения выполнены,
11 отклонены из-за неуникального первого столбца. Семантика ключа не выводится.

## Продолжение

U02 частичен: свежие индексы и один набор CSV готовы; зависимые квестовые графы,
UI/карты и выбор актуального override ещё не пересобраны. U03 compatibility gate
и серверная проверка отсутствуют. H04 продолжать от источника UNMSDKSettings,
не подставляя окружение или SDK URLs по догадке. EXE сохранил исследованный SHA.
Игра/аккаунты/сеть в этой проверке не использовались.

Воспроизведение: index-release-archives.py принимает путь к release manifest;
extract-release-tables.py — путь к свежему record manifest и прежнему table index.
Тесты используют искусственные заголовки/CSV: bounds, skips, неполный проход,
content match отдельно от schema candidate, quoted CSV, дубликаты ключей и diff.
