# Полная проверка базы знаний v2

Новый `knowledge-check-v2.py` сохраняет frozen consistency, Markdown-ссылки
и staged Markdown audit. При обновлении контекста `knowledge-index-refresh-v2.py`
готовит частную SQLite и выполняет один итоговый полный проход исторических SHA.
Прежние producers и ordinary-update stages сохраняются.

Команда из корня проекта:

```powershell
python -X utf8 phone-exit/bots/resource-tools/vampir/knowledge-check-v2.py
```

Флаги `--root`, `--knowledge`, `--database` выбирают библиотеку и базу;
`--output` сохраняет дополнительный JSON вне входных материалов.
Статус содержит `full_history_verified`, producer, число проходов и длительности.

Перед публикацией проверяются полные SHA входов, инструменты, Git index
и исходная база назначения. WAL / journal, алиасы назначения и параллельное
изменение базы отклоняются. SHA не кэшируются между обращениями; size / mtime
не служат подтверждением целостности. Неизменный повтор проверяет всю историю.

Проверки стабильности сравнивают конечные состояния. Атомарный снимок файловой
системы не создаётся; изменение и восстановление файла между проверками остаётся
за пределами этого контракта. Общий тестовый набор пока использует один ключ.
Пакет не доказывает работу игрового клиента и не меняет runtime admission.

## Измерение и приёмка

На независимых копиях одной базы обе команды дали одинаковое содержимое
13 логических таблиц. При обновлении контекста число чтений SHA
псевдокода сократилось с 74674 до 37337
для 37337 файлов. Время полного прохода: прежний
191.734 с, v2 160.330 с.
Это локальный замер при работающем наборе tooling-тестов; OS cache
и нагрузка влияют на время. Устранение второго прохода подтверждено
счётчиками чтений, ускорение любого неизменного запуска не обещается.

20 новых тестов и общий набор из 1989 тестов прошли; три прежних skip
сохранены. Шесть дополнительных зарегистрированных проверок прошли:
пять использовали прежние квитанции, проверка реестра заново прошла
шесть тестов после регистрации новых зависимостей. Новых JVM и игровых
native replay — ноль. Исходная рабочая база в сравнении не менялась;
59 frozen входов, прежние facts, история и пользовательские файлы сохранены.

[Машинная квитанция](AUTO-KNOWLEDGE-CHECK-V2.json) содержит полные SHA
компонентов, benchmark, проверки и точные границы. Новый тест и оба
инструмента включены в зависимости `automatic-update-tooling`
с `on_update=true`; его кеш по-прежнему отделён от клиентских проверок.
