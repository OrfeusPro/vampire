# Подготовленный офлайн-кандидат Vampir 1.13.22

Исходный EXE имеет SHA256
`03edad26033c85835ad8fdc1825df7aeb635e2c199055598ad926bf84b43739f`.
`build-game-candidate-current.py` собирает неизменяемый пакет для проверки
игрового запуска. В него входят SDK Launcher, семь областей переноса прежнего
candidate, композиция игрового VersionResult, CharacterList, clock/Ping,
обработка временной зоны и чтение нового ответа лобби. Сборка использует
сохранённые доказательства и сверяет полные SHA входов. [Машинная квитанция](GAME-CANDIDATE-CURRENT-VALIDATION.json).

Базовый `DefaultGame.ini` связан с установленным `ProjectRED-Windows.pak` и
полной описью релиза. Он задаёт CDN для `real` / `1.13.22`. В двух независимо
привязанных текущих контекстах Version и Login совпадает compiled tag
`4138E0A8C7421BE4F7F7078FF635DAD5`. Сборщик сверяет указатель и литерал по байтам
установленного EXE. Приоритет активных настроек движка остаётся отдельной проверкой.

## Лобби

Текущий reader ID 2 исполнен вместе с INPUT, buffer, scalar, UTF-8 и TimeBase
providers. Пройдено восемь полных входов, 45 коротких префиксов, восемь отказов
чтения и случай с хвостом. На стороне Python сохраняются все поля результата.
Переносимый decoder требует точной длины. Выделение памяти, присвоение FString
и frees в проверке используют стенд. Отдельный Windows binder удерживает
результат в объекте вместе с Login и явно отмечает состояние metadata.

Пять отсутствовавших функций подготовки и записи собраны в `run-6204f055a2a7`.
Нормализатор сверяет каждую инструкцию и полное покрытие PE unwind ranges.

| Роль | Адрес | Инструкций |
| --- | --- | --- |
| LoginPrepare | `0x1467d1200` | 222 |
| VersionPrepare | `0x1467d2cf0` | 256 |
| Version writer | `0x14575b5d0` | 58 |
| Login writer | `0x14575afc0` | 75 |
| ServerList writer | `0x14575b3a0` | 43 |

У `LoginPrepare` сохранены точные callsites конструктора и send wrapper,
а также две проверки флагов SDK и VersionResult. Эти пять функций проверены
статически. Предыдущий Ghidra проход `run-13a51593255f` остановился на строгой
проверке unwind coverage у send wrapper `0x144aaf380`. Его частичный экспорт
сохранён как диагностика. Для допуска остаётся исполнить связку подготовки
с реальными для этой ветви входами и подтвердить контракт передачи пакета.

## Создание Viper

Проверены 24 случая свежего выделения и копирования полей из CDO. Клиент вызывает
`memset` для свежего объекта, затем конструктор и копирование полей по metadata.
Состав отражённых полей и шаблон CDO в этих случаях заданы в стенде. Актуальный
загруженный пресет требует отдельной проверки. [Доказательство CDO](../characters/HEADLESS-VIPER-CDO-CURRENT.md).

Пакет Create содержит 18 тел ID 103, 18 отказов записи и 12 случаев внешнего
читателя ID 104. Три текущих writer и два конструктора исполняются вместе с
source-checked dispatch. Запись строк и отдельных элементов остаётся fixture.
ID 104 вызывает вложенный reader даже при ненулевом коде, если поле кода прочитано.
Вложенный reader в этой композиции задан стендом. Готовое доказательство
CharacterList удерживается отдельно. Для создания нужны текущий producer,
загруженные поля Viper и полный Result 104 с обработчиком.

## Воспроизведение

Из корня проекта выполните сборку. Для проверки существующего пакета передайте
его полный SHA, напечатанный первой командой.

```powershell
python -X utf8 phone-exit/bots/resource-tools/vampir/build-game-candidate-current.py
python -X utf8 phone-exit/bots/resource-tools/vampir/build-game-candidate-current.py --check $candidateSha
```

`game-candidate-current`, `lobby-wire-current`, `viper-cdo-current` и
`create-packets-current` подключены к `on_update` и своим группам тестов.
При попадании в кэш guard проверяет выбранные доказательства и входы.
Большой установленный PAK проверяется потоковым SHA через manifest кандидата.
Обычный scope receipt хранит указатель на этот manifest и остальные входы.

Кандидат собран для офлайн-проверок. Текущий игровой допуск и отдельный допуск
создания остаются открытыми. Для Silvercrow последним подтверждённым онлайн
этапом остаётся SDK SignIn. [Результат SDK-входа](../auth/HEADLESS-FIRST-SDK-PROFILE-CURRENT.md).
