## Запуск

```powershell
$raw = python -X utf8 phone-exit/bots/resource-tools/vampir/build-bounded-world-current.py
if ($LASTEXITCODE -ne 0) { throw 'Профиль входа не подготовлен' }
$profile = ($raw | ConvertFrom-Json).selected_profile
python -X utf8 phone-exit/bots/vampir-headless/run-bounded-world.py --account $accountId --profile $profile --detached
```

`$accountId` берётся из локальной панели. У аккаунта должны быть назначены
сервер, слот и подтверждённый ключ. В игре выбирается ключ, найденный в новом
списке. Владелец запускается одноразовым заданием Windows без триггеров и
лимита времени. Его состояние доступно на `127.0.0.1:17947` через `GET /sessions`
и `GET /bots/{accountId}/state`. Для группы можно повторить `--account`.
Одновременно авторизуются до двух аккаунтов. `--port` задаёт отдельный порт
владельца для другого набора аккаунтов. Состояние отказавшего аккаунта доступно
через тот же API, пока другие сессии группы продолжают работать.

## Проверки и автообновление

- Select 110 переносится с `c7552efd`, Finish 206 с `98802d550890`.
  Два reader используют новые пределы 97 и 8. Восемь сценариев конструктора
  и 15 сценариев reader проверяют текущие native bytes и отказы чтения.
- Агрегат проверяет целые nested функции, таблицы и общие зависимости.
  Проекции сверены на 322 сценариях Select и 42 сценариях Finish из готовых
  доказательств. Связь с Clock/Ping сохраняется в неизменяемом пакете.
- `world-player-constructor-current`, `world-select-clamps-current`,
  `world-results-current` и `bounded-world-current` подключены к `on_update`
  и контрактам выбора, входа, позиции и heartbeat. Повтор проверяет SHA
  сохранённых доказательств. Новый SHA требует доказательств для новой версии.
- [Приёмка](BOUNDED-WORLD-CURRENT-ACCEPTANCE.json) фиксирует 60 групп,
  2255 тестов, четыре пропуска и повтор за 65,4 с без новых процессов и
  native replay.

Пакет допускает выбор, вход и удержание текущего соединения. Серверный флаг
персонажа по умолчанию, HP/MP, проекция карты, движение и квестовые команды
требуют собственных доказательств. Фактическая онлайн-проверка хранится отдельно
от подготовленного профиля.
