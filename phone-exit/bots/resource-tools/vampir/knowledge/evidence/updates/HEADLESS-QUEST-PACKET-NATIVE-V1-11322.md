# Автоматическая проверка входных пакетов квестов и обучения

Штатный обновлятор выполняет полные ограниченные native-сценарии QuestSync
1854 и Tutorial 9905 через новый proof-bound harness. Результаты сохраняются
отдельно для двух семейств и используются при неизменном повторе. Текущий
source SHA — 03edad26033c85835ad8fdc1825df7aeb635e2c199055598ad926bf84b43739f.

## Что исполнено

Готовый статический перенос предоставляет два контекста и 22 уникальные
основные функции. Семь существующих экспортов использованы повторно,
15 недостающих получены одним явным запросом. Harness сверяет полный SHA
EXE, контекст / transfer proof, whole unwind instruction spans всех roots,
точные bytes leaves и используемые table bindings. Допуск к эмуляции
восстанавливает статическую closure один раз на общий SourceStore.

QuestSync прошёл 269 входов. Успешная матрица содержит 96 комбинаций
числа групп / квестов 0, 1, 2, 8 и raw 0, 1, 6, 7, 12, 255.
Проверены все 172 обрезанных префикса тела 2 × 2 и один случай с хвостом.
Tutorial прошёл 909 входов. Проверены 73 успешных комбинации, включая
64 записи, все 835 обрезанных префиксов и один случай с хвостом.
Итого 1178 входов — 169 valid, 1007 truncated и два trailing.

Успешные случаи сверяют vptr / ID, число и capacity записей, каждый raw
скаляр, clamp / bool и suffix. Обрезанные случаи обязаны вернуть отказ
и точное число потреблённых байтов. Хвостовые случаи отдельно фиксируют
успешное чтение тела с двумя оставшимися байтами. Матрица отчёта сверяется
целиком с учётом типов значений. Ожидания задаются синтетическими wire
полями, без изменения runtime decoder allowlists.

## Память, ABI и границы модели

Новый harness проверяет Win64 stack alignment / return, shadow space,
nonvolatile GPR и XMM6–15. Разрешены только выбранные инструкции, прямые
и виртуальные fixture callers из исходных exports. Чтения и записи
ограничены packet / archive, текущим входом, живыми allocations и стеком.
Записи в источник запрещены. Memcpy ограничен текущим входом, размером
скаляра и объявленным выходом. Growth вызывает конкретную ошибку.

Storage fixtures создают свежие обнулённые буферы. Максимум — восемь групп
и восемь квестов в каждой либо 64 tutorial records. Временные quest-буферы
отравляются после free, разрешения на их чтение и запись снимаются.
Финальная проекция проверяется после этого. Guard bytes входа / объектов /
allocations и счётчики cleanup / free проверяются во всех применимых случаях.
Повторное использование storage, тела настоящих allocators / destructors,
handlers, активный квест и игровые команды требуют следующих проверок.

## Обновлятор и повтор

[Selector](../../quest-packet-native.json) включает два stages после INPUT
seed и статического переноса. Новые экспорты получает штатный collector
пакетами до 32 адресов. Журнал содержит quest_packet_native, а результаты —
quest-packet-native-checks-v1 библиотеки. Ключ учитывает оба source identities,
точный static proof, exports, код scenarios / harness, runtime и lineage.
Повреждённый отчёт, неверная матрица, пробел exports или изменённый источник
становятся конкретным blocker. Финальная проверка перед публикацией сверяет
материалы и тот же завершённый scoped Owner после SourceStore / installed SHA.

При первом компонентном запуске обнаружен пробел передачи готового research
export в общий scoped pointer. Collector выполнил дополнительный export batch
и записал указатель. Оба native stages завершились за
38.681504 и
37.32166 с.
Сохранённые этапы восстановлены из durable журнала после несовпадения
ожидаемого счётчика stages. Повторного native исполнения при восстановлении
не потребовалось. Два свежих повтора заняли 4.248983 и
4.44688 с — четыре cached stages, ноль новых JVM, transfer,
PE builds и native исполнения. История дополнительного экспорта сохранена.
