## Обход map

Пять synthetic maps: пустая, индексы [0,1,2], [0,2,31], [31,32,65]
и [0,127,128,129]. Последняя использует внешний массив битов, остальные —
встроенный. Начальное выделение JSON-объекта и virtual getter — fixtures,
но обход и переход к следующему индексу исполняются настоящими инструкциями.

Setter1415F2570 перехватывается: проверяются receiver объекта, адрес key
и адрес value = key+10. Получены ровно занятые индексы, в исходном порядке;
пустые слоты не передаются. Размер записи входной map — 28 hex байт.
Это подтверждает выбор записей и указателей, но не семантику отдельных значений
и не native копирование key/value во внутренний JSON storage.

## Преобразование в строку

Для каждого значения третьего аргумента 0/1 проверены девять случаев:
null value, тип 5 вместо требуемого 6, отказ virtual getter, отсутствие pair,
null object, отказ writer, отказ первой проверки скобки, отказ второй и успех.
Всего 18 сценариев, порядок вызовов проверяется отдельно от конечного результата.

Первые пять отказов не вызывают writer. Для пригодного объекта ветвь 0 вызывает
1415E5EA0, ветвь 1 — 1415E4E20. Возврат writer=false сразу ведёт к отказу;
при true вызываются две операции над строкой и два последовательных predicate.
Первый получает UTF-16 `{`, второй `}`, длину 1 и flag1. Исходные ASCII literals
находятся по 148A14DDC и 14950C940, bytes проверены.

Writer fixture намеренно создаёт непустой частичный результат и при false.
Outer wrapper144489150 в каждом отказе возвращает исходный output pointer,
обнуляет оба поля FString и освобождает частичную строку ровно один раз.
При успехе сохраняет полученный буфер без освобождения. Temporary writer holder
имеет исходный refcount3; native cleanup уменьшает его до 2. Деструкция при
последней ссылке здесь не выполнена.

## Границы и следующий шаг

Constructor/getter/setter объекта, engine writers, строковые predicates и
postprocessing, выделение/освобождение — fixtures. Writer всегда выдаёт одну
synthetic строку; это не проверка настоящего JSON writer, экранирования,
форматирования, чисел, массивов и вложенных объектов. Shared control block
исходного объекта null; ветви его удаления не выполнены.

`native_execution=true`, `network_used=false`, `profile_activation=false`,
`compatibility=not_established`. Runtime бота, профиль, реальные credentials
и онлайн-сессия не изменялись. Успех replay не считается успешным HTTP или квестом.

Далее связать caller fields/credential с map и serializer, проверить сами writers
и response getters/dispatch с SDK context. Тип 6 и handoff writers подтверждены
в пределах этих сценариев; фактическое содержимое запроса ещё неизвестно.
