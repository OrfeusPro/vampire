# Стабильный PATH групповых проверок Vampir

Ключ кэша учитывает `PATH`, который фактически получают воркеры Windows.
Временные каталоги запуска Codex под `.codex/tmp/arg0-windows` и версионные
каталоги `OpenAI/Codex/bin` исключаются в обоих местах. Аудит проверил ссылки
на их инструменты в зарегистрированных входах. Найденные команды Git используют
обычный `PATH`, PowerShell и Python запускаются по заданным путям.

Правило проверяет точного родителя внутри `USERPROFILE` или `LOCALAPPDATA`
и формат имени каталога. Остальные записи сохраняют порядок. Изменение
эффективного `PATH` меняет ключ. Перед запуском воркера runner сверяет
отпечаток этого пути с определением группы.

Миграция кэша выполнила 27 групп и 2037
тестовых случаев за 302.033 с, включая одну новую регрессию.
Все прежние 2036 case IDs сохранены с исходной кратностью. Число пропусков
равно 4. Регрессия проверяет окружение настоящего воркера,
попадание в кэш после ротации служебных путей и пересчёт при добавлении обычного пути.

Затем в полном проходе заменили служебные записи Codex. SHA исходного `PATH`
изменился, SHA пути воркера совпал. Повтор использовал 27
групп за 13.463 с при 0 запусках.
Исторический сброс кэша был связан с SHA `PATH`. Состав исторического пути
по одному хэшу восстановить нельзя. Приёмка воспроизводит именно ротацию двух
известных видов служебных каталогов.
