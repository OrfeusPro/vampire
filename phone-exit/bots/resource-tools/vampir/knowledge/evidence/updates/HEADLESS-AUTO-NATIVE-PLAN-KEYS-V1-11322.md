# Подготовка native-контекстов и выбор затронутых контрактов

[Машинное правило](../../native-materialize-scope.json) отделяет регистрацию
проверок от подготовки native-контекстов. Удаляются только research-checks.json
выбранного knowledge и test_*.py внутри bots. Остальные definitions, source,
contexts, function reuse, tools и generated index остаются в ключе.

Правило закрепляет SHA десяти модулей — весь native.TOOLS и function-reuse-plan.
Если изменён любой из них или выбран custom knowledge, подготовка использует
прежние полные definitions. Это сохраняет консервативный режим при новой
логике чтения входов. Сам selector входит в общие definitions и итоговые
проверки. Frozen native engines сохраняются.

На текущем дереве число файлов в части definitions ключа сократилось с 1248
до 828. Статическая подготовка на сохранённом EXE выполнилась один раз.
Два повтора взяли Journal cache, включая моделирование изменения исключённого
тестового SHA. Реальные файлы сохранили свои хэши. Полученные declarations
сохраняют прежние source и границы; runtime admission не повышается.

План affected теперь сопоставляет полные пути зависимостей относительно
workspace. Одинаковое имя файла в другом каталоге не затрагивает потребителя.
Выбор варианта проверки выполняется существующим workflow.source_definition
для текущего и прежнего SHA. Variant заменяет базовые поля. Правки чужого
variant и переопределённых базовых dependencies не создают лишних причин
перепроверки. Изменение выбранной проверки, удаление dependencies и смена
test pattern затрагивают соответствующие контракты и их обратных потребителей.
Старый journal без source identity сохраняет консервативное сравнение.

Общий набор завершил 1526 тестов с тремя прежними пропусками. Отдельный
controller check завершил 40 тестов. Добавлены три сценария контроллера
и десять проверок плана. Контроллер подтверждает reuse native stage после
изменения test / check registry и пересчёт после изменения native metadata.
Проверены code / custom knowledge fallback, неизвестный scope, same-basename,
selected / foreign variants, overrides, удаление, test-pattern location,
общий helper и транзитивные обратные зависимости. Исходные объекты плана
сохраняются. Шесть дополнительных checks прошли.

Полный updater, native-сценарии и JVM этой приёмкой не запускались.
Состав остальных tool groups остаётся консервативным. Дальнейшее сужение
требует собственного доказательства фактически используемых зависимостей.
Полный проход с последними изменениями остаётся отдельной приёмкой.
