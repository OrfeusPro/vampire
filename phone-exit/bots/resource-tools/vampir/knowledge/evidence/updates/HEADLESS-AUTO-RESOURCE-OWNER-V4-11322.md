# Общий владелец SHA ресурсов v4

[Selector](../../resource-owner-engine.json) подключает owner к штатному
pipeline. Он закрепляет root, knowledge, index, SourceStore и исходный digest.
Первое чтение считает полный SHA. Следующие потребители используют этот
результат в одном owner. Прочитанные manifests и CSV blobs регистрируются
в общей closure. Runtime, decoder, tools, дополнительные pins, reference
snapshot / activation / active pointer также входят в проверку.

Индекс возвращает pending до owner.finish. Перед назначением кэша owner
заново читает все использованные файлы исходным digest, проверяет aliases,
optional inputs и summary inventory. Разрешение путей и identity arguments
кэшируются внутри owner, а root / knowledge aliases проходят свежую сверку
до и после общего барьера. Затем сохраняется immutable barrier receipt.

Новые CSV и comparison cache pointers ждут общего барьера. Повторный запрос
видит pending результат в памяти. Назначение использует готовый временный
файл и hard link с проверкой уже существующего значения, без перезаписи
другого результата. Неудачный барьер не назначает новые pointers. При
ошибке назначения после успешного барьера часть уже заработанных pointers
может сохраниться; следующий owner проверит их заново. Abort и неудачный
begin закрывают owner. Повтор запуска начинает новый epoch и свежие SHA.

Standalone CSV и index сохраняют собственные свежие проверки. Внешний
installed-file barrier перед bundle publisher остаётся отдельным.
Изменение содержимого runtime файлов проверяется в общей closure. Состав
runtime остаётся в прежних границах CSV-проверок.

На четырёх реальных PAK индекс, CSV и потребитель выходов проверили все
3344 ранее полученные табличные записи. Первичный и финальный проходы PAK
сократились с 16 до 8 полных чтений. Выходные CSV pointers совпали.
Медиана прежнего компонента — 24.028 с, нового — 23.491 с.
Чтений стало вдвое меньше, выигрыш по времени в этом замере небольшой.

Это выбранный компонент. Полный process с config / reference, все 109 архивов
и установка целиком этим замером не проверялись. Decoder / native replay /
JVM / игровой вход не запускались. Назначение новых pointers и ошибки
проверены на временных fixtures; финальный реальный замер использовал готовый
кэш. Перенос с исходного v3 producer остаётся подключённым по точному правилу.

Общий набор завершил 1515 тестов, включая 33 новых. Три прежних symlink
теста пропущены. В 24 owner-тестах проверены late mutations, сохранённый stat,
SHA conflicts, aliases, cache races, abort/retry, identity и восемь
одновременных читателей. Интеграции покрывают pending CSV, index inventory,
reference mutation после её барьера и позднюю подмену comparison pointer.
Шесть дополнительных checks прошли.

Далее остаются сужение консервативных ключей и измерение полного ordinary
update. Сопоставление функций и онлайн-допуск сохраняют отдельные проверки.
