# Однократная серверная проверка первого шага 110110

7 ноября 2026 после одного согласованного перевхода Bipoberiho в мир `10010`
свежий `1854` показал состояние `2` и индекс `0`. После отправки одного `1810`
ответ `1811` для этого квеста вернул код `0`, состояние `2` и индекс `1`.
В новом независимом процессе продолжили приходить ответы heartbeat. Последний
полученный список `1854` относится к моменту до отправки и содержит индекс `0`.
Переход подтверждён по `1811`.
[Живое наблюдение](QUEST-TIME-PROBE-CURRENT-ONLINE.json).

Для текущего EXE `03edad26033c85835ad8fdc1825df7aeb635e2c199055598ad926bf84b43739f`
подготовлен отдельный профиль запуска. Он использует проверенный формат `1810`,
строку Time `110110010` и наблюдатель `1811` из текущих доказательств.
[Таймер и очередь](HEADLESS-QUEST-TIME-CURRENT.md).
[Наблюдатель ответа](HEADLESS-QUEST-REPLY-OBSERVER-CURRENT.md).

Проверка отвечает на вопрос, примет ли сервер первый Time-шаг с координатами
точки входа. При явном запуске для одного персонажа процесс ожидает успешный
`206` в мире `10010` и свежий `1854` с единственной записью квеста `110110`
в состоянии `2` на индексе `0`. Перед отправкой проверяются тот же персонаж,
мир, положительный HP и окно свежести 30 секунд. Выдержка с входа составляет
минимум 0,1 секунды. XYZ читаются из `206` этого соединения. Историческая
поправка высоты и значения из HTTP не участвуют в запросе.

Процесс ставит в очередь один `1810` с `TargetId=0` и ждёт до 15 секунд.
Переход считается подтверждённым при `1811` для того же персонажа, мира и
квеста после полной отправки кадра, с кодом `0`, состоянием `2` и индексом `1`.
Локальная сводка различает отказ, ответ без перехода и неизвестный исход.
Проба сохраняет результат отдельно от последнего списка `1854`, а неизвестный
исход прекращает попытку. Эти данные проверяют только первый шаг. Для
исполнения других задач и движения по карте действуют отдельные контракты.

Источник XYZ в сводке обозначен `world_move_finish_result`. Фактическая
позиция после коррекции в движке остаётся отдельной проверкой.
[Расчёт позиции и открытые входы](../characters/HEADLESS-OWN-POSITION-CURRENT.md).

Профиль строится явной командой. Он закрепляет EXE, архив, исходную таблицу
задач, проверки Time, `1810`, `1811` и код исполнения. Обычный профиль
входа сохраняет прежний набор операций. Исполнение пробы требует отдельного
флага, одного аккаунта и нового процесса владельца.

```powershell
python -X utf8 phone-exit/bots/resource-tools/vampir/build-bounded-world-current.py --quest-time-probe
python -X utf8 phone-exit/bots/vampir-headless/run-bounded-world.py --account $accountId --profile $selectedProfile --port $port --detached --quest-time-probe
```

После запуска результат доступен в `quest_time_probe` состояния владельца.
Проверки порядка, корреляции и отказов зарегистрированы для контракта `quests`
в `quest-time-server-position-probe-current`. Проверка формата `1810`
и Time lifecycle используют сохранённые доказательства. При смене клиента
профиль требует новые доказательства для точного SHA.

## Проверка второго шага

Для индекса `1` подготовлен отдельный вариант того же профиля. Он закрепляет
подтверждённый переход `0 → 1` и проверенную строку Time `110110020`.
Команда допускается только при новом `1854` со статусом `2` и индексом `1`.
Запрос содержит `TargetId=0`, индекс `1` и точку `206` нового соединения.
Для подтверждения нужен связанный `1811` с кодом `0`, состоянием `2` и индексом `2`.

```powershell
python -X utf8 phone-exit/bots/resource-tools/vampir/build-bounded-world-current.py --quest-time-probe --time-probe-index 1
```

Команда запуска принимает полученный `selected_profile` с прежним флагом
`--quest-time-probe`.

После одного согласованного перевхода Bipoberiho 7 ноября 2026 новый `1854`
показал состояние `2` и индекс `0`. В прошлой сессии связанный `1811`
вернул индекс `1`. Из-за расхождения новый процесс завершил пробу со статусом
`ineligible_step` до постановки `1810` в очередь. Переход `1 → 2` остаётся
открытым, персонаж онлайн. Следующая проверка должна различать прогресс в одном
соединении и состояние в списке после входа. Причина расхождения неизвестна.
[Живое наблюдение второго входа](QUEST-TIME-PROBE-INDEX1-ONLINE.json).

## Диалог с Чумой и маршрут по тропе

Текущие строки `QuestTask` задают Time на индексах `0` и `1`, затем диалог
`110110030` «Оцените текущую обстановку». Для класса Viper в таблице указан
диалог `11011110`. В нём Чума говорит «Вы наконец очнулись. Следуйте за мной».
Явная задача перемещения `110110050` стоит на индексе `5`, после обучения
`1001`. Она задаёт цель `(129522, 83557, −9452)` и радиус `100` в Param.
[Связи и происхождение русских реплик](HEADLESS-QUEST-DIALOGUE-CURRENT.md).

`WorldSpot 10010011` совпадает с серверной точкой входа в `10010`.
`NpcSpawn` содержит в этом мире две записи для `NpcInfoId 10021` «Чума».
Одна рядом с точкой входа `(131775, 81646, −10955)`, другая рядом с целью
тропы `(129409, 83675, −9439)`. Это точки из таблицы. Живой экземпляр NPC
и условие его доступности остаются открытыми. Использована именованная опись
`43204e85a3d2c4f5bb11581264688ca7f1b1502206f59d36f70fd1145a55cc2d`.
SHA256 `WorldSpot` — `7d35e500a5498bcd14ea816d3c3b4bf9d349c5b221e455f54c6e9117e22ed70b`,
`NpcSpawn` — `4bb8be8dedfd5ee6a493b64cc1e4758f52a91c2f9c3bee02018ef7923bb86907`.

В ранее записанном входе первые четыре `1810` (`0`, `1`, `2`, `3`) имели одну
и ту же тройку XYZ и `TargetId=0`. Между ними клиент не посылал `305`.
Эта запись показывает порядок в наблюдавшемся сценарии. Реакция текущего
сервера на второй шаг остаётся открытой.
[Происхождение записи](HEADLESS-QUEST-TIME-CURRENT.md).

## Два Time-шага в одном соединении

Новый вариант профиля закрепляет две строки Time и живой результат `0 → 1`.
Первый запрос требует свежий `1854` с индексом `0`. Второй допускается после
связанного `1811` с индексом `1` в том же соединении и выдержки `0,1` секунды.
Если приходит новый `1854`, он должен согласоваться с индексом `1`.
Отказ, потеря ответа, смена персонажа или мира останавливают пробу.
Связанный `1811` с индексом `2` завершает проверку перед диалогом.

```powershell
python -X utf8 phone-exit/bots/resource-tools/vampir/build-bounded-world-current.py --quest-time-probe --time-probe-chain
```

Запуск использует новый `selected_profile` и флаг `--quest-time-probe`.
Проверки цепочки входят в `quest-time-server-position-probe-current`.

7 ноября 2026 после одного согласованного перевхода Bipoberiho подтвердил
`0 → 1 → 2` в одном соединении. Свежий `1854` содержал индекс `0`.
В журнале по порядку записаны две постановки `1810` в очередь и два связанных
`1811` с кодом `0`, состоянием `2` и индексами `1` и `2`. Проверка завершилась
перед диалогом `110110030`. Персонаж остался онлайн. Последний `1854`
по-прежнему относится к моменту входа. Сохранение шага `2` при перевходе
остаётся открытым.
[Живое наблюдение двух переходов](QUEST-TIME-PROBE-CHAIN-ONLINE.json).
