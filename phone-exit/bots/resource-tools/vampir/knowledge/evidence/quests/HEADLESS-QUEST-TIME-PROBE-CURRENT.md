# Однократная серверная проверка первого шага 110110

Для текущего EXE `03edad26033c85835ad8fdc1825df7aeb635e2c199055598ad926bf84b43739f`
подготовлен отдельный профиль запуска. Он использует проверенный формат `1810`,
строку Time `110110010` и наблюдатель `1811` из текущих доказательств.
[Таймер и очередь](HEADLESS-QUEST-TIME-CURRENT.md).
[Наблюдатель ответа](HEADLESS-QUEST-REPLY-OBSERVER-CURRENT.md).

Проверка отвечает на вопрос, примет ли сервер первый Time-шаг с координатами
точки входа. При явном запуске для одного персонажа процесс ожидает успешный
`206` в мире `10010` и свежий `1854` с единственной записью квеста `110110`
в состоянии `2` на индексе `0`. Перед отправкой проверяются тот же персонаж,
мир, положительный HP и окно свежести 30 секунд. Выдержка с входа составляет
минимум 0,1 секунды. XYZ читаются из `206` этого соединения. Историческая
поправка высоты и значения из HTTP не участвуют в запросе.

Процесс ставит в очередь один `1810` с `TargetId=0` и ждёт до 15 секунд.
Переход считается подтверждённым при `1811` для того же персонажа, мира и
квеста после полной отправки кадра, с кодом `0`, состоянием `2` и индексом `1`.
Локальная сводка различает отказ, ответ без перехода и неизвестный исход.
Проба сохраняет результат отдельно от последнего списка `1854`, а неизвестный
исход прекращает попытку. Эти данные проверяют только первый шаг. Для
исполнения других задач и движения по карте действуют отдельные контракты.

Источник XYZ в сводке обозначен `world_move_finish_result`. Фактическая
позиция после коррекции в движке остаётся отдельной проверкой.
[Расчёт позиции и открытые входы](../characters/HEADLESS-OWN-POSITION-CURRENT.md).

Профиль строится явной командой. Он закрепляет EXE, архив, исходную таблицу
задач, проверки Time, `1810`, `1811` и код исполнения. Обычный профиль
входа сохраняет прежний набор операций. Исполнение пробы требует отдельного
флага, одного аккаунта и нового процесса владельца.

```powershell
python -X utf8 phone-exit/bots/resource-tools/vampir/build-bounded-world-current.py --quest-time-probe
python -X utf8 phone-exit/bots/vampir-headless/run-bounded-world.py --account $accountId --profile $selectedProfile --port $port --detached --quest-time-probe
```

После запуска результат доступен в `quest_time_probe` состояния владельца.
Проверки порядка, корреляции и отказов зарегистрированы для контракта `quests`
в `quest-time-server-position-probe-current`. Проверка формата `1810`
и Time lifecycle используют сохранённые доказательства. При смене клиента
профиль требует новые доказательства для точного SHA.
