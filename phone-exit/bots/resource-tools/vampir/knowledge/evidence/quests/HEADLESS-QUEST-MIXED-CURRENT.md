# Совместная загрузка задач с фильтром сервиса

Клиент 1.13.22, SHA256
`03edad26033c85835ad8fdc1825df7aeb635e2c199055598ad926bf84b43739f`.
Пакет соединяет [основной загрузчик](HEADLESS-QUEST-LOADER-CURRENT.md)
и [политику сервиса](HEADLESS-QUEST-SERVICE-CURRENT.md) в одной памяти.
Готовые экспорты и CSV используются повторно.

## Проверяемая композиция

16 запусков целого основного загрузчика обрабатывают 12 исходных строк.
Шесть строк квеста 110120 имеют пустую группу, шесть строк 200110 используют
группу `10000`. Задаются регионы 0–7 и прямой / обратный порядок строк.
Для регионов 0–4 native код создаёт 12 записей и два массива групп.
Для 5–7 остаются шесть записей и одна группа, исключённые ID отсутствуют.
В 156 проекциях индекс считается отдельно внутри массива каждого QuestInfoId.
Итого исполняются 172 Win64-вызова и 23 целые функции.

Парсер, хранилище и выделение памяти используют новый версионированный helper.
Готовые проверки русского override и policy сохраняются отдельными квитанциями.
В этом сценарии secondary vtable клонируется в ограниченную память, только
slot `+0x40` заменяется явным provider русского override с нулевыми эффектами.
Перед этим сверяются исходный slot и инструкции dispatch.
Сервисные записи и TLS задаются ограниченными fixtures из текущих CSV.

Проверка подключена к штатному `on_update` как `quest-mixed-loader-current`.
Кэш учитывает исходный EXE, архив, таблицы, экспорты, код и среду выполнения.
[Контекст](../../native-contexts/quest-mixed-current.json) и
[машинная приёмка](QUEST-MIXED-CURRENT-VALIDATION.json) фиксируют границы.
Контекст покрывает этот полный SHA. Для изменившегося клиента требуется
подтверждённый перенос привязок и новое доказательство композиции.

```powershell
python -X utf8 -m unittest discover -s phone-exit/bots -p test_vampir_quest_mixed_current.py
```

Активный регион, выбранный объект задачи и executor остаются открытыми.
После [реального перевхода](HEADLESS-QUEST-LIVE-REENTRY-CURRENT.md) приоритет
первого действия определяется полученным квестом 110110. Композиция каталога
сохраняется для дальнейших цепочек с непустой группой сервиса.
