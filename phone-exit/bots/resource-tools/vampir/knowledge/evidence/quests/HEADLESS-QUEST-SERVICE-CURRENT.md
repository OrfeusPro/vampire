# Фильтр непустой группы квестовых задач

Клиент 1.13.22, SHA256
`03edad26033c85835ad8fdc1825df7aeb635e2c199055598ad926bf84b43739f`.
Пакет продолжает [загрузку задач 110120](HEADLESS-QUEST-LOADER-CURRENT.md).
В текущем `QuestTask.csv` 1 627 строк используют группу `10000`, ещё 4 317 строк
имеют пустую группу. Фильтр группы связан с тем же входом загрузчика.

## Источники и исполняемая цепочка

Проверяются целые функции фильтра `145a4d700`, получателей таблиц `145bff820`
и `145bff6a0`, политики `145c03670` и поиска фазы `145bfefd0`.
Три недостающие функции экспортированы одним scoped collect, готовые фильтр
и политика используются повторно. Именованные CSV взяты из принятого текущего
архива. [Контекст и точные SHA](../../native-contexts/quest-service-current.json).

Таблица `ServerServiceGroup.csv` задаёт группу, регион, границы фазы и списки
серверов. `ServerGroup.csv` содержит фазу конкретного сервера. Каноническая
запись Canon 1 имеет ID `387` и `ServicePhase=10000`. В памяти сценария карты
и записи построены из выбранных исходных строк CSV. Политика сама проходит
цепочки коллизий, список записей региона и поиск фазы сервера.

Для группы `10000` и Canon 1 явно задаются регионы 0–7. Значения 0–4 сохраняют
строку, 5–7 исключают её. В группе `7000` сервер `140` разрешён списком, хотя
фаза `10000` выше верхней границы `9999`. В группе `8000` тот же сервер исключён
списком при подходящей фазе. Canon 1 служит контролем для отсутствия в списках.
Проверяются встроенные и внешние таблицы хеш-бакетов.

24 сценария проходят 24 проверки Win64 ABI. Для каждого фиксируются входы
в целые функции, выбранная ветка, результат `AL`, обращения к CRT и 524 вызова
ограниченных providers за весь прогон. Менеджеры, таблицы и исходные записи
сохраняются, временные выделения освобождаются с проверкой контрольных байтов.

Загрузчик `QuestTask` вызывает фильтр по адресу `145b5fab7`, проверяет `AL`
и при ненулевом результате переходит к следующей строке. Точные байты
`CALL → TEST → JNZ` и адрес назначения закреплены в проверке источника.
Эта ветка располагается до чтения ID и создания записи.
Экспорты загрузчиков таблиц также сверены с исходными PE-диапазонами. Один
восьмибайтный выравнивающий NOP `145c08278` отсутствует в листинге Ghidra;
его точные байты и отсутствие прямых переходов в него проверяются отдельно.

## Границы и продолжение

Регион и ID сервера заданы сценарием. TLS изображает уже инициализированные
менеджеры. Операции со строками, выделение и освобождение памяти имеют
ограниченные providers, числовое преобразование использует Windows CRT
с проверкой SHA и локали. Активные значения региона и загрузка таблиц
в работающей сессии остаются открытыми.

Штатная проверка `quest-service-policy-current` удерживает точный SHA EXE,
архив, три таблицы, экспорты, код и среду выполнения. Результат и проверки кэша
сохраняются в [машинной квитанции](QUEST-SERVICE-CURRENT-VALIDATION.json).
Команда воспроизведения из корня проекта:

```powershell
python -X utf8 -m unittest discover -s phone-exit/bots -p test_vampir_quest_service_current.py
```

Следующая совместная проверка должна загрузить две группы задач в одну модель,
проверить сохранённые и исключённые записи и затем читать их проекции.
Для игрового действия требуются активный шаг, его исполнитель и корреляция
с серверным ответом.
