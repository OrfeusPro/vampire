## Проверенный код

Девять недостающих функций получены общим scoped collect. Первый экспорт
остановился на проверке границы хвостового перехода `1455b1190 → 1455ca1f0`.
Повтор с готовым completion как явным корнем применил существующее правило
tail-call. Проверка границ сохранена; частичная выгрузка доказательством не служит.

[Контекст завершения](../../native-contexts/quest-dialogue-lifecycle-current.json)
связывает пять целых функций с точным EXE. 13 native-сценариев проверяют
completion `1455d4290`, delayed callback `1455b1190`, event callback `1455d2dc0`
и прежнюю постановку selector 1 через `1455ca1f0 / 1455ca000`.
Проверены 14 ABI вызовов и 101 ABI вызовов fixtures.

Completion сразу вызывает постановку шага, затем устанавливает таймер на одну
секунду. Прямой вызов сохранённого callback даёт второй completion, но очередь
оставляет одну ожидающую запись. При заблокированном событии подписка сохраняется;
готовое событие снимает её, обнуляет handle и передаёт управление task vtable
`+0x28`. Это проверка callbacks с явными engine / model / delegate fixtures.
Диспетчер таймера, проигрыватель реплик и живой переход сюда не входят.
Индекс `2` и группа `11011110` берутся из текущего CSV как вход сценария.
Преобразование строкового ClassInfo и выбор активной реплики остаются открытыми.

## Обновление и живая сессия

Оба дочерних результата включены в `quest-dialogue-current`, его зависимости,
кэш и контракт `quests`. Два новых тестовых модуля зарегистрированы в одной
tooling-группе. Неизменный повтор проверяет полные SHA и барьеры входов,
используя сохранённые native-сценарии. Идентичность Python / Capstone / Unicorn
учитывается в ключах. Проверка названий теперь автоматически получает свежую
derived-квитанцию наблюдателя при прежних native parents; изменение допуска
Time больше не требует повторной эмуляции QuestSync / Tutorial.
[Приёмка и manifests](QUEST-DIALOGUE-LIFECYCLE-CURRENT-VALIDATION.json).

Bipoberiho остался в прежнем соединении. Последний `1811` имеет code `0`,
state `2`, индекс `2`. [Наблюдение владельца](QUEST-DIALOGUE-LIVE-BLOCKER.json)
подтверждает отсутствие доступных действий и активных сообщений диалога.
Его закреплённый профиль допускает только уже завершённую цепочку Time `0 / 1`.
HTTP API принимает опубликованные владельцем действия; установки нового
обработчика в текущий процесс через этот API нет. Изменение файлов не меняет
загруженный обработчик или закреплённый пакет. Перевход не выполнялся.

Переход `2 → 3` онлайн пока не подтверждён. Открыты проигрывание и завершение
группы, текущие NPC / caller keys, источник времени и доступность действия
у владельца. Для следующего пакета использовать готовые callbacks и wire proof;
исследовать очередь / playback и Type 5 execution без повторения готовых матриц.
Смена профиля действующей сессии потребует отдельного пересмотра её контракта.
