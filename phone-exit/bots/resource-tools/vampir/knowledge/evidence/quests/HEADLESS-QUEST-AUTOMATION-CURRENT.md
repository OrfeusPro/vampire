# Квесты: наблюдение и выбранное автозадание

6 ноября 2026. Клиент 1.13.22, SHA256
`03edad26033c85835ad8fdc1825df7aeb635e2c199055598ad926bf84b43739f`.

## Реализовано

- Следующий владелец читает ограниченные QuestSync / 1854 и Tutorial / 9905.
  Квитанция `quest-observation-current-v1` переиспользует 269 и 909 сохранённых
  native случаев, проверяет packet bindings и portable projection. Нового native
  исполнения нет. Это последнее полное сообщение, а не применённая модель задач.
- Первый клик по полученному квесту выбирает его и включает автовыполнение.
  Повторный клик снимает выбор и выключает его. Состояние принадлежит игровому
  владельцу; браузер хранит только предпочтения. Без допущенного шага показывается
  ожидание, игровой пакет не отправляется.
- Первый доступный шаг отправляется через прежний адаптер один раз.
  Owner pump продолжает только после подтверждённого результата и нового точного
  предложения шага выбранного квеста. Цель, индекс и координаты из ID не выводятся.
  Current provider ещё не допущен; композиция отправки проверена локальными socket
  fixtures прежнего допущенного контракта, а не текущим игровым сервером.
- Подтверждённый HP=0 выключает автоматизацию и отменяет ещё не отправленные
  намерения, сохраняя исходы отправленных. Воскрешение её не включает. Неизвестный
  исход блокирует продолжение. Смена персонажа / мира / соединения останавливает
  выбор; управление изолировано по аккаунту и session ID.
- `/bots/<id>/quest-automation` принимает только `{quest_id, enabled}` с точными
  bot/session и токеном. Это настройка, не отправка пакета. Общая карта использует
  proxy `/api/world`; токены владельцев в браузер не передаются.

Границы: QuestSync — 8 групп по 8 записей, 72 элемента с учётом групп,
2530 байт; Tutorial — 64 записи, 835 байт. Короткие и лишние байты отвергаются.
Две native trailing-пробы принимаются исходным reader как префикс;
portable-контракт намеренно требует точную длину.

## Онлайн и оставшиеся пакеты

Bipoberiho оставлен онлайн в прежнем независимом процессе. Остальные персонажи
не запускались. Старый обработчик пропустил начальные 1854 / 9905: получение
видно по счётчикам, тела не сохранялись. Они не восстанавливаются из fixtures.
Персонажа ради начального списка не отключали. Новый неизменяемый пакет готов
для следующего явного входа; работающая сессия сохраняет свой пакет.

Открыты три пакета:

1. Текущий QuestInfoId → русские ресурсы и реальные тексты / варианты диалога.
   Старый русский каталог другого SHA не подставляется. Current `observed_prompts`
   без нового доказательства отвергается. Ручные варианты и пропуск диалогов
   сохранены для доказанного адаптера; пропуск по умолчанию включён.
2. Provider выбранного шага текущего SHA: индекс, цель, координаты, движение /
   взаимодействие и подтверждение результата. Native wire / handler fixtures
   сами по себе этого не разрешают. Обучение об экипировке требует действия
   с реальным item instance, а не автоматического ACK.
3. Получение нового живого сообщения и проверка клика / продолжения на текущем
   сервере после подключения provider. Остановка при смерти проверена fixtures;
   персонажа ради проверки не убивали.

## Автообновление

Source-bound check `quest-observation-current` включён в `on_update` через
`entry-package-check-guard`, сохраняя native manifests, экспорты, runtime и код
readers. Неизменный повтор проверяет целостность и берёт готовую композицию.
Профиль `bounded-world` удерживает квитанцию и policy `quest-observation-v1`;
исходящие действия этим не допускаются.

Новые tests зарегистрированы в `MODULES`, группах `quest-observation-current`
и `quest-automation-owner`, общем tooling gate и пакете следующего входа.
Изменение общего owner/controller пересчитывает потребителей. Представление
использует прежний адаптер и tooling checks; semantic контракт `game-ui`
инфраструктурной проверкой не расширяется.

Композиция оформлена `prepare → collect → finish`; сбор использовал готовые
материалы без JVM. Итоговые manifests, проверки и границы онлайн —
в [приёмке](QUEST-AUTOMATION-CURRENT-VALIDATION.json).
