## Подтверждённые статические связи

144a88f70 вызывает getter 144a66f20, передаёт результат в RCX, таблицу
14965ba48 в RDX и count 1 в R8D, затем переходит к 1416b2c10.
Таблица содержит два uint64: 1495133e0 указывает на точную ANSI строку Refresh,
144a8f220 — адрес callback. Полные 16 байтов таблицы:
`e03351490100000020f2a84401000000`.

1416b2c10 читает имя из `[RSI]` и указатель из `[RSI+8]`, преобразует имя
через вспомогательные функции и добавляет 16-байтовую пару в массив по
исходному объекту +0x1f0. Счётчик находится +0x1f8, capacity +0x1fc.
Указатель сохраняется во втором qword записи; RSI увеличивается на 0x10.
Подтверждена статическая регистрационная ассоциация Refresh → 144a8f220.
Callback не исполнен, его тело в этом запросе не исследовано; связь с
кнопкой / обновлением HUD или динамическими данными списка не доказана.

144a6a620 разыменовывает входной RCX, пропускает нулевой объект, иначе
вызывает 144a6f9e0. Затем записывает два указателя таблиц в +0 / +0x28,
byte +0x428 = 1, qword +0x408 / +0x410 / +0x418 / +0x420 = 0 и
dword +0x460 = 0. Полный callee 144a6f9e0 экспортирован и сохранён;
он имеет собственные вызовы и записи, не все их роли разобраны.
Это наблюдаемая инициализация памяти, не доказательство имён UProperties,
порядка сериализации, inherited defaults или runtime значений.

144a7b370 имеет форму getter кешируемого указателя с точными UTF16
NkScrollView и /Script/NkUMG. Совместно с переданным указателем-переходом это
ориентир для разбора наследования. Полная reflection цепочка и её порядок
ещё не восстановлены; схема NkTileView не объявляется схемой NkScrollView.
