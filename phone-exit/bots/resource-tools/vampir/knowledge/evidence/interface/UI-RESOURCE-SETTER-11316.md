## Resolver: установленная граница

1445cf4f0 имеет три статические ветви:

- Нулевой RDX обнуляет два qword результата и возвращает его адрес.
- Если первый UTF16 символ равен `/`, вызывает 141426b30 с исходным путём.
- Иначе передаёт ключ и точный UTF16 шаблон `/UI/Resource/Texture/%s`
  из 1495593f8 в 141433340. Затем адрес временного результата и глобальный
  объект 14b5646b0 передаются 14142bc30, после чего временная строка освобождается.

Это статические аргументы вызовов. Helpers строк, форматирование / конкатенация
и runtime значение глобального префикса не исполнены и не восстановлены.
14b5646b0 находится вне file-backed части образа; из EXE нельзя вывести
активное строковое значение. Не подставлять `/Game/RED` по совпадению PNG-пути.
Абсолютная ветвь не подтверждает успешную загрузку или активный mounted вариант.

## Setter: точные записи

14191ab70 сравнивает входной указатель с qword объекта +0x38.
Равенство (включая оба нуля) возвращает без invalidation или внешних calls.
При различии:

1. Если глобальный byte 14b3cb8c0 ненулевой и новый указатель ненулевой,
   вызывается 1416e2a20 с новым указателем. Назначение side effect неизвестно.
2. В +0x38 записывается новый указатель.
3. Первый qword кеша +0x98 обнуляется. Соседний control pointer +0xa0
   меняется на ноль через 1414734e0, старое значение передаётся для release.
4. При старом control pointer выполняется atomic уменьшение счётчика +8;
   если прежнее значение равно 1, вызывается virtual slot 0. Затем уменьшается
   счётчик +0xc; если прежнее значение равно 1, вызывается slot +8 с EDX=1.

Имена reflected полей, класс объекта и полный Brush layout этим не определены.
Нельзя считать равенство PNG SHA равенством runtime resource pointer.
Для вызова из scroll preparation setter получает owner +0x2a0 / +0x350,
следовательно его ресурсное поле +0x38 совпадает с проверявшимися ранее
указателями owner +0x2d8 / +0x388. Это арифметическая связь исходных адресов,
а не подтверждение загрузки этих текстур на живом клиенте.

## Bounded native проверка

`replay-ui-resource-setter.py` исполняет целую функцию setter. Swap helper,
resource side effect, destructor и deallocation — явные fixtures. Сам native
код выполняет сравнение, запись / invalidation, atomic refcount operations
и условия virtual calls. Три старых / новых указателя (0, A, B), два gate и
три состояния control (нет / счётчик 1 / счётчик 2) дают 54 случая.

Проверены полные байты объекта 0xc0 и control 32 байта, порядок calls,
сохранение полей при 18 случаях равенства, возврат и стек. Искусственные
счётчики и no-op destructors не доказывают реальное освобождение UObject,
многопоточную корректность, GC, загрузку или отрисовку. Resolver проверяется
статически тем же инструментом, не объявляется native replay.

```powershell
python -X utf8 -m unittest discover -s phone-exit/bots -p test_vampir_ui_tile_refresh.py -v
python -X utf8 phone-exit/bots/resource-tools/vampir/replay-ui-resource-setter.py --request 'F:/PhoneExit Resources/Vampir/knowledge/requests/a332126fbd8c6db1632525d5f6f76d91b549dce4a7cbfdbac5caa9817e750696/manifest.json' --output 'F:/PhoneExit Resources/Vampir/code-clues/ui-resource-setter-d00a-next.json'
```

Отчёт `code-clues/ui-resource-setter-d00a-02.json` вне Git. Первоначальный
отчёт без статического resolver блока сохранён отдельно. Четыре offline теста
покрывают прежние 24 / 128 / 32 случая и новые 54 setter случая; check
`ui-nktileview-refresh-current` включает новый replay в зависимости.

Для сборщика подтверждён локальный identity / invalidation контракт, но не
полная система экономии. Следом — источник runtime префикса и точные строковые
helpers, затем связь с активным ресурсом и Brush. Frontend пока не получает
автоматический полный путь или глобальные defaults из этих наблюдений.
