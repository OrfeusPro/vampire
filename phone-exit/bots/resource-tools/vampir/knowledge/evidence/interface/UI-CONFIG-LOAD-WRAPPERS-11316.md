## Источники и границы

roots 14157cf70 и 141534f70. Ghidra export завершён:
`ghidra/request-exports/<полный SHA EXE>/run-66f295ee495f/details.json`, SHA256
`d4a39b06441c510007834d8c68e47a85aef6216f59fc5a467929476b38b4c245`.
Инструкции сверены с псевдокодом; его void return не отражает перенос AL.
Полные unwind тела: 14157cf70…14157cf92 и 141534f70…14153505d.

14157cf70 вызывает provider 14144b5b0, передаёт возвращённый указатель вторым
аргументом FString-copy 141426b30 и возвращает собственный output object.
Содержимое настоящего пути и provider ещё не исследованы.

141534f70 копирует третий аргумент во временный FString. Constructor 141547b10
получает контекст, девятый аргумент, low byte 1, временную строку и пятый
аргумент 0. Затем ненулевой data временной строки освобождается. Если восьмой
входной аргумент ненулевой, assignment 1414277b0 получает context+0x50 и этот
указатель. Перед loader записываются три байта контекста:

| Смещение | Источник |
| --- | --- |
| +0x181 | low byte входного аргумента 6 |
| +0x182 | low byte входного аргумента 4 |
| +0x183 | low byte входного аргумента 7 |

Входной аргумент 5 самим wrapper не читается. Имена и смысл флагов неизвестны.
Loader 14155bbe0 вызывается с RCX=context, RDX=аргумент 2, R8=аргумент 1.
Его AL сохраняется через destructor 141549ba0 и возвращается с zero-extension.
Wrapper не нормализует произвольный ненулевой AL в 1. Для Reload второй
аргумент — Game, но ни активный файл, ни его приоритет этим не установлены.

## Проверка и ограничения

`replay-ui-config-load-wrapper.py` исполняет оба native тела целиком. Provider,
строковые операции, constructor / destructor контекста, loader, free и cookie
являются явными fixtures. Не вызываются загрузчик игры, сеть или игровой процесс.
Проверяются SHA EXE, unwind roots, вызовы, границы исполнения и полный RIP / RSP
возврат. Cookie fixture сохраняет фактический native EAX, не подставляет oracle.

Шесть path fixtures: null, пустая строка, ASCII, кириллица, surrogate pair и
встроенный NUL. Копирование fixture задано явно: это ABI / output guards,
а не доказательство настоящей обработки NUL или null строковыми helpers.

768 load cases: три input fixtures; четыре значения аргумента 4; два значения
неиспользуемого аргумента 5; по два значения аргументов 6 и 7; наличие override;
четыре loader результата 0 / 1 / 0x1234 / 0x123400. Проверены порядок services,
аргументы constructor / loader / override, освобождение временной строки,
все байты synthetic контекста 0x190 и сохранение low byte через destructor.
Это bounded модель доступного контекста, не определение полного native типа.
Allocator errors, exceptions, malformed strings и реальный cookie не проверены.

Отчёт `code-clues/ui-config-load-wrapper-d00a-02.json`, SHA256
`1c8208fc2e365c33a6005fc2c181e5a3ce8ea2926cc8653883c21795279509e8`.
Закреплённые Unicorn 2.1.4 / Capstone 5.0.6; проверка включена в общий source-bound
набор tile refresh. Следующий SHA требует переноса проверки, автоматического
продвижения runtime / совместимости нет.

Далее: provider 14144b5b0, constructor 141547b10 и loader 14155bbe0; подтвердить
реальные пути, состав источников, precedence и ошибки. Отдельно остаются
регистрация Reload callbacks и связь с key bindings / применением UI.
Генерация внешнего вида по неподтверждённым настройкам остаётся закрытой.
