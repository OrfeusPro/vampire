# Слои общей карты и один тестовый персонаж

Из восьми владельцев семь остановлены отдельными командами с точными bot/session.
Онлайн оставлен Bipoberiho на Canon 1. Его сессия
`aeef7a6b85192dd6fd65a9726b83c3a4` сохранена при обновлении панели.
Квестовые и другие игровые команды в этом пакете не отправлялись.

## Представление и источники

В существующем `ui-prototype` шестерёнка «Слои карты» открывает переключатели
детальных изображений, персонажей, подписей, областей, порталов, объектов,
мировых точек, целей квестов и исследовательской навигационной сетки.
Переключение не центрирует карту и не сохраняет настройки аккаунта.
Закрытие — шестерёнка, Escape или клик за пределами панели внутри карты.
Размещение панели — временная веб-геометрия; это не восстановленный игровой виджет.

Фон и сетка используют общий `atlas-map-layers.js`, подключённый также
к исходному renderer большой карты. При увеличении загружаются только видимые
оригинальные части 2048 × 2048. Preview остаётся до загрузки; границы тайлов
читаются как left/top/right/bottom. Невидимые изображения освобождаются,
параллельные события загрузки объединяют перерисовку. Повторная ошибка
изображения сама не запускает новый запрос. Карта не перезагружается из-за polling.

[Машинный selector](../../console-prototype-assets.json) закрепляет SHA:

- `maps/atlas/nocturne.json`: `7ad6d62a02111d5c58e0b202b778f40a0723aa34ccc1b98f380ad82c52d91bc6`;
- `maps/atlas/nocturne-manifest.json`: `feaa0c486792176d90873b82321ddd4ab6f6730e954f06e918dd15bf6ecaa5a1`;
- `maps/atlas/navigation-overlay-manifest.json`: `ce4c57eb24affdccc92505ee5fade1d603ddf2148e94682b599acf8545e5198d`.

Backend проверяет 25 разных ячеек сетки 5 × 5, соответствие preview, проекции
Map10/11 и описи навигации. PNG / 12,7 МБ navigation проверяются по SHA при чтении.
Общий серверный LRU ограничен 64 МиБ. Клиент дополнительно проверяет SHA точек
и навигации. При изменении закреплённого ресурса выдаётся конкретная ошибка;
неизвестная карта не получает чужой слой.

В справочных данных 175 областей, 40 порталов, 629 объектов, 207 мировых точек
и 5535 целей квестов. Они фильтруются по миру выбранного персонажа и видимой
части карты; доступность портала, объекта или квеста сервером здесь не подтверждается.
Навигация содержит 18 430 ячеек / 101 090 полигонов. На общем виде показаны
ячейки, при приближении — полигоны. Все высоты объединены. Слой не разрешает
движение и не доказывает активную версию navmesh или фактическую проходимость.

## Живые NPC и следующие общие блокеры

17 488 архивных NpcSpawn в справочной модели **не отображаются** как NPC рядом.
Слой «NPC рядом» получает только `entities` выбранной сессии при coverage
`received` / `partial`, совпадающем мире, конечных XYZ и серверной семантике позиции.
До готовности текущего окружения он отключён с пояснением. Имя, торговая или
квестовая роль не выводятся из непроверенного raw-кода. Подключение отображения
не включает взаимодействия, покупки, обход заданий или движение.

Блокер окружения для текущего SHA: общий перенос SightEnter 301, SightLeave 302,
NpcCreate 324 и их PktNpc / INPUT / Appearance closure. Готовые native материалы
остаются в 1.13.16; допуска для текущего клиента нет. Отдельный семантический
пробел — `wire field → model → typed Npc row lookup → shop / quest relation`.
Даже в прежней базе NPC `+0x10` сохранён как raw uint32, не доказанный `Npc.Id`.
[NPC create](../characters/HEADLESS-NPC-CREATE-11316.md),
[окружение](../characters/HEADLESS-OBSERVED-ENVIRONMENT-11316.md).

Для следующего ограниченного `prepare` read-only поиск дал **кандидаты**, не допуск:
readers 301 `0x1456c5390 → 0x1456c53b0`, 302 `0x1456c5550 → 0x1456c5570`,
324 `0x1456c5180 → 0x1456c51a0`; PktNpc reader
`0x14579e350 → 0x14579e710`. ID / name / reader anchors и формы корней совпали,
но полная closure и поля модели ещё не проверены. В готовых текущих exports этих
корней нет. При переносе можно переиспользовать 28 именованных ролей INPUT,
Appearance, optional, Time и vector из текущего CharacterList proof
`f2353d6d1b1ca7006f4f26f466aca617d80ff070e4ab0895452289f1b71d66a0`.
Его `character-list-records.json` имеет SHA
`12b9bc8e1ffb93c3133c22a155cc3785c66e8805b33fb5bd08ec0f5f0ae56063`;
общий Appearance / optional export — `run-acc24c5196b9`, SHA
`fc8cae5bd2348ae09abc8496eb4f9d253be6c0c0edf1257071bbe5b850a1df99`.
Это ориентиры discovery для пакетного переноса, не готовое runtime-разрешение.

Для QuestSync 1854 / Tutorial 9905 уже есть текущие native отчёты 269 / 909 случаев:
`F:/PhoneExit Resources/Vampir/knowledge/quest-packet-native-checks-v1/90eb396d3744175bf1af9a360e9fad479a89801f417ae35e245df9c20b69bd80/manifest.json`
и `d2ef50629f8578e5e1adf4ab6d576b6c3de2ff9bb878c264c190aa7423a1b7ec` в том же namespace.
Следующий пакет должен сравнить portable projection с этими сохранёнными результатами,
подключить отдельный допуск наблюдения и source-bound русский словарь. Повторный
Ghidra / native replay неизменных readers не требуется. Нынешний owner не имеет
hot-loader декодеров: новые обработчики применяются при следующем входе.

## Проверка и обновление

Node-проверки общего renderer: culling, LTRB, preview, cache eviction, отказ без
повтора, объединение callbacks, неизменность камеры, ячейки / полигоны и фильтры.
Fixture групповой карты проверяет gear / Escape, переключение персонажей,
исключение статических NpcSpawn, отделение чужого мира и неподтверждённого окружения.
Backend fixtures проверяют 25 частей, повреждение SHA, traversal, смешанную опись,
неизвестную карту, проекцию, отбор координат и справочную границу статуса.

Изменение входит в существующий `automatic-update-tooling`, группу
`account-verification`. Общий helper и его оба потребителя включены в dependencies
и кэш. Покрывающий контракт — существующий адаптер позиции / game UI; source-bound
game admission не расширен. Переиспользование справочных материалов не означает
автоматического переноса текущей navmesh: это остаётся открытым блокером.
Отдельная [машинная приёмка](GROUP-MAP-LAYERS-VALIDATION.json) хранит результаты.
