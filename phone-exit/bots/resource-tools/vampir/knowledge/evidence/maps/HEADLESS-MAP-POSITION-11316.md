## Адаптер и интерфейс

`map_position.py` допускает только два явно проверенных source SHA.
`map_projection_input.py` загружает явный content-addressed manifest и проверяет
полный SHA установленного PAK. `LiveSession.bind_source` отклоняет проекцию
другой версии. Оба launcher принимают `--projection`; у нескольких владельцев
общая конфигурация проекции не содержит состояние аккаунта.

При первой подтверждённой позиции после входа / смены мира карта центрируется
и приближается до прежнего масштаба явного focus атласа: минимум
min(viewport width, height) / 65000. Это правило оболочки прототипа, не
восстановленная настройка масштаба игрового UI. Ожидание initial atlas setup
не позволяет его fit перезаписать первое центрирование. Обычные state polls
и клики по объектам не меняют вид. После разрыва новое получение позиции
снова разрешает одно центрирование. Постоянное слежение выключено по умолчанию
и включается отдельно в меню окна; масштаб при центрировании не уменьшается.

В Node VM проверены readiness, первое центрирование / zoom, ручной вид,
повторные polls, клик, чужая сессия, новый мир, reconnect и неизвестная позиция.
Браузерный fixture с явной пометкой «Тестовые данные» показал маркер в центре
увеличенной карты; ручной drag сохранил сдвиг при последующих обновлениях.
Снимки вне Git в `ui-prototype-checks/entry-map-*-final-fixture.png`.
Snapshot `6514cce3aea73bc39ff10f8e2c34fcbf6fe31137d30ecfb255b0e79ec0159680`
прошёл verifier: 1970 resources, 1507 textures. Это не live marker proof.

Повторная общая проверка обнаружила timeout / WinError 10054 на больших
страницах loopback API. Отдельный bounded диагностический клиент получил
195840 из ожидаемых 198000 байт первой страницы и timeout; вторая пришла целиком.
TCP_NODELAY дал успешную отдельную проверку, но общий повтор снова получил
timeout: одного этого параметра недостаточно. После ограничения каждого write
до 16 КиБ обе страницы пришли целиком на 12 отдельных соединениях. Проверки NPC
и игроков читают каждую страницу на трёх отдельных соединениях. Все 25 тестов
окружения, сессий, API и журнала прошли; все 19 выбранных knowledge checks passed.
Таймауты, размер ответа и запрет
игровых команд сохранены. Это локальная проверка передачи HTTP, не WAN proof
и не установление причины любых возможных сетевых таймаутов.
