# Проверка официального клиента через JP

20 октября 2026. Пользователь разрешил запуск установленного клиента на ПК
для сравнения с headless-входом и самостоятельно ввёл данные в лаунчере.
Это отдельная проверка официального клиента: доступ к экрану создания
персонажа подтверждён; сетевой ответ Login отдельно не наблюдался.

## Условия

- Windows-клиент: `C:/Program Files/Netmarble/Netmarble Game/VAMPIR/ProjectRED/Binaries/Win64/ProjectRED-Win64-Shipping.exe`.
- SHA256 повторно проверен:
  `c7552efd2125e7981945d3443cc1d70a41ac0a8a4cb42e7c77e0d40b4713dfc8`.
- Phone Exit подключён к личному телефону TECNO TECNO BG6 со страной JP.
  HTTPS-проверка через SOCKS вернула `loc=JP`; адрес выхода не сохранялся.
- Выборочный VPN активен. Список содержит пять EXE: VAMPIR, игровой Shipping,
  Netmarble Launcher, EpicWebHelper и Epic Online Services overlay.
  Состояние обнаружения процессов: `count=5`, `error=false`, `limit=false`.
  Это подтверждает настройку маршрута, а не успешный обмен игры с сервером.

## Наблюдения

1. Прямой запуск VAMPIR.exe показал `Please launch through the launcher`.
   Он не воспроизводит штатную цепочку запуска из лаунчера.
2. После ручного входа пользователя Netmarble Launcher показал VAMPIR
   версии 1.12.14 и профиль `Must Create Character`.
   Надпись профиля сама по себе не подтверждает ответ со списком персонажей.
3. Пользователь нажал Run Game. Появился экран Select Region с вариантами
   Taiwan, Hong Kong, Macau / Global / Global 2.
4. Описание Global 2 включает Korea, Taiwan, Hong Kong, Macau и Japan.
   Оно соответствует описанию региона JP в ранее извлечённой таблице:
   [связи регионов](HEADLESS-SERVER-REGION-SELECTION.md).
   Прямое чтение выбранного числового региона в процессе не выполнялось.
5. Автоматические клики в лаунчере и игре не вызвали наблюдаемого перехода.
   Выбор Global 2 передан пользователю. Причина отсутствия реакции неизвестна.
6. Пользователь прислал снимок стартового экрана: Global 2,
   `Franz - Franz 2`, версия `v1.12.14 (REAL)`, ревизия `258392`.
   Версия и ревизия совпадают с ранее использованными headless-входом.
7. После нажатия на стартовый экран пользователь сообщил о видеозаставке,
   затем прислал снимок `Class Selection` с предложением выбрать класс.
   Подтверждён доступ к созданию персонажа. Создание, вход в мир и позиция
   этим экраном не подтверждены; ответ со списком персонажей не перехватывался.

## Следующая проверка и границы

Пользователь подтвердил, что персонаж не создан, и затем закрыл игру.
Таблицы связывают Franz2 с ID 256, свежий список — с группой 253; прежний
ID 251 соответствует Monty1. Отдельная попытка на 256 также получила Login 16.
[Сопоставление, границы и новая проверка](HEADLESS-FRANZ2-LOGIN.md).
Создание первого персонажа и вход в мир остаются открытыми.
Страна JP не доказывает совпадение адреса выхода с прежними попытками.

Токены, пароли, содержимое webcache и память процесса не считывались.
Dumper-7 не внедрялся; перехват сетевых пакетов не включался. Результаты выше
основаны на экране и состоянии Phone Exit. Они не устанавливают причину
headless InvalidState и не подтверждают получение позиции персонажа.

## Подготовка сравнения после замены телефонов

После последнего headless Login 16 заново проверено состояние Windows:
VAMPIR не запущен, Netmarble Launcher открыт. В Phone Exit 0.6.0 сохранена
группа Vampir с пятью EXE, выбран режим трафика выбранных приложений.

Попытка через доступный Google Pixel 5 не дошла до готового VPN:
интерфейс перешёл от установки прямой связи к ожиданию переподключения.
Ожидание остановлено кнопкой. Затем выбран другой доступный JP-телефон,
samsung SM-A057F: Phone Exit показал «Подключено · VPN», пинг 341 мс
и пять EXE в маршруте. HTTPS через SOCKS 127.0.0.1:1080 подтвердил `loc=JP`.
Адрес выхода не сохранялся. Совпадение этого телефона с прежней попыткой
по одному индексу каталога не доказано; для сравнения теперь зафиксировано имя.

В лаунчере загрузилась страница RF ONLINE NEXT. Нажатие кнопки выбора игры
не вызвало наблюдаемого перехода; повторять его вслепую не стали.
Пользователю передан переход на VAMPIR и запуск под bot-hk-test@vampir.top.
На момент записи VAMPIR в этом сравнительном тесте ещё не запущен,
поэтому нового результата официального входа нет. VPN оставлен подключённым
для запрошенного ручного шага; остальные приложения используют обычный маршрут.

## Персонаж создан и вошёл в мир, 21 октября 2026

Пользователь подтвердил bot-hk-test@vampir.top и Global 2 → Franz 2.
На текущем экране последовательно наблюдались Select Region, видеозаставка,
Class Selection и игровой мир. Пользователь создал персонажа; в мире видны
имя Okly, уровень 1, локация Blood Pool и начальное задание Moving forward.
Создание и вход в мир подтверждены экраном и сообщением пользователя.
Сетевые координаты, ответ списка и внутренние IDs не считывались.

На протяжении сравнения выбран samsung SM-A057F, JP; HTTPS через SOCKS 1080
подтвердил JP до официального запуска и после закрытия игры. Это один выбранный
телефон и непрерывное подключение Phone Exit; неизменность внешнего IP отдельно
не измерялась. Пользователь закрыл игру и лаунчер; отсутствие процессов
VAMPIR / ProjectRED-Win64-Shipping проверено до авторизации бота.

После закрытия официальный EXE сохранил SHA `c7552efd2125e7981945d3443cc1d70a41ac0a8a4cb42e7c77e0d40b4713dfc8`,
windows.manifestlist — `4dff7291228f11bd330f80af5a2797a877396e41287fe46a0db8fa4e3e874ffd`.
Бот с новым SDK / lobby context снова получил Game Login 16:
[отдельный результат и SHA](../auth/HEADLESS-LAUNCHER-LIVE-LOGIN.md#после-создания-персонажа-21-октября-2026).
Отсутствие персонажа не объясняет этот отказ. Совпадение всех полей игрового
контекста не доказано; успешный официальный вход не означает успешный вход бота.

После теста попытка проверки окна Phone Exit была остановлена физическим Escape.
Дальнейшие действия с окнами не выполнялись; отключение VPN после этого
не подтверждено. Это не отменяет уже полученные результаты входа.
