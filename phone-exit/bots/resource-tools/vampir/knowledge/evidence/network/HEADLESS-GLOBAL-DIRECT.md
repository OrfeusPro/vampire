# Прямой маршрут и переход к Global

22 октября 2026. Пользователь сообщил об открытии Global, выбрал Prelude 2
и уточнил, что для проверки нужен новый персонаж. Аккаунт бота остаётся
`bot-hk-test@vampir.top`; в открытой игре пользователь играет другим аккаунтом.
Существующего персонажа Franz 2 не переносить в ожидания Prelude 2.

## Проверенный прямой транспорт

В `probe-selected-game-login.py`, `probe-lobby-sdk-login.py` и
`probe-lobby-connection.py` добавлен явный `--direct`, взаимоисключающийся
с `--socks-port`. В Python API прямой выбор задаётся обязательным аргументом
`socks_port=None`. Перехода с отказавшего SOCKS на прямой маршрут нет.

CDN, GMC2 и SDK HTTPS уже поддерживали обычное соединение с проверкой TLS
и без environment proxy. Окно NID теперь явно получает `--no-proxy-server`.
Лобби и игра используют обычный IPv4 TCP: проверяются все DNS-ответы,
private / loopback / link-local назначения отклоняются до открытия сокета.
Соединение идёт к проверенному числовому адресу без второго DNS-запроса.
Попытки по нескольким адресам делят один бюджет подключения; системный DNS
остаётся синхронным и отдельного ограниченного resolver пока нет.

Version получает локальный адрес действительного игрового сокета, без
попытки угадать внешний IP. Для SOCKS сохраняется прежний bound endpoint.
Прямой режим следует маршрутам ОС: настройки системного VPN и фильтров
инструмент не изменяет, физический выход вне системного VPN этим не доказан.

## Проверки и следующий шаг

16 локальных тестов direct route / selected login / SOCKS прошли:
передача прямого выбора до игрового соединения, адрес Version, закрытие при
отказе, общий бюджет попыток и запрет private DNS-ответов. Проверка WebView2
`nid-browser.py --smoke` прошла на синтетическом callback, игра не запускалась.

Сначала определить источник каталога Global и сверить его EXE / конфигурацию,
затем получить свежую запись Prelude 2. Прежний region enum и server ID
нельзя автоматически объявить подходящими для Global. После успешного входа
прочитать список персонажей; создание нового разобрать и проверить отдельно.
