обработчик ошибки и источники игрового контекста. Без нового проверяемого
различия вход не повторять. После принятого Login получить свежий список
Franz 2 и выбрать существующего персонажа. Для удержания сессии отдельно
перенести проверки selection / world / Ping clock на текущий SHA;
ограничения кандидата не отключать. Затем подключать приём команд движения
параллельно чтению сервера и heartbeat, подтверждая результат серверным
состоянием. Движение по карте и квестовый сценарий остаются непроверенными.
