## Значение отказа

В текущей функции словаря `0x1457da4e0` проверена пара **59 / BlockedInfo**:
literal `0x149952320`, constructor строки `0x141426a30`, объект `[rbp+0x5ae0]`,
int 59 записан по `0x1457df78e` в `[rbp+0x180]`. Соседние указатели пары
записаны в `[rbp+0x6df0]` / `[rbp+0x6df8]`.
Это отдельное значение от 58 / BlockedIp; причину по имени не определять.

[inspect-release-result-names.py](../../../inspect-release-result-names.py)
теперь проверяет четыре точные пары на полном SHA текущего EXE.
Отчёт `F:/PhoneExit Resources/Vampir/code-clues/release-result-names/eec50ba10620820cd64a40a484d8b4dd311780123e5385287eb8830ff2ff959a/manifest.json`,
SHA256 совпадает с именем каталога. Полные unwind fragments декодированы,
но constructor / insertion / lookup и конкретный handler не исполнены.
Повтор огромного экспорта Ghidra не запускался: его прежний body-budget отказ
не изменился. Это статическая проверка выбранных записей словаря.

Runtime показывает для 59 «Доступ к игровому сервису ограничен сервером».
Серверная причина, привязка ограничения к аккаунту / устройству / сети и способ
устранения не установлены. Joined country SDK в этой сессии — HK; это наблюдение,
а не доказательство причины отказа. Автоматической смены страны или телефона нет.

Следом — исследовать обработку 59 и сравнить с принятым официальным входом
на EU. Создание нового персонажа возможно проверять только после принятого
Game Login; наличие свободного сервера само по себе этот этап не подтверждает.
