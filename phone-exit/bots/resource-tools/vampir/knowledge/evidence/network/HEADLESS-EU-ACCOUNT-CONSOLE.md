# EU-вход через панель аккаунтов

22 октября 2026, основной тестовый EU-аккаунт, прямой маршрут без Phone Exit / VPN.
EXE SHA256 `98802d550890354da73cfef101bc49c1691f104beccb8b6d878594ba8952807e`.
Сервер Prelude 2, region EU / 7, server ID 384, group ID 358.

## Наблюдения

1. Через «Загрузить серверы» получены 12 EU-серверов с названиями.
2. «Прочитать персонажей» получило Game Login 0 и одну запись. Она назначена
   по ключу; имя, ключ и аккаунт остаются в приватной локальной базе.
3. Отдельная попытка «Запустить» закончилась на NID до игрового соединения.
   Это не Login 59 и не доказательство пустого списка или отказа выбора персонажа.
4. После следующего успешного чтения Login 0 / списка был выполнен один новый
   явный запуск. Worker получил server position callback и выставил active / «В мире».
5. Два снимка API в `20:06:29.660662 UTC` и `20:07:21.802431 UTC`
   подтверждают running / active на том же сервере; интервал — 52,14 секунды.
6. Кнопка «Остановить» закрыла принадлежащий панели worker. API подтвердил
   running=false / active=false / stopped; процесса `account-worker.py` не осталось.

На экране имя персонажа и время подтверждения списка сохранены после перезагрузки
страницы. Кэш хранится по аккаунту, региону и server ID; последующая ошибка входа
его не заменяет. Выбор при каждом входе всё равно сверяет ключ со свежим списком.

## Что означает результат

Статус active устанавливает `account-worker.py` только из непустого
`world_observer` callback после явного чтения завершения входа в мир.
Это доказывает получение серверной позиции на одном EU-аккаунте.
Полный снимок мира, движение, квестовые действия, длительная устойчивость,
reconnect и две параллельные игровые сессии этой проверкой не подтверждены.
Счётчики heartbeat и тела ответов этим отчётом не сохранялись.

Квестовых команд, создания персонажа или изменения региона аккаунта не было.
Прежний HK-профиль больше не используется для EU; его исторический Login 59
не описывает результат этого основного аккаунта.

## Новый EU-аккаунт после создания персонажа, 23 октября

Пользователь сообщил о создании персонажа и входе в мир официальным клиентом
без VPN. После отсутствия игрового процесса выполнен один автоматический
launcher-вход бота для чтения списка. Свежая цепочка NID → launcher/token →
launcher/sign-in → лобби EU → Prelude 2 принята; Game Login 0, один персонаж Prox.
Новый профиль не регистрировался, создание персонажа бот не отправлял.
Запись назначена по серверному ключу из принятого списка.

Следующий отдельный запуск для получения позиции закончился на NID:
Login Failed / HTTP 400, форма отправлена, диагностика `read_failed`.
До SDK и игрового соединения он не дошёл. Прежний список сохранён.
Следовательно, список нового аккаунта подтверждён, вход Prox в мир ботом — нет.
Прежний SDK 1203 в успешной попытке не повторился, но конкретная причина
изменения не изолирована: изменились и состояние официального клиента,
и время проверки. Не выводить из результата необходимость SignUp.

Сводка двух разных операций:
`F:/PhoneExit Resources/Vampir/live-account-console/post-character/00677f94d75c8c49e44fceeb5257a701d182fb6767eb3d8eb077bb00405b28c6/manifest.json`.
SHA256 совпадает с именем каталога; это наблюдения панели, не доказательство
полного packet capture. Короткий захват всех сетевых компонентов завершился
до игрового обмена бота и не дал TCP-потоков на 12000; он не подтверждает
устранение пропусков предыдущей записи через сетевые адаптеры.

## Две одновременные сессии, следующая проверка 23 октября

После отдельного исправления чтения диагностического ответа WebView2 выполнен
один новый автоматический запуск Prox через launcher. Получен непустой
world-position callback, API показал running / active / «В мире».
Следом подключён основной аккаунт с XI, пока Prox оставался онлайн.
У каждого отдельный worker и назначение по серверному ключу; источник устройства
остаётся наблюдённым текущим ПК. Регион EU, Prelude 2 / server 384, прямой маршрут.

Семь снимков от `22:11:06.467649 UTC` до `22:11:36.535685 UTC` подтвердили active
обоих аккаунтов на интервале 30,068 секунды. Подключение второго не прервало
первый в этом окне. Затем Stop для каждого закрыл принадлежащий панели процесс;
API подтвердил running=false / active=false / stopped для обоих.

Это проверка двух кратковременных одновременных сессий и получения позиций,
не доказательство длительной устойчивости, reconnect, движения или квестов.
Исправление offset в диагностике WebView2 не доказывает причину прежнего NID 400
и само не меняет SDK-запросы; оба факта нельзя смешивать.
Подробности исправления и синтетического smoke — в
[описании панели](../../../../../vampir-headless/ACCOUNT-CONSOLE.md).

Сводка без почт, credentials, ключей персонажей, адресов и координат:
`F:/PhoneExit Resources/Vampir/live-account-console/dual-world/c90650813190393ba9d1d8d915f1b13dc04677fff1325447a5cd7d9bf1051e15/manifest.json`.
SHA256 совпадает с именем каталога. Полный ожидаемый SHA EXE, SHA worker,
снимки двух active и подтверждённая остановка сохранены в сводке.
