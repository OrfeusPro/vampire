# EU-вход через панель аккаунтов

22 октября 2026, основной тестовый EU-аккаунт, прямой маршрут без Phone Exit / VPN.
EXE SHA256 `98802d550890354da73cfef101bc49c1691f104beccb8b6d878594ba8952807e`.
Сервер Prelude 2, region EU / 7, server ID 384, group ID 358.

## Наблюдения

1. Через «Загрузить серверы» получены 12 EU-серверов с названиями.
2. «Прочитать персонажей» получило Game Login 0 и одну запись. Она назначена
   по ключу; имя, ключ и аккаунт остаются в приватной локальной базе.
3. Отдельная попытка «Запустить» закончилась на NID до игрового соединения.
   Это не Login 59 и не доказательство пустого списка или отказа выбора персонажа.
4. После следующего успешного чтения Login 0 / списка был выполнен один новый
   явный запуск. Worker получил server position callback и выставил active / «В мире».
5. Два снимка API в `20:06:29.660662 UTC` и `20:07:21.802431 UTC`
   подтверждают running / active на том же сервере; интервал — 52,14 секунды.
6. Кнопка «Остановить» закрыла принадлежащий панели worker. API подтвердил
   running=false / active=false / stopped; процесса `account-worker.py` не осталось.

На экране имя персонажа и время подтверждения списка сохранены после перезагрузки
страницы. Кэш хранится по аккаунту, региону и server ID; последующая ошибка входа
его не заменяет. Выбор при каждом входе всё равно сверяет ключ со свежим списком.

## Что означает результат

Статус active устанавливает `account-worker.py` только из непустого
`world_observer` callback после явного чтения завершения входа в мир.
Это доказывает получение серверной позиции на одном EU-аккаунте.
Полный снимок мира, движение, квестовые действия, длительная устойчивость,
reconnect и две параллельные игровые сессии этой проверкой не подтверждены.
Счётчики heartbeat и тела ответов этим отчётом не сохранялись.

Квестовых команд, создания персонажа или изменения региона аккаунта не было.
Прежний HK-профиль больше не используется для EU; его исторический Login 59
не описывает результат этого основного аккаунта. Регистрация новой EU-почты
и создание на ней персонажа остаются следующими отдельными проверками.

## Воспроизводимость и evidence

Запуск [панели и проверки](../../../../../vampir-headless/ACCOUNT-CONSOLE.md):
прочитать список → назначить запись → сохранить → запустить → проверить «В мире»
→ остановить. Эта последовательность выполняет реальный вход, её не включать
в автоматические offline-проверки.
