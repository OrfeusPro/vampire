## Как использовать дальше

Сначала определить lobby / game flows по проверенному framing и CRC, затем
сопоставить выбор персонажа и вход в мир. Найти штатные запросы состояния
квестов, включение / остановку автопрохождения и смену локации; сравнить
их порядок с ботом. Проверять границы кадров, компрессию и смену ключей;
не считать TCP chunks границами пакетов. Сохранять публично только схемы,
счётчики и доказанные связи, а не значения авторизации из записи.
