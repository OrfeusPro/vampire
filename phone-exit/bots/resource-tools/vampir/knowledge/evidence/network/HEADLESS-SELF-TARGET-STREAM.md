# Серверная XY-цель собственного персонажа

22 октября 2026. Источник — EXE SHA256
`98802d550890354da73cfef101bc49c1691f104beccb8b6d878594ba8952807e`.
[Проверенные тела ID 306 / 307](HEADLESS-CHARACTER-MOVE-EVENTS.md)
используются повторно, без нового анализа readers.

## Источник ключа и координат

Текущий receiver ID 206 `0x145dade30` ищет actor через `0x145514ef0`
по ключу player+8. Receiver ID 307 `0x14679eab0` использует тот же lookup
для packet+0x10. Эти связи прочитаны в текущих экспортах; ключ не выбирается
по близости координат, имени или первой встреченной сущности.

Дополнительно получен `0x1456a6770`: он вызывает `0x145690e50` и
`0x1456a7fc0`, получает варианты векторов и выбирает результат с учётом
их высот и флагов. Код не сводится к копированию входящего XY.
Зависимости движка и их поведение пока не исполнены; этот алгоритм runtime
не воспроизводит.

Новый `CharacterTargetTracker` активируется после успешных выбора и ID 206.
Он принимает ID 307 только при совпадении с ненулевым ключом выбранного
персонажа. При нулевом ключе сохраняет только цель входа. Чужие уведомления
игнорируются; неконечный собственный XY отклоняется. До ID 206 уведомления
не применяются. При закрытии ключ и позиция очищаются.

Это серверная цель до применения условий и коррекций движка. Высота сохраняется
из ID 206, а не вычисляется из XY. В feed и UI используется отдельная семантика
`server_target_xy_retained_z`; подпись сообщает о серверной XY-цели и последней
известной высоте. Фактическая высота, проходимость, прибытие и завершение движения
из этого события не следуют.

## Подключение и проверки

При явном `world_observer` существующий exchange передаёт последние обновления
цели в `MapSession`. В одном чтении могут прийти ID 206 и несколько ID 307:
последняя собственная цель не затирается начальной позицией. Повторная выдача
observer происходит при новой ревизии. Скрытая карта не отключает обработку
сессии. Без observer прежнее диагностическое поведение сохраняется.

Проверены:

- 3 теста tracker: собственный / чужой / нулевой ключ, сохранение битов Z,
  неверный SHA / отказ выбора, короткое тело, NaN и cleanup;
- 27 socketpair-тестов exchange, включая совместное получение ID 206,
  чужого и собственного ID 307 без новых исходящих игровых команд;
- 4 теста проекции, 2 теста feed и 8 тестов запуска выбранной сессии;
- Node-проверка модели слоя и синтаксиса карты.

Offline-проверки `world-target-stream` и `character-target-identity`
зарегистрированы для `world-position-events`; авторизация в них не выполняется.
Это локальные fixtures, не доказательство живого движения.

```powershell

```
