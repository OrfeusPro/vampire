# Средство записи официального TCP для сравнения с ботом

21 октября 2026. Добавлен диагностический режим Phone Exit Windows:
[инструкция и формат](../../../../../../pc/DIAGNOSTICS.md).
Он работает в собственном SOCKS-прокси, не внедряется в процесс игры.
Запись включается явно, только для точных хост:порт и новых соединений.
Исследовательский экспорт не входит в runtime самостоятельного бота.

Код: `phone-exit/pc/src/diagnostic-capture.js`, точки наблюдения в `socks.js` /
`bridge.js`, управление через `desktop-diagnostics.ps1` и команды локального pipe.
Для каждого направления сохраняются последовательные байты и смещения;
TLS / внутреннее игровое шифрование автоматически не снимаются.
Лимиты, ошибка диска и отключение наблюдения не должны прерывать передачу.

Проверены синтетические фильтры / бинарные потоки / лимиты / ошибки и настоящий
локальный native / werift WebRTC с тремя параллельными TCP. Есть offline reader
со сверкой смещений и экспортом направлений. Проверены start/stop из собственного
окна, DPI / resize, а также полный desktop smoke. Реальные токены не использовались.
