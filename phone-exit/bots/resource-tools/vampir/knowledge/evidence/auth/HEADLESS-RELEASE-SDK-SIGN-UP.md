## Что установлено

`0x144506cf0` содержит diagnostic `FAuthImpl::SignUp`. После получения
service settings функция собирает четыре начальных пары через глобальные
дескрипторы `0x14b564d10`, `0x14b564d00`, `0x14b564d70`, `0x14b564d80`.
При ненулевом credential вызывает virtual `+0x8`, преобразует результат
и добавляет ещё одну пару с ключом `0x14b564d20`. Семантика этих пяти ключей
в этом проходе не переносится из прежней версии: нужны текущие initializers.

Инструкция `0x14450722b` передаёт ASCII literal `authUrl` по адресу
`0x149530ed0`; `0x14450745f` передаёт UTF-16 literal `v1/sign-up` по адресу
`0x149530ed8`. Это разные кодировки соседних литералов. Псевдокод показывает
lookup адреса, добавление суффикса и сериализацию собранного объекта.

Callback `0x1444d6050` проверяет JSON и содержит отдельную ветку HTTP
`200..206`: unsigned условие `status - 200 < 7`. Затем проходит вложенные
объекты по глобальному ключу `0x14b564df0` и строкам из owner `+0x20` /
`+0x28`, проверяет поле из owner `+0x30`, передаёт строку setter и вызывает
сохранение settings. Имена этих ключей требуют проверки текущего constructor.
Установленный порядок не означает, что отсутствие необязательных полей
обязательно приводит к отказу callback.

## Границы и следующий шаг

Ghidra завершил декомпиляцию обеих функций; предупреждение о пересечении
глобальных символов в SignUp сохранено. JSON helpers, settings getters,
конструктор ключей, сериализация, HTTP и callback здесь не исполнялись.
Это не актуальный bounded replay и не успешное создание SDK-профиля.

Исторический replay можно воспроизвести с явным `--source-snapshot`
старого SHA. Он проверяет полный SHA снимка; новый результат записывается
в отдельный каталог `code-clues/sdk-sign-up-body-replays/<SHA>/manifest.json`.
Прежний отчёт сохраняется. Проверены четыре исторических сценария и отказ
повреждённого снимка. Эти результаты не подтверждают текущие поля.

Далее — текущие initializers пяти ключей и constructor owner callback,
затем bounded replay актуального тела и отдельная живая проверка SDK SignUp.
Повторная регистрация уже занятой почты для этого не нужна.
