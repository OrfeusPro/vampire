# JP: SDK принял повторный вход после официального клиента

24 октября выполнен один обычный вход `bot-tw-test@vampir.top` после
[официальной записи до выбора Evans 1](HEADLESS-JP-LAUNCHER-CAPTURE-20261024.md).
Регистрация Netmarble, SDK SignUp и игровые действия не запускались.

Первая попытка транспорта к realme RMX3511 / JP завершилась WebRTC failed,
до NID. Второе подключение к тому же телефону прошло; HTTPS Cloudflare trace
через SOCKS `127.0.0.1:1080` подтвердил `loc=JP`. Прямого fallback не было.

Повтор использовал тот же `run-nid-sdk-sign-in.py`, `recovered-release`,
`auth_flow=launcher`, свежий GMC2 и раздельный WebView-профиль аккаунта.
Пароль прочитан из локального AccountStore под DPAPI и передан в памяти.
Последовательность NID → launcher token → launcher sign-in завершилась
успешно за **28,062 секунды**. SDK вернул непустые player ID / access token,
`joined_country=JP`, `game_region=GLOBAL`. Значения credentials не сохранялись.

Отказ 1203 из прежней попытки не повторился. Порядок событий согласуется с
гипотезой подготовки серверного профиля официальным входом, но не доказывает
причину: в промежутке также изменились время и соединение. Точное отличие
HTTP-запросов официального клиента и бота по-прежнему не установлено.

У этой записи локальной панели статус обновлён до `sdk_created` по принятому
SDK-ответу. Сервер / персонаж не назначались; остальные аккаунты не менялись.
Токен сеанса не сохранялся для повторного использования.

Затем `game-source-profile.py --profile recovered-release --check` вернул
`source_profile_not_verified`. Поэтому нового запроса каталога от бота,
игрового соединения и создания персонажа не было. Готовность launcher / SDK
не означает готовность игрового Version / Login текущей сборки.
Следующий этап — завершить перенос игрового профиля 1.13.16 и его проверки,
после этого получить свежий каталог, выбрать сервер и прочитать персонажей.

Собственный транспорт остановлен, дочерний процесс завершился с кодом 0;
порт 1080 после остановки не слушает. Системный VPN Windows не включался.

SHA256 совпадает с именем каталога. Отчёт подтверждает только эту SDK-попытку,
не вход в игровой мир и не причинное объяснение исчезновения 1203.
