## Изменение runtime

Явный selector `sdk-launcher:<SHA>` входит в отдельный ContextVar scope.
Загрузчик проверяет полный SHA профиля, установленный EXE, все evidence / runtime
inputs и CRT locale. Scope разрешает только `sdk-launcher-gmc2-geo-v2` для
точного SHA. Он не назначает пакет игрового мира, не предоставляет его policies,
не разрешает прямой SDK SignIn / Fetch / SignUp. Смена профиля внутри scope
запрещена; после исключения допуск снимается. Другой worker его не наследует.

Offline composition использует настоящий selector вместо подмены source loader
и fixture-permits. Детерминированными остаются внешние OS / browser / HTTP эффекты.
Отдельные сценарии проверяют шифрование приватной записи, бюджеты, сохранение
payload / заголовков и закрытие ответа, отсутствие значений токенов в inventory
и нормализацию прежних неполных настроек аккаунта.

Изменён существующий source check `sdk-runtime-launcher-11316`, вариант этого SHA:
добавлены SDK scope, runtime admission, диагностическая команда и её зависимости.
Он уже подключён к `on_update`, guard проверяет неизменность исходных 98 inputs
также на cache hit. Зависимость нового helper добавлена в девять tooling-групп,
которые используют общий runtime admission. Имена и реестры не извлекаются из Markdown.

## Настоящий сервер

[Машинный результат](SDK-ENTRY-11322-ONLINE.json) описывает одну удачную попытку
5 ноября 2026 года через прямой маршрут с наблюдаемым устройством Windows.
NID вернул credential; launcher/token и launcher/sign-in приняты сервером,
получены непустые SDK accessToken и player ID. Значения credentials не опубликованы.
Ожидание и обмен заняли 18,673 секунды; приватная запись содержит восемь записей
с 3964 байтами application payloads / HTTP metadata под Windows DPAPI.

Два ранних запуска диагностической команды остановились локально до открытия
NID: прежняя assignment не содержала `socks_port`. Исправлена нормализация через
существующий AccountStore.assignment; добавлен воспроизводимый сценарий.
Это не отказы серверной авторизации.

Ответ содержит `status = 2`, `restriction = ["workplace"]`,
`deviceSecure = ["device-registration"]`, `withdraw = []`.
Причина ограничения, успешная регистрация нового устройства и снятие защиты
для этого аккаунта не установлены. Сессия игрового мира не создавалась.
Успешный вход с наблюдённым ПК не доказывает принятие custom-шаблонов.
