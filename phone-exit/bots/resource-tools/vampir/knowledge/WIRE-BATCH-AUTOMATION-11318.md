# Автопроход общего wire пакета 1.13.18

[Native доказательства и границы](evidence/updates/HEADLESS-WIRE-BATCH-11318.md).

Штатный `update --resume` подтвердил сокращение очереди 144 → 134 строки:
для каждого из Version и Login закрыты writer, string-writer и три общие
проверки UTF-8/string/archive. Разница двух списков — ровно 10 удалённых причин
и 0 новых. Всего закрыто 16 строк из исходных 150.

Для обоих контрактов журнал содержит буквально одинаковые reports/cache keys
трёх checks. Использованы результаты `finish`; native тесты повторно не
запускались. Повторяемость обеспечивается hashes contexts, sources, tools,
runtime и Ghidra artifacts. Результат одного общего helper не дублируется
отдельным ручным переносом для второго контракта.

Первый проход обнаружил отдельный timeout инструментального `update-run-offline`
на лимите 180 секунд; временный остаток был 135. Причина лишней работы —
повторный AST-разбор общих зависимостей для нескольких групп инструментов.
`execution_inputs` теперь кэширует разбор файла внутри одного расчёта. Каждый
следующий расчёт заново читает inputs, сохраняя обнаружение изменений.

Новый тест проверяет один разбор общего файла и его повторную валидацию после
изменения во всех группах. Полный штатный набор после исправления: 15 tests,
99.388 секунды, OK. Лимит не увеличен; timeout больше не присутствует в очереди.
Это замер данного запуска, не обещание одинакового времени на других ПК.
