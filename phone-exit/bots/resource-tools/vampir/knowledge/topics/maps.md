# Карта, геометрия и навигация

## Установлено

Существующий атлас содержит карты, миры, точки, области, NPC / gadget spawns,
waypoints и связи квестовых целей. Есть просмотрщик и данные по мирам в
`F:/PhoneExit Resources/Vampir/maps/atlas/`. Отдельно исследованы nav tiles,
координаты, polygon queries, переходы, проекция и маршруты на offline fixtures.
Подробные результаты и ограничения active mesh / filters —
[MAP-ATLAS](../evidence/maps/MAP-ATLAS.md).

Карту и сетку использовать как существующую основу. Доказанные преобразования
и synthetic inputs брать только из соответствующего evidence; не переносить
offline фильтры и параметры как наблюдённые настройки живого клиента.

## Открыто

Позиция персонажа из реальной headless-сессии, активный mesh / filters,
подтверждённое сетевое перемещение по выбранной цели и исправление по ответам
сервера. Картинка и offline достижимость не доказывают серверную проходимость.

Дальнейший UI: персонаж, цель, путь, цели квестов, атакуемые и атакующие мобы.
Обновление отображения должно отключаться для экономии ресурсов; такая
полная живая оболочка ещё не готова.
