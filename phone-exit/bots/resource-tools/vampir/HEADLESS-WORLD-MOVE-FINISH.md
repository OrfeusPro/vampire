## Проверенная цепочка

Сначала исполняются чтение ID110 и его обработчик с переносом данных персонажа.
Затем тест передаёт отдельный объект ID206 в `0x1467a5d30`:

`0x1467a5d30` → общий фильтр `0x1467a8e10` → `0x145dbef80` →
виртуальный `+0x78` / `0x145dbcbe0` → `0x14560d7b0` →
`0x1456140f0(service, 6, text)`.

Сохраняются те же тестовые объекты сервиса и персонажа. Реальные инструкции
увеличения и уменьшения счётчика ссылок возвращают его к исходному значению 2.

Исполнены 10 сценариев: коды 0, 1 и `0x1197` при двух значениях байта фильтра;
разные поля пакета, включая граничные числа; нулевое поле `player+8`.
Наличие указателя персонажа и нулевое значение его поля не смешиваются:
в последнем сценарии объект остаётся, меняется только поле `+8`.

Код 0 проходит фильтр. Код 1 отклоняется. Код `0x1197` проходит при байте
фильтра 0 и отклоняется при 1, как в ранее исследованных ответах. Нулевое
поле `player+8` завершает этот обработчик до фильтра. Эти результаты относятся
к проверенным локальным ветвям, а не к серверному смыслу каждого кода.

При принятом ответе подтверждены следующие записи:

| Поле объекта пакета | Поле сервиса или персонажа |
| --- | --- |
| `packet+0x18`, u64 | `service+0x38` |
| `packet+0x20`, u32 | `service+0x40` и `player+0x1f8` |
| `packet+0x24`, u32 | `service+0x48` |
| `packet+0x110`, u64 | `service+0x50` |
| `packet+0x29`, байт | `service+0x58` и аргумент виртуального слота `+0x78` |
| `packet+0x118`, байт | `service+0xf1` |
| `packet+0x119`, байт | Четвёртый аргумент виртуального слота `+0x78` |

При отклонении либо нулевом `player+8` переход не происходит: состояние
после ID110 сохраняет значение 1. В принятых сценариях оно становится 6.

и не общий декодер. Массивы и callbacks пусты. SDK выключен. Ветвь первого
перемещения и флаг `service+0x1a8` выключены; специальное значение поля

объекта перехвачено и также возвращает null. Проверка вектора возвращает
тестовое разрешение. Функция преобразования направления в углы исполняется,
но перенос уже существующего игрового объекта и его физика не проверены.

перехвачены. Параметры этих вызовов не доказывают исполнение их внутренностей.

Для TLS задано явное уже инициализированное окружение с нулевыми индексом
и эпохой. Инструкции приложения не пропускаются; вызов CRT-инициализации
