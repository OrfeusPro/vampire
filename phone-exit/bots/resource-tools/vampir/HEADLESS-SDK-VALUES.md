## Цикл DecryptXOR

Функция `0x1444ddf50`, цикл `0x1444de000..0x1444de019`:
для каждой 16-битной единицы входа берётся XOR с единицей ключа по индексу
`i % key_length`. Длина ключа вычисляется из FString count минус завершающий NUL.
Размер входа берётся из отдельного массива; нулевые единицы внутри не обрезаются.
Результат передаётся по одному wchar в `0x1414242a0`.

В Unicorn исполнен настоящий цикл. Вызов append заменён ограниченным захватом
16-битных результатов; логирование отключено искусственным флагом. Аллокатор,
создание полноценного FString, загрузка DECKEY и внешний разбор ответа здесь
не исполняются. 42 сценария охватывают пустой вход, разные длины и период ключа,
значения до 65535, суррогатные единицы и искусственный JSON. Максимальная
проверенная длина — 2048 единиц. Это отдельное преобразование от XOR TCP-кадров.

Общий [sdk_constants.py](../../vampir-shared/vampir_core/sdk_constants.py)
принимает immutable UTF-16LE bytes без добавленного завершающего NUL, возвращает
bytes и сохраняет все единицы, включая изолированные суррогаты. Ограничения:
4096 байт входа и 1024 байта ключа, чётные размеры. Непустой вход с пустым ключом
отклоняется явно; native цикл в этом случае делил бы на ноль. Эти лимиты —
локальная политика ядра. Декодирование текста и проверка JSON выполняются отдельно.

Пять тестов проверяют происхождение, соответствие всем native векторам,
повторное выполнение семи выбранных native сценариев и ограничения памяти.
