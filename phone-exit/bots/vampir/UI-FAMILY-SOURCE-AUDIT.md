# Первичный проход семейств UI по источникам

Это результат проверки извлечённых данных, а не восстановление внешнего вида.
Единые статусы окон находятся в [UI-W чеклисте](UI-WINDOW-TASKS.md), выборка —
в [очереди имён с UI](UI-NAMED-WINDOW-TASKS.md). Проверка выполнена двумя
параллельными заданиями по явному запросу пользователя; результаты приняты
последовательно. Полные отчёты хранятся вне Git.

Базовый snapshot: `4ceec6f214cbe9d28e35d1a05d5a3c4731d45296e15336575075202793d0cde9`.
Во всех пяти ресурсах сверены SHA каталогов, UAsset / UExp и exports контролов;
локальные схемы повторно построены существующим `ui_layout_schema.compile_schema`.
Ссылки на дочерние классы сохранены кандидатами, без автоматического выбора варианта.
PAK sample SHA в происхождении не выдаётся за полный SHA архива.

## Следующие обязательные проверки

Для каждого ресурса остаются открытыми активный вариант, совместимость исторических
cooked данных с установленным EXE, видимый root / ветка, внешние размеры, DPI /
SafeZone / desired size, Brush / шрифты / оттенки / прозрачность, динамические
bindings и native handlers. Затем нужны модель, интерактивность и визуальная сверка.
Перечисленное ведётся в .01–.06 соответствующего UI-W пункта; частичная проверка
источников закрывает только .01.01. Игровые команды не отправлялись.

Общие TitleBarUI, BGDefault, вкладки, списки наград и слоты следует проверять
один раз как компоненты, затем отдельно проверять размещение у каждого потребителя.
Следующий проход — общие зависимости и семейства входа / персонажей / HUD / карты,
без исключения остальных 551 записей из очереди.
