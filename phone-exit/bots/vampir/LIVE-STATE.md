# Текущее состояние игры: возможные источники

16 октября 2026. Описания квестов/обучения в quest-runtime.json статические:
они не сообщают, какое окно сейчас видно или какой этап сервер подтвердил.

Проверено: Windows-клиент имеет Saved/Logs, но на момент осмотра папка пуста.
Даже найденный Windows-лог не отражал бы текущую сессию другого Android-клиента.
На ПК по ADB доступен только USB-vivo81865352, не удалённый Pixel 5. Удалённый
BotAPI не имеет операций чтения файлов другого приложения или logcat.
Статус Pixel 5 сохранён в игнорируемом .tools/vampir-capabilities.json.

Пока не проверено: существуют ли на Pixel 5 экспортируемые игрой файлы состояния,
внешние логи или полезные строки logcat. Отсутствие API чтения не доказывает
отсутствие логов. Внутренние /data/user/0/com.netmarble.thered доступны только
самой игре/привилегированному процессу; обычный APK PhoneExit не имеет такого
доступа. Наличие su-бинарника не доказывает предоставленные права.

Следующий проверяемый путь: если целевой Pixel 5 станет доступен через разрешённый
ADB, изучить read-only logcat и доступные внешние каталоги, сопоставляя фактические
изменения QuestId/TaskId/TutorialStep со свежими кадрами. Не обещать эти поля до
наблюдения. Не включать постоянный общий сбор логов/секретов аккаунта.
Если подтверждённый runtime-источник найден, использовать его для определения
этапа, а проверку видимости/позиции контрола сохранять перед действием.
До этого источник состояния — распознанный кадр, смысл шага берётся из данных клиента.
