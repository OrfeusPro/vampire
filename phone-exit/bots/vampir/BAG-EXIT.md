# Выход из оставшейся сумки

Наблюдение: Zizak4 уровня после сцены, обычная сумка без учебной подсказки мешает
панели квеста. Офлайн bot.py не делает tap, возвращает quest_wait_state; это не
доказательство ложных нажатий/открытия сумки самим ботом. Причина открытия
в данном эпизоде не установлена. Учебные шаги экипировки 4003 уже существуют.

Источник: WBP_InventoryUI, patchentry2167, ButtonClose161 (NkButton), Slot69 и
цепь родителей. Экспорт/слоты/SHA в bag-exit-reference.json. Реальная координата
определяется по Android кадру, не выводится только из имени/Canvas слота.

Используется общий recognition.overlay_route. Положительные якоря: Bag,
BulkSalvage, Default. Названия кнопок сортировки/разбора используются только как
идентификация экрана — бот их не нажимает. Цель только ButtonClose(X).
Учебный SKIP и известные подсказки экипировки/улучшения запрещают закрытие.
Ожидание 2 сек, одно нажатие, проверка исчезновения якорей; при 10 сек неизменного окна
пауза retryablefalse. Любая другая компоновка остаётся полным поиском.

Три размера 75/100/125%и сдвиг 8×6, отрицательный кадр с обучением проверяются
в test_vampir_bag_exit.py. Генератор build-bag-exit.py, источники crop/SHA сохранены.

Дополнительно найдены CutsceneUIentry735/MediaUI789/ButtonSkip, 350×100local,
anchor1,0alignment1,0. Аналогичный ButtonSkip есть DialogUI1193. Общий текст SKIP
сам по себе не доказывает катсцену: обучение тоже его использует. Универсальный
пропуск катсцен пока не включён; подтверждённый диалоговый пропуск остался прежним.
Сцена в этом прогоне закончилась сама. Источники кандидатов в библиотеке
phone-tests/bag-exit-2026-10-16/skip-candidates.json.

## Проверка 1.0.19

2 кадровых теста(4 масштабных/сдвига варианта+запрет для учебного инвентаря), 5 тестов
общего роутера и 25 квестовых регрессий прошли. Генератор воспроизвёл 12 шаблонов.
Подпись ZIP, локальный и удалённый SHA проверены; Pixel 5 подтвердил install/start.
Свежий кадр после запуска: сумки нет, Zizak5 уровня, KrynaNest, статус quest_auto_running,
errornull. Это успешный возврат к игровому экрану; детальный tap-статус между кадрами
несохранён. Полный поиск обычного HUD пока 6833 ms, его ускорение не утверждается.
