# Запуск карты Vampir

Дважды нажмите **Start-Vampir-Map.cmd** в корне проекта. Откроются браузер
с картой и окно сервера. Окно сервера оставьте открытым; для остановки нажмите
в нём **Ctrl+C** или закройте его. Если сервер уже работает, повторный запуск
просто открывает карту, второй сервер не создаётся.

Адрес: http://127.0.0.1:17946/maps/atlas/index.html

Нужны Python 3 в PATH и готовые файлы карты в `F:\PhoneExit Resources\Vampir`.
Сервер доступен только на этом компьютере. Скрипт не пересобирает данные.

Если каталог ресурсов перенесён, укажите новый путь из PowerShell в корне проекта:

```powershell
powershell.exe -NoProfile -File .\phone-exit\bots\vampir\start-map-server.ps1 -ResourceRoot 'D:\Resources\Vampir'
```

Параметр `-NoBrowser` запускает сервер без открытия браузера. Если порт 17946
занят другим приложением и карта не отвечает, скрипт покажет ошибку;
чужие процессы автоматически не завершаются.
