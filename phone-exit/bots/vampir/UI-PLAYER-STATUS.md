# Общий блок портрета и HP / MP

Исходный компонент — WBP_PCStatusProgressBarT, вложенный портрет —
WBP_PortraitSmallT. Это cooked ресурсы клиента, не доступный исходный C++ проект.
Их дерево генерируется в HTML через общий renderer; native код браузер не исполняет.

Прежняя проекция переносила только часть элементов: пропускала рамки полос
и вставляла thumbnail в ButtonPortraitMove вместо отдельной визуальной ветви.
Из-за этого полосы перекрывали контур портрета и выглядели слишком тонкими.

Теперь применены исходные рамки 299 × 22 вокруг полос 291 × 14, прямая ссылка
Brush на ProgressBG_HP, отдельная область нажатия и вложенное дерево портрета
с тремя NkImage. Текстура FloatRGBA извлекается при сборке; анализ native /
пакетов не переносится в каждое из 50 окон. Компоненты получают одну модель,
новые таймеры и подписки не добавлены, оба view освобождаются при закрытии.

В offline preview используются явно прочитанные DeferredResourceObject:
фон PortraitCommon, рамка Noble_01 и лицо Portrait_80002_F. Это статический
вариант WBP; он может отличаться от рамки / лица реального персонажа в игре.
Native загрузчик, runtime замены / ранг / внешность и inherited visibility
ещё не восстановлены. Fallback Brush Noble_05 не подменяет deferred path.
Сходство имён не использовано как доказательство привязки.

[Доказательства, полные SHA и ограничения](../resource-tools/vampir/knowledge/evidence/interface/UI-HP-MP-SKIN-11316.md).
Задача UI-21.11 в [общем плане](UI-TASKS.md) остаётся открытой для runtime оформления.
Бафы и сведения об эффектах учитываются отдельно в UI-21.08.

Проверены 29 Python / 5 renderer tests, verifier сборки и HUD / коллекции /
магазин на трёх разрешениях. Native DPI этим не подтверждён; системные настройки
не менялись. Проверялся отдельный демопрофиль hp-rebuild-v4, реальные профили сохранены.
