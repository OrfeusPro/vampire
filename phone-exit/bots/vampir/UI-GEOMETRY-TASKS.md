# Повторная проверка расположения интерфейса

Обязательная часть UI-19.16. Постоянные ID; новые окна добавлять без перенумерации.
`[ ] ~` означает расчёт / проверку, `[x]` — выполненный расчёт и сверку.
Функциональные результаты в UI-TASKS не заменяют эту проверку.

Для **каждого** окна и дочернего контрола нужен паспорт: полный путь ресурса,
вариант и SHA256, корень и цепочка родителей / exports / slots, anchors,
offsets, alignment, padding, ограничения размеров, desired size / AutoSize,
SafeZone, DPI / ApplicationScale / UI Scale, преобразование областей клика,
проверенные разрешения и оставшиеся неизвестные. Источник расчёта — структура
клиента; кадры игры проверяют результат. Ручные проценты не закрывают пункт.
Неизвестный контейнер нельзя молча заменить общей рамкой попапа.

Паспорта текущих профилей: `ui-prototype/window-layouts.json` и
`button-layouts.json`; сборщик добавляет SHA / slots в `placement-evidence.json`
и `button-evidence.json` неизменяемого снимка. Это исходные свидетельства;
временная рамка и неизвестный масштаб остаются явно отмеченными допущениями.
Для остальных ресурсов действует тот же критерий в [UI-WINDOW-TASKS](UI-WINDOW-TASKS.md).
