# Повторная проверка иконок, оформления и событий

Обязательная часть UI-20.14 / UI-20.16 / UI-20.17. Постоянные ID;
новые окна и подзадачи добавлять без перенумерации. Функциональные проверки
и наличие оригинального PNG не закрывают этот список.

Для каждого окна и каждого дочернего контрола оформить паспорт:

- ресурс / вариант / полный SHA, class / export / slot и источник стиля;
- контрол → дочерний Image либо Brush / Style → asset path / SHA;
- положение и размер иконки, padding, выравнивание и масштаб;
- normal / hover / pressed / released / selected / focus / disabled / loading;
- цвет и оттенок, LinearColor / sRGB, tint, ColorAndOpacity, RenderOpacity,
  наследование и alpha без повторного преобразования;
- texture / material parameters, рамка / nine-slice, шрифт, обводка, тени,
  эффекты, видимость / hit testing, анимация и переходы состояний;
- delegate / callback / binding, условия и порядок событий, отмена,
  потеря фокуса / окна, повтор; отдельно доступность действия и результат;
- цепочка события до целевой функции и её callees, имя / ID, аргументы,
  условия, export / адрес с полным SHA клиента, изменение состояния / запрос,
  ошибки и подтверждение результата; статус повторной проверки после обновления;
- что подтверждено байтами / схемой / кадром / демопроверкой и что неизвестно.

Событие клика и pressed-эффект не подтверждают выполнение игровой команды.
Демо-события и будущий адаптер бота проверять отдельно. В проверенных таблицах
имён WBP_CommonFavoriteT и WBP_ItemCollectionUI прямые имена OnPressed /
OnReleased / OnClicked не найдены; это не доказывает отсутствие native delegates.
Связи могут задаваться superclass, нативным кодом или runtime bindings.
Реальные действия бота остаются UI-17 после готовности прототипа.

Неизвестные свойства и временный CSS указывать явно. Если свойства / иконки
пропущены в уже реализованном окне, повторный проход обязателен. Паспорт
геометрии находится в [UI-GEOMETRY-TASKS](UI-GEOMETRY-TASKS.md); новая визуальная
проверка не заменяет его.
