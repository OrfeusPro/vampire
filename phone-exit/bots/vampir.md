# Vampir

Главный файл разработки и навигации: [vampir/README.md](vampir/README.md).
Текущее состояние и свежие ограничения смотреть там; разделы ниже сохраняют историю.

Отдельный Android-модуль `vampir`; игра работает только на телефоне.
ПК служит каталогом, редактором настроек и источником исследования ресурсов.
Игровой клиент Windows не запускается ботом и не является средой исполнения.
OCR и ML Kit не используются. Фарм/маршруты пока не реализованы.

## Модуль

Manifest разрешает только пакет `com.netmarble.thered`, engine3, settings1.
Настройки отдельные: автозапуск включён, фарм/разбор/восстановление выключены,
точек Lord Nine или RF нет. Назначение не запускает сценарий автоматически.
Сценарий ожидает распознанную загрузку патча без кликов, ограничивает запуск
и повторное нажатие известной кнопки. Неизвестный экран не считается готовым
персонажем. По кадрам телефона добавлены два якоря HUD, отдельный режим квестов,
распознавание автоматического выполнения, пропуск сцен и подсказок обучения.
Существование процесса игры не подменяет распознавание готового персонажа.
Режим квестов по умолчанию выключен; на тестовом Pixel 5 включён явно.

На ПК Vampir добавлен в фильтр и каталог. Общие назначение/автозапуск доступны
модулям из каталога; игровые функции Lord Nine и карта RF не показываются Vampir.
Иконка извлечена из установленного `ProjectRED-Win64-Shipping.exe`.
Для обновления уже открытого окна требуется обычное повторное открытие клиента;
несохранённые настройки других телефонов автоматически не закрывать.
