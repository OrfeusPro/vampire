# Action Icons

Lucide 0.468.0, ISC license (see LICENSE).
Source: https://github.com/lucide-icons/lucide/tree/0.468.0/icons

SVG source files and 48px PNG variants are committed for offline native rendering.
The light, mint, dark, muted and danger variants cover ordinary, selected,
primary, disabled and destructive controls. No icons are downloaded at runtime.

Regenerate with `pc/scripts/build-action-icons.cjs` using Node.js and Sharp
available in the development environment (`NODE_PATH` when needed).
