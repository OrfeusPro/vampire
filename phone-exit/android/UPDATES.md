# Обновления Android 0.8.10

Проверка и загрузка запускаются кнопкой обновления в шапке приложения.
Проверка выполняется в отдельном потоке, с авторизованным HTTPS через выбранную
проверенную Wi-Fi Network. LTE не используется. Она не включает доступ с ПК,
не запускает WebRTC и не требует службы специальных возможностей.

Фоновая проверка каждые 30 минут удалена по запросу пользователя. Ранее
сохранённый флаг autoUpdate больше не используется. API сообщает autoDownload=false.
Явные команды checkUpdate/installUpdate с ПК сохранены.

Проверка с телефона, команда ПК и ранее начатая загрузка сериализованы, чтобы
не записывать один временный APK одновременно. Повторный клик блокируется до
завершения проверки. APK проверяется по SHA256, имени пакета, версии и подписи;
установка остаётся явным подтверждением пользователя в Android.

Если обновление уже загружено, уведомление открывает предложение установки.
Клик по кнопке в шапке всегда проверяет текущий серверный manifest, включая случай,
когда в кэше есть более старое загруженное обновление.

Проверка 14 октября 2026: personal APK 0.8.10/versionCode 36 собран;
lint — 0 ошибок, 16 предупреждений. Установлен поверх USB-vivo без удаления
данных. Реальное нажатие кнопки открыло ожидание HTTPS-проверки, затем
диалог «Нового обновления нет. Фоновые проверки отключены». Подключение
телефона осталось включённым. Загрузка более новой версии через эту кнопку
и проверка при выключенном доступе ещё не воспроизводились на устройстве.
