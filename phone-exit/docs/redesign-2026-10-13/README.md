«незащищённым трафиком». Выбор приложений обозначен тестовым режимом.

## Границы результата

Экспорты Figma — статические макеты с редактируемыми текстами и векторными слоями,
а не снимки работающего приложения. После создания макетов их визуальная
структура перенесена в нативный Windows-клиент: см. раздел редизайна в
`../../README.md`, `pc/desktop-redesign.ps1` и `pc/desktop-fleet.cs`.
Имена, страны, модели, время, RTT и состояния являются демонстрационными данными.
50 карточек иллюстрируют плотность макета; нагрузка на 50 устройств не проверялась.
Инициалы LN/RF являются временными обозначениями игр, не официальными иконками.

Расписание, массовое применение профилей, отложенное применение после текущего
шага и новые переключатели в макете являются предложениями для реализации.
Их нельзя считать подтверждением существующей функциональности. Разрешение
доступа к телефону по-прежнему должно включаться явным действием на Android.
Макет не меняет эту политику и не предоставляет разрешений.

PNG экспортированы из Figma и основной экран просмотрен после экспорта.
Все четыре фрейма проверены визуально в редакторе. На этапе создания макетов
код приложения, активные подключения, профили, ключи, APK и сервер не менялись.
Последующее внедрение меняет только Windows UI и его проверки. Реальные
данные каталога и API используются вместо демонстрационных записей.
