# Игры и связанные приложения — Windows 0.4.11

В режиме «Выбранные EXE» откройте **«Список приложений…» → «Запущенная игра…»**.
Введите имя EXE, выберите игру. При включённом пункте «Добавить лаунчер и связанные
процессы» ниже показаны найденные EXE; название группы можно изменить.
Нажмите «Добавить в список», затем «Готово» для сохранения.

Игра отображается одной группой. Выберите её для просмотра состава;
полные пути доступны в подсказке. «Добавить EXE…» дополняет выбранную группу,
а без выбранной группы создаёт отдельные записи. «Удалить» удаляет всю выбранную
группу. Escape/Отмена не сохраняют изменения.

**«VPN вкл/выкл»** переключает выбранную группу между VPN и обычной сетью.
**«Только эта»** включает VPN только для выбранной группы, сохраняя другие группы
выключенными. При «Готово» включается выборочный режим, если есть выбранные EXE.
Режим запоминается при следующем запуске; подключение требует кнопки пользователя.
Изменять список нужно при отключённом VPN. Открытые соединения игры после смены
маршрута могут потребовать переподключения в игре или её перезапуска.

Состав хранится локально в `application-groups.json`; активные полные пути остаются
в прежнем `applications.json` для движка маршрутизации. Старые списки совместимы.
Выключенные группы переживают перезапуск и могут быть включены снова.
Аккаунт/телефоны/персональный APK не меняются.

## Определение связи

Toolhelp snapshot + QueryFullProcessImageName/GetProcessTimes: без командных строк,
адресов соединений, внедрения в игру и постоянной истории процессов.
Берутся выбранный процесс и его потомки; родители включаются до лаунчера/каталога
игры, но не системной оболочки. Возраст процессов проверяется против повторного
использования PID. Собственные помощники лаунчера ограничены его каталогом,
resources/bin; соседняя игра другого каталога не включается автоматически.
Сторонние службы и уже завершившиеся процессы могут отсутствовать; нужные EXE
можно добавить вручную. Недоступные для чтения пути не угадываются.

При одновременном выборе лаунчера и отдельных EXE игры отслеживание новых потомков
лаунчера ограничено его помощниками. Потомки самой выбранной игры продолжают
добавляться, в том числе оверлеи вне каталога игры. Общий EXE, явно выбранный для
VPN, маршрутизирует все свои экземпляры — разделения по отдельным PID пока нет.
Режим остаётся тестовым: polling не гарантирует изоляцию с первого пакета.
