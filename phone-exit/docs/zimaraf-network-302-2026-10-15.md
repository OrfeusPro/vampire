# Zimaraf: Network Error 302

Телефон Coolpad CP03 · HK, Lord Nine 1.1.23. API показывал
farm_map_not_opened / farm_map_open и исчерпанные 5 перезапусков.
Свежий снимок и сохранённые кадры ошибок показывают одно окно игры:
Network Error / Connection lost / Please log in again / code: 302.
Это потеря игровой сессии, а не недоступность телефона.

Причина пропущенной обработки: основной notice-обработчик проверял T005
и disconnected, но не network_error_302. Для 302 в imported.json был указан
detector_only типа network_error_302, которого нет в BotVision; PNG также
отсутствовал. Такой признак всегда возвращал found=false.

В модуле 1.1.24 заменено на обычные OpenCV-шаблоны. Свежий кадр 1280×720:

- network_error_302.png: текст соединения и code302, crop[512,320, 774,398].
- network_error_title.png: заголовок, crop[570,248, 713,273].
- network_error_302_ok.png: кнопка OK, crop[568,429, 712,470].

Файлы в bots/lordnine/templates, порог .9, масштабы .65–1.5.
Для распознавания 302 обязательны тело и заголовок. Нажатие допускается
только по найденной кнопке. Применяется существующий reconnect с backoff
15/30/60 сек, сбросом прерванного маршрута/состояния обслуживания и новым входом.
При выключенном автозапуске — game_reconnect_disabled без нажатия.
Новые правила покупки или разбора не вводились, APK не требуется.

Replay последнего сохранённого сбоя: .973/.992/.986, свежий кадр 1/1/1.
Отрицательный кадр HUD другой игры: .162/.304/.301. Это проверка шаблонов,
не гарантия распознавания всех будущих сетевых окон.
113 Python-тестов прошли, включая приоритет 302 перед ожиданием карты,
сброс старого маршрута, backoff, отсутствие действий без заголовка/кнопки
и выключенный автозапуск.

Подписанный пакет опубликован в приватном каталоге, SHA256 проверен удалённым
чтением FTPS; каталог RF сохранён. Команда обновления отправлена только Zimaraf.
Результат живого повторного входа фиксируется после установки.

Первое скачивание 1.1.24 завершилось bot_download_timeout, установленная
1.1.23 сохранилась. Пакет 22.6 МБ содержал карты maps/*.png только для редактора
ПК. Android открывает maps/index.json и шаблоны из templates, а не эти PNG.
В 1.1.25 manifest.pcOnly=["maps/*.png"] исключает их только из ZIP, исходные
файлы ПК остаются на месте. Размер 2 231 389 байт вместо 22 600 233.
Проверен точный состав архива: сохранены все остальные файлы, каталог,
Python-навигация и три новых шаблона. Подписанный 1.1.25 опубликован,
проверен удалённый SHA256, отправлено повторное обновление только Zimaraf.

Live: 1.1.25 установлен, start сбросил исчерпанный счётчик. Окно 302 закрыто
самим ботом, игра вышла на launcher Android. Первый автозапуск не дал быстрого
возврата в игру; причина не доказана. Для продолжения проверки отправлена
отдельная команда launch через API, она открыла титульный экран Lord Nine.
Эта ручная команда поставила бот на manual_control; затем выполнен resume.
Бот продолжил штатный вход, на свежем кадре — чёрный экран загрузки со спиннером,
status=running / step=monitoring / error=null. Следовательно, распознавание 302
и продолжение входа проверены, полностью автоматический повторный запуск
после закрытия игры этим тестом пока не подтверждён.

После штатного входа свежий кадр подтвердил персонажа и открытую World Map:
Current Location Ulan > Lower Tomb of Tyriosa1F. Бот продолжает маршрут с
применённой revision4; статус running, error=null. Первоначальное
farm_map_not_opened устранено для этого окна 302. Это не утверждение об
исправлении всех причин ошибки открытия карты и не часовой автономный тест.
