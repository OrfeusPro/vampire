# Перенос на другой ПК

Windows 0.4.10: кнопка **«Аккаунт…»** справа сверху.

1. Отключите VPN. Нажмите «Аккаунт…», введите пароль минимум из 12 символов
   дважды и нажмите «Экспорт…». Сохраните файл `.phoneexit`.
2. Скопируйте папку программы на другой Windows x64. Одного EXE недостаточно:
   нужны `pc/` вместе с `pc/node_modules/`, `.tools/transport/PhoneExitTransport.exe`
   и `.tools/sing-box/`. Android SDK, JDK и Gradle для запуска ПК не нужны.
3. На новом ПК запустите `Phone Exit.exe`, откройте «Аккаунт…», введите исходный
   пароль и нажмите «Импорт…». Второе поле нужно только для экспорта.
4. Выберите файл: телефоны появятся, доступность обновится автоматически.
   Замена существующего аккаунта требует подтверждения в приложении.

Персональный APK менять не нужно; новые телефоны из него будут обнаруживаться
под импортированным аккаунтом. Файл содержит аккаунт, привязки и список удалённых
устройств. Пути выбранных EXE не переносятся: настройте их на новом ПК.
Ярлыки содержат абсолютные пути: используйте EXE или пересоздайте их через
`pc/install-shortcuts.ps1`.

Храните пароль отдельно от файла: вместе они дают доступ к телефонам.
Без пароля файл не восстановить. Импорт не отключает старый ПК;
не подключайте два ПК к одному телефону одновременно.

## Защита и проверки

Контейнер JSON `phone-exit-account`, версия 1: AES-256-GCM со случайными salt
16 байт и nonce 12 байт; scrypt N=32768, r=8, p=1; фиксированные параметры и
AAD `phone-exit-account-transfer-v1`. Ключи и имена устройств зашифрованы.
Размер ограничен 512 КиБ, проверяются ключевая пара P-256 и привязки.
Пароль передаётся только через приватный stdin, не аргументы процесса или логи.
После импорта профиль защищается DPAPI CurrentUser в `.phone-exit` домашнего
каталога пользователя Windows.

Неверный пароль не меняет профиль. При ошибке второй записи первая откатывается.
Резервные зашифрованные файлы удаляются после успеха или успешного отката;
при ошибке самого отката остаются для восстановления. Аварийное выключение
питания во время двух замен отдельно не проверено.

Node-тесты проверяют шифрование, неверный пароль, подмену и валидацию.
Windows PowerShell 5.1: реальные pipes, DPAPI, замена, откат при блокировке файла,
очистка временных файлов. GUI проверен при 150% DPI. Физический второй ПК
и другие архитектуры Windows не тестировались.
