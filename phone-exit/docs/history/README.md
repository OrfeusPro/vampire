## Снимок прежнего AGENTS.md

[AGENTS-2026-10-21.snapshot.md](AGENTS-2026-10-21.snapshot.md) — побайтовая копия
корневого файла до переработки 21 октября 2026. В ней сохранены все прежние
ограничения, версии, результаты проверок, пути и команды. Сам снимок не править.
Относительные текстовые пути в нём относятся к прежнему корню репозитория.

SHA256 снимка: `2e0d3cd2deec78fda897616f19fed03670bfc16fcafc22f32ac0b49f4891b21d`.

В снимке есть отменённые требования Wi-Fi-only и запрета LTE, ранние статусы
«UDP/TUN ещё нет», уже завершённые проверки и заменённые варианты UI / транспорта.
Их нельзя применять как текущие правила или автоматически повторять старые
команды. Сначала читать актуальный README и проверять нынешние файлы / устройства.

Политики и устойчивые ограничения перенесены в действующие AGENTS.md;
хронология оставлена здесь. Новые результаты записывать в README соответствующего
компонента и профильные документы, не наращивать журнал внутри AGENTS.md.
