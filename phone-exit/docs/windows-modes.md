# Системные режимы Windows

Оконный клиент: `../Phone Exit.vbs`. Современный тёмный интерфейс, личные телефоны
по странам, выбор режима, подключение и остановка. На телефоне нужен персональный
APK 0.3.1 с UDP. Старые APK допускают только TCP-прокси.

## Весь трафик · VPN

Используется sing-box 1.14.3 с TUN и стеком gVisor. Только помощник TUN запрашивает
права администратора; каталог и WebRTC работают с обычными правами. SOCKS слушает
только 127.0.0.1:1080. Подключение WebRTC сохраняет физический интерфейс, точные
адреса транспорта исключены из маршрута. TCP, UDP и DNS идут через сеть Android
(Wi-Fi или мобильную, начиная с APK 0.9.4).
ICMP и доступ к локальным сетям через телефон не поддерживаются.
С 16 октября 2026 пользователь выбрал IPv4-only: DNS AAAA получает пустой
NOERROR, в полном режиме IPv6 отклоняется, в выборочном — только для выбранных
EXE. IPv6-адрес TUN оставлен для перехвата и запрета, а не для выхода в сеть;
он не создаёт прямого обхода. FakeIP выдаёт только IPv4. DNS, перехваченный
клиентом в обоих режимах, не выдаёт AAAA, в том числе невыбранным приложениям;
их IPv4 продолжает идти через обычное подключение, прямой маршрут IPv6 по IP
невыбранного EXE не блокируется.

Реальный тест `pc/desktop.ps1 -VpnTest` на vivo прошёл: обычный HTTPS без прокси
сравнен с выходом телефона; UDP STUN и DNS; принудительная потеря транспорта
блокирует новый HTTPS; отключение TUN восстанавливает обычный HTTPS. Тест не
доказывает работу всех игр, anti-cheat, любой сети/NAT или долговременную стабильность.

Проверка IPv4-only 16 октября: оба конфига прошли `sing-box check` на закреплённом
1.14.3; тесты конфигурации и native/werift UDP прошли. Через настоящий WebRTC к
realme JP и loopback mixed-вход sing-box проверены AAAA (NOERROR/0 ответов),
A (5 ответов), Netmarble `/restriction` (HTTPS 200) и полная загрузка 5 000 000
байт (6,49 с). Этот прогон не включал системный TUN/права администратора и не
заменяет повторную проверку выбранных EXE с IPv4-only. Новые правила применяются
при следующем включении VPN; уже запущенный туннель нужно отключить/подключить.

При потере канала TUN остаётся активен без прямого запасного выхода. Нажмите
«Отключить», чтобы вернуть обычную сеть. Нормальное закрытие окна тоже удаляет TUN. Помощник отслеживает процесс окна
и завершает движок при исчезновении владельца.

## Выбранные EXE · VPN (тестовый)

Пути EXE выбираются в окне; правила сопоставляют полный путь, не название сайта.
Другие программы используют прямой выход. FakeIP сохраняет доменное имя до выбора
маршрута: телефон разрешает имена выбранных программ, прямой выход использует
отдельный DNS-over-HTTPS. Указать отдельно EXE игры, лаунчера и вспомогательных
процессов. Автоматическое отслеживание новых дочерних EXE ещё не реализовано.
Реальный тест `-VpnTest -VpnTestApps` прошёл: выбранные curl/PowerShell выполняют
HTTPS и UDP через телефон; после потери транспорта выбранный curl блокируется,
другой EXE сохраняет DNS и HTTPS через обычный интернет. Режим помечен тестовым
из-за отсутствия автоматического учёта дочерних EXE и проверок конкретных игр.
Сопоставление полного пути не чувствительно к регистру Windows.

## Движок и воспроизводимость

`pc/install-vpn-engine.ps1` загружает закреплённый официальный архив и проверяет
SHA256; помощник повторно проверяет EXE перед запуском. Движок и сборки в `.tools/`.
Sing-box распространяется по GPL-3.0; лицензия рядом с движком. При дальнейшей
передаче программы сохранять лицензию и доступ к соответствующим исходникам:
[официальный релиз](https://github.com/SagerNet/sing-box/releases/tag/v1.14.3).

Werift 0.25.0 имеет локальное исправление позднего DCEP ACK после закрытия потока:
`pc/scripts/patch-werift.js`, автоматически применяется через npm postinstall.
Регрессионный тест проверяет, что подтверждение не завершает транспорт и не
открывает закрытый канал. Изменение версии требует пересмотра патча.

Основание конфигурации: [TUN](https://sing-box.sagernet.org/configuration/inbound/tun/),
[правила процессов](https://sing-box.sagernet.org/configuration/route/rule/),
[FakeIP](https://sing-box.sagernet.org/configuration/dns/server/fakeip/).
