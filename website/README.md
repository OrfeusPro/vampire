# VAMPIR.TOP — локальный магазин алмазов

PHP 8.3+, HTML/CSS/JS без сборки и npm-зависимостей. Русский, украинский, английский. По умолчанию открывается английская версия, в том числе до загрузки JS. Явный выбор языка запоминается; прямые ссылки `?lang=ru`, `?lang=uk`, `?lang=en`.

## Запуск

Из корня проекта: `powershell -ExecutionPolicy Bypass -File website/start-local.ps1`.
Адрес: http://127.0.0.1:8787/. Остановка: `powershell -ExecutionPolicy Bypass -File website/stop-local.ps1`.

Добавлен `.osp/project.ini`: домен **vampir.local**, PHP-8.3, публичный каталог `website/dist`. После перечитывания проектов OSPanel можно открыть этот домен. При текущем запуске используется встроенный сервер PHP из установленного OSPanel на loopback; другие проекты OSPanel не перезапускались. Публичный DNS vampir.top не изменялся.

## Реализовано и границы

- Основной вариант — индивидуальный заказ с вводом количества. Кнопка первого экрана сразу открывает форму; в каталоге количество переносится в заявку. 1 000 / 5 000 / 10 000 оставлены дополнительными кнопками быстрого выбора, не официальными пакетами игры. Проверено в браузере: ввод 7 500 → форма с 7 500 алмазов.
- Регион GLOBAL / SEA / KR, точное название сервера вводится пользователем; персонаж необязателен. Совместимость серверов и наличие товара не проверяются автоматически.
- USD / USDT / EUR / UAH / RUB — предпочтительная валюта **запроса цены**, без конвертации и без заявления о доступности приёма платежей.
- Реальное локальное сохранение заявки через `dist/api/order.php` в `website/var/orders/*.json`, вне публичного каталога и Git. Контакт, сервер, количество, валюта, язык, дата согласия. Платежи, передача товара, операторские уведомления и личный кабинет не подключены. Интерфейс честно сообщает это до и после заявки.
- CSRF, серверная валидация, лимит тела, интервал 15 секунд между заявками одной сессии; защита от распределённого спама для публичного запуска ещё нужна.
- Просмотр заявок сейчас — локальные JSON-файлы. Перед публичным запуском нужны прайс и наличие по серверу, способ передачи, операторский канал, платёжная интеграция и обработка жизненного цикла заказов.

Проверено 16.10.2026: PHP syntax обоих файлов, `node --check`, HTTP 201 и содержимое сохранённой заявки, отклонения 403/405, HTTP 404 к приватным заказам. В браузере: RU/UK/EN, открытие пакета, успешная тестовая заявка, каталог. Проверка на физическом мобильном устройстве не проводилась. Тестовые заявки удалены.

## Языковые URL и SEO (актуальная схема)

- EN: `/`; UK: `/ua/`; RU: `/ru/`; остальные по коду в нижнем регистре, например `/de/`, `/sr-latn/`.
- Без завершающего слеша, `/en/`, `/index.php`, `/uk/` и старые `?lang=…` возвращают 301 на единственный адрес. Неизвестные пути — 404. Выбор языка — обычная ссылка, URL является источником языка; localStorage больше не переопределяет корень EN.
- Сервер выводит переведённые тексты, title, description, доступные подписи, `html lang` и Content-Language. Без JS поисковик получает полноценный перевод.
- Self canonical на https://vampir.top, 50 взаимных hreflang + x-default, Open Graph / Twitter, JSON-LD WebSite/WebPage без выдуманных рейтингов/отзывов. Украинский URL `/ua/`, но hreflang `uk`.
- `/sitemap.xml` содержит все 50 канонических адресов. `/robots.txt` на публичном домене разрешает индексацию страниц и закрывает API/locales; локально — Disallow: / и noindex, nofollow. Данные заказов остаются вне webroot.
- Встроенный сервер PHP использует `website/router.php`, Apache/LiteSpeed — `dist/.htaccess`. Для Nginx отдельно нужен `try_files $uri $uri/ /index.php?$query_string;` и запрет `/locales/`. Публичный webroot должен быть `website/dist`, а `i18n.php` и `seo.php` размещены в родительском `website/`.
- Клиенту передаются только EN и текущий словарь; все 50 словарей не включаются в каждую страницу. Статические CSS/JS имеют версию filemtime для обновления кэша. Основная иллюстрация preload; добавлен preconnect шрифтов.

Проверки: `python website/check-seo.py` — HTTP для всех 50 URL: серверный lang/title/canonical, 51 alternate, 50 ссылок меню, редиректы, 404, sitemap/robots и production-директивы через локальный Host. PHP syntax и JS syntax пройдены. Визуальная проверка в браузере остаётся недоступна при отключённом browser use.

Это техническая подготовка SEO, не гарантия позиций. Публикация на домен и добавление sitemap в Google Search Console/Bing Webmaster не выполнялись; потребуются доступ к хостингу/подтверждение владения доменом. Перед продвижением важны вычитка переводов, реальные условия оплаты/передачи и контактные/юридические страницы магазина.

Минимальное количество заказа — 1 000 алмазов: min обоих полей, границы кнопок −/+, расчёт и серверная проверка. Первый экран открывает форму с выбранным количеством или 1 000. Валюта оплаты вынесена в отдельную строку, поле персонажа — на всю ширину. HTTP: 999 отклонено (422), 1000 принято (201); тестовая запись удалена.


## Настройка цены и список региона (17.10.2026)

Единый тариф находится в `website/settings.json`: `"price_usd_per_1000": "8.00"`. Чтобы изменить цену за 1 000 алмазов, поменяйте строку, например на `"9.50"`, сохраните файл и обновите страницу. Десятичный разделитель — точка, ровно два знака после неё; цена строго положительная. Перезапуск PHP не нужен. Файл расположен вне публичного каталога.

Калькулятор получает тариф с сервера; сервер заявки независимо использует тот же файл. `rateLabel` и `a2` всех 50 языков используют `{pricePer1000}`; отдельное редактирование цены в переводах не требуется. В заявке сохраняется тариф на момент создания, точная цена в USD и целочисленные единицы 1/100 000 USD. Максимум 5 знаков нужен для точного расчёта произвольного целого количества при тарифе с центами; конвертация USD/USDT не предполагается.

Проверено временное изменение на 9.50: обновились HTML, русский текст, данные клиентского калькулятора и сохранённая заявка (1250 → 11.875 USD). Затем восстановлено 8.00, тестовая заявка удалена. Проверки переводов и SEO проходят.

При пустом регионе отправка открывает список и подсвечивает поле. JS/PHP syntax проверены; визуальная проверка недоступна при выключенном browser use.
