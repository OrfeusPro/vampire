# XMail — закрытая почта VAMPIR.TOP

Единый вход: `/xmail/`. Интерфейс на русском. Подключены 17 ящиков владельца.
Это IMAP-читатель: отправка, удаление, перемещение и изменение флагов не реализованы.

## Файлы и секреты

- `dist/xmail/`: PHP entry point, JavaScript и CSS.
- `xmail-backend.php`: авторизация, API, cache и ограничение входа.
- `xmail-imap.php`: IMAP SSL и MIME; PHP imap extension не требуется.
- `xmail.local.php`: игнорируемая приватная конфигурация вне public_html.
  Пароль входа — bcrypt hash; пароли IMAP нужны в исходном виде для LOGIN по TLS.
- `xmail.example.php`: образец без секретов.
- `var/xmail-access.txt`: локальные реквизиты единого входа, вне Git, на сайт не загружаются.
- `var/xmail/`: приватный cache заголовков/папок и счётчик попыток входа.
  Тексты писем и вложения постоянно не сохраняются.

Секретная конфигурация на хостинге `/xmail.local.php`, права 600.
Список аккаунтов и содержимое писем выдаются только после входа. Пароли не выдаются API.

## Чтение и обновление

IMAP `mail.vampir.top:993`, TLS с проверкой имени и сертификата. EXAMINE и BODY.PEEK
сохраняют флаги сервера. Используются UID вместе с UIDVALIDITY, чтобы не открыть
другое письмо после пересоздания папки. Чтение письма не ставит Seen.

При входе загружаются все выбираемые IMAP-папки (включая spam, sent, archive).
Список — последние 50 писем каждой папки, более ранние доступны по кнопке.
Общий список сортируется по времени IMAP. Поиск действует по загруженным
заголовкам, отправителю и ящику, фильтры — по ящику, папке, unread.

Раз в 30 секунд видимая вкладка запускает refresh; при уже идущем цикле новый
не создаётся. Одновременно обрабатываются максимум три ящика, папки каждого —
последовательно. Скрытая вкладка не начинает новые циклы, текущие запросы могут
завершиться. При возврате — refresh. Cache списка 25 секунд, папок 5 минут.
При потере сети/доступа видна ошибка соответствующего ящика; кнопка обновления
позволяет повторить попытку. Ошибка одного ящика не блокирует остальные.

Письмо открывается в безопасном текстовом виде. HTML преобразуется в текст,
script/style/head удаляются, ссылки сохраняются текстом. Внешние картинки,
трекеры, скрипты, iframes не загружаются. Текст вставляется через textContent.
Вложения скачиваются по отдельному авторизованному POST как attachment/octet-stream.
Максимум письма 12 МБ, 150 MIME-частей и глубина 12; для больших писем нужен
обычный почтовый клиент. S/MIME/PGP и сложная визуальная HTML-вёрстка не поддерживаются.

## Защита

Отдельная session cookie с Path=/xmail/, HttpOnly, SameSite=Strict, Secure на HTTPS.
Session ID меняется при входе; idle timeout 30 минут, абсолютный срок 8 часов.
Автообновление считается активностью. Выход уничтожает сессию и cookie.
Все API — POST + CSRF; вход ограничен 8 попытками за 15 минут на IP-HMAC.
IP/пароли в runtime-файлах не записываются. Session lock освобождается до IMAP.
Cache вне webroot, каталоги 700, JSON cache 600. CSP без inline script/style,
frame-ancestors none, no-store и noindex на всём разделе. HTTPS обязателен,
кроме localhost/127.0.0.1/vampir.local для разработки.

## Публикация

`python website/deploy-ftp.py --xmail-only`: выгружает только раздел xmail,
его приватные helpers/config и добавляет маршрут в существующий .htaccess.
Содержимое .htaccess хостинга сохраняется, добавляются только правила XMail.
index.php/index.html не заменяются; до и после проверяются byte-for-byte.
Это важно: владелец временно закомментировал главную на проде.
Обычную полную выгрузку для этого изменения не применять.

## Проверки

- `php website/check-xmail.php`: MIME encoded headers, multipart, base64,
  attachments/RFC2231, HTML-to-text, quoting и отклонение CRLF.
- `python website/check-xmail.py [--production]`: auth, CSRF, HTTP заголовки,
  чтение папок/списка/одного письма всех 17 ящиков, logout; содержимое не печатается.
- PHP lint, JS syntax; реальные IMAP SSL подключения ко всем 17 ящикам пройдены.
- Чтение реального письма через EXAMINE/BODY.PEEK проверено без изменения Seen.
- Локальный браузер: вход, появление списка, открытие текста без внешних
  script/iframe/img; мобильная ширина 390 px без горизонтального переполнения.

Для проверки не отправляются письма и не меняются ящики.
