# Как переводить сайт

## Файлы

- `../dist/locales/en.json` — эталон ключей и английский текст.
- `../dist/locales/ru.json`, `uk.json` — готовые переводы.
- `../dist/locales/languages.json` — общий реестр: код, родное название, короткая подпись и `enabled`.
- Все 50 вариантов из реестра заполнены, включены и находятся в `../dist/locales/`. Пустые прежние шаблоны удалены, чтобы не было двух мест редактирования.
- Новые переводы являются черновыми: большинство подготовлено через машинный перевод Google Translate; нюнорск и романшский подготовлены отдельно, сербская латиница получена из кириллицы. Лингвистическая вычитка носителями не выполнена.
- В реестре поле `translationStatus` фиксирует статус перевода.

## Добавление языка

1. Для существующего языка редактируйте `website/dist/locales/de.json` напрямую. Переводите значения справа; имена ключей не меняйте.
2. Для нового языка скопируйте `en.json` в файл с нужным кодом и переведите значения.
3. В `languages.json` найдите `de` и задайте `"enabled": true`.
4. Из корня проекта запустите `node website/check-translations.cjs`.
5. Обновите страницу и проверьте `http://127.0.0.1:8787/de/`, включая форму заказа и мобильный экран.

JavaScript, PHP и меню при этом редактировать не требуется. Перезапуск сервера не нужен. По умолчанию EN на `/`. Язык задаётся URL, а не сохранённой настройкой браузера: `/ua/` для украинского (код `uk`), `/ru/`, `/de/` и т. д. Файлы хранить в UTF-8, без комментариев и завершающих запятых.

## Правила текста

- `{id}` — номер заявки, `{pricePer1000}` — цена из настроек: сохранять без изменений.
- HTML разрешён только в `heroTitle`, `catalogTitle`, `howTitle`, `worldTitle`, `faqTitle`; используйте только `<br>` и `<em>...</em>` без атрибутов.
- USD, USDT и название VAMPIR не переводить.
- В `rateLabel` и ответе `a2` цена задаётся шаблоном `{pricePer1000}`. Меняйте цену только в `website/settings.json`; локализованное значение подставляется сервером.
- `pageTitle` — заголовок вкладки, `heroDesc` также используется в meta description.
- Ключи с `Label` включают подписи доступности; переводите их тоже.

При пропуске строки сайт подставляет английский текст, но проверка требует заполнить все ключи перед выпуском языка.

## Охват

Реестр включает 50 языковых вариантов: основные государственные языки Европы, ряд региональных языков и языки стран на границе Европы и Азии; для сербского предусмотрены кириллица и латиница, для норвежского — букмол и нюнорск. Это расширяемый рабочий список, а не заявление о покрытии всех региональных и малых языков Европы. Новый код можно добавить в реестр и создать для него файл по образцу `en.json`.

## Проверка подключения

Все 50 файлов проходят `check-translations.cjs`: 72 ключа на язык, плейсхолдер `{id}`, HTML и неизменные USD/USDT/VAMPIR/Discord/Telegram. Проверены переключение и форматирование цены для всех кодов в изолированной JS-проверке. HTTP-страница отдаёт 50 переводов и 50 кнопок меню. Браузерная визуальная проверка новых языков не выполнена: локальное управление браузером отключено в настройках Work.
